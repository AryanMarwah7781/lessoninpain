# Nozzle Setup

Nozzle Setup allows you to view and change nozzle configuration. Nozzles must be properly configured for the spray rate control unit to apply the desired rate of solution.
NOTE: Some of the following items are only displayed if machine is equipped with the associated option.
Modify When:
- Performing broadcast application.
- Performing band spraying application.
- Spraying at a reduced width that cannot be achieved with section shutoffs.
Active Nozzle Configurations:
