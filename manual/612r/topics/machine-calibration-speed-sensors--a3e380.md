# Machine Calibration | Speed Sensors

This procedure calibrates the wheel speed sensors and radar by comparison with the Global Positioning System (GPS) signal or using a known distance and time. Speed sensors and radar must be calibrated to achieve the desired application rate.
Perform Calibration When:
- A wheel speed sensor has been replaced.
- Speed sources are displaying inconsistent speeds.
- Tire sizes have changed since last calibration.
- New tires were installed, or tires have become excessively worn since last calibration.
- Radar has been replaced (if equipped).
