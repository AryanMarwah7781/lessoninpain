# Spray Calibration | Flowmeter

This procedure calibrates the flowmeter(s). The flowmeter(s) must have the correct calibration numbers entered in order to provide the desired application rate.
Perform Calibration When:
- Flowmeter(s) have been replaced.
- Actual application is not equal to target application rate.
Items Accessible on Spray Calibration | Flowmeter Page:
NOTE: Verify location of the flowmeter for each system so that calibration numbers are entered correctly.
