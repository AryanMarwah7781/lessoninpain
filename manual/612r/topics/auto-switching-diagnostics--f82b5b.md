# Auto Switching | Diagnostics

Auto Switching | Diagnostics provides a list of prerequisites to aid you in troubleshooting system faults and errors. All prerequisites must be met before auto switching will operate.
Items Available on Auto Switching | Diagnostics Page:
N118420C—UN—26JUN25

![[N118420C.png]]
**Figure N118420C**

Status Indicator
Status Indicator— indicates whether the system is inactive/active or if there are faults preventing auto switching.
N118025C—UN—20JUN25

![[N118025C.png]]
**Figure N118025C**

Checkmark
Checkmark— indicates a normal state for the auto switching requirement.
N118026—UN—30NOV16

![[N118026.png]]
**Figure N118026**

Exclamation Mark
Exclamation Mark— indicates a fault condition with the prerequisite. Auto switching cannot be turned ON until the prerequisites are met.
Auto Switching Prerequisites:
- Tank configuration must be supported
- Spray mode must be set to Broadcast
- Nozzle turret must have tips assigned
- Target rate must be selected
- Pressure must be within range
NOTE: These settings can be changed using Sprayer Setup and the Spray System application.
