# Section Status

Section Status displays the status of each spray section on the boom.
Available Status Indicators:
N119616—UN—14NOV16

![[N119616.png]]
**Figure N119616**

Section Ready
Section Ready— section enabled but not applying product.
N119617—UN—14NOV16

![[N119617.png]]
**Figure N119617**

Section Applying
Section Applying— section currently applying product.
N122954—UN—14NOV16

![[N122954.png]]
**Figure N122954**

Section Fault
Section Fault— section not applying product. Nozzle fault has occurred.
N125628—UN—14NOV16

![[N125628.png]]
**Figure N125628**

Section Control Auto OFF
Section Control Auto OFF— section not applying product. Section commanded OFF by section control.
N122953—UN—14NOV16

![[N122953.png]]
**Figure N122953**

Section Indexed OFF
Section Indexed OFF— section not applying product. Section commanded OFF by Index Boom Section (IBS) switches.
N122955—UN—14NOV16

![[N122955.png]]
**Figure N122955**

Section Disabled
Section Disabled— section disabled using Nozzles System application or CommandARM switches.
NOTE: If operating with section control, see Section Control Application for setup information. See Section Control in the display Operator's Manual for more information.
