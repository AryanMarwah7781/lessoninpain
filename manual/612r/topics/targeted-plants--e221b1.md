# Targeted Plants

Targeted Plants refers to the type of plants that See & Spray will target when Targeted Herbicide is ON. The targeted plant displayed, either Broadleaf or All Weeds, will automatically update based on the crop type selected.
To change the targeted plant type, change the crop type in Work Setup.
