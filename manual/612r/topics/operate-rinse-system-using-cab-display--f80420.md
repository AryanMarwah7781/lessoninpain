# Operate Rinse System Using Cab Display

CAUTION: Spray system can contain hazardous material, which can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use the rinse system in an area where people, animals, vegetation, and water supply, and so on, cannot be contaminated.
Rinsing system is recommended daily or anytime chemicals are switched. There are two separate systems to rinse, Solution System 1 and Solution System 2. These systems can be rinsed independently, or combined, or combined with equalizer.
Solution System 1 or 2 Rinse Using Cab Display
NOTE: Rinse procedures can be activated from the cab using the display, but the operator must still open eductor valves manually to rinse the hopper.
NX1408050—UN—05JUN25

![[NX1408050.png]]
**Figure NX1408050** — A: Solution system Button

1. Unfold the boom.
2. Drain the solution tank. (See Drain Solution Tank in this section.)
3. Operate boom air purge (if equipped) to remove solution before performing the rinse procedure.
4. Set spray pressure at 620—690 kPa (6.2—6.9 bar) (90—100 psi) to assist in chemical removal when spraying rinse water.
5. Select Solution System button (A).
NX1408051—UN—05JUN25

![[NX1408051.png]]
**Figure NX1408051** — A: Solution System Button; B: Checkbox; C: OK Button

6. Select solution system button (A) for system to be rinsed from the Select Solution System page.
7. Select checkbox (B) to reclaim product after rinse cycle is complete.
8. Select OK button (C) to confirm the selections.
NX1408052—UN—05JUN25

![[NX1408052.png]]
**Figure NX1408052** — A: Rinse Cycles Button; B: Cycle Fluid Usage Button; C: Start Button

9. Select Rinse Cycles button (A) to chose the number of of rinse cycles.
10. Select Cycle Fluid Usage button to select between Low, Normal, and High.
11. Select Start button (C) to start the rinse cycle.
NX1408246—UN—08JUN25

![[NX1408246.png]]
**Figure NX1408246** — A: Status Indicator; B: Checkmark; C: Progress Indicator; D: Skip Button; E: Abort Button

12. Status indicator (A) will illuminate and the status of the cycle will be displayed. Completed portions will be noted with a check mark (B).
13. The progress indicator (C) displays next to the rinse step in progress. A rotating indicator means that the listed components are currently being rinsed.
NOTE: Skip button (D) is only available once per circuit and can only skip in order.
14. Choose the Skip button (D) to advance the procedure to the next component before rinsing the current component is completed.
15. Choose the Abort button (E) to prematurely end the cycle if desired.
16. Rinse procedure automatically stops when complete.
N120497—UN—02NOV16

![[N120497.png]]
**Figure N120497**

17. Start the solution pump using solution pump switch.
18. Press spray system On/Off switch to spray rinsate through boom.
