# Advanced Settings

Advanced Settings allow you to access further adjustments and less common settings.
Items Accessible on Advanced Settings Page:
WZ1406741—UN—28MAY25

![[WZ1406741.png]]
**Figure WZ1406741**

Stationary Active Roll
Stationary Active Roll— select to enable/disable stationary active roll.
Enabling keeps the booms aligned with the machine.
Disabling allows the booms to rotate to be parallel with the ground at machine speeds below 2 km/h (1.2 mph).
NOTE: It is recommended to keep stationary active roll ON unless you are trying to diagnose an issue with the roll system.
