# Spreader | Spreader Check Calibration

This procedure can be used to check the dry spreader application rate capability and troubleshoot component function.
Perform Spreader Check When:
- Beginning the season.
- Hydraulic pump is replaced.
- Hydraulic motors and valves are replaced on spreader.
- Actual rate and target rate are not equal.
- Verifying the conveyor speed response to the desired rate or ground speed.
- Verifying the spinner speed response when operating at low engine speeds while using manual transmission mode.
