# Rinse System | Solution System

Solution System allows you to clean the spray solution from the solution system and boom.
NOTE: To rinse entire system, solution tank must be empty.
Perform Solution System Rinse:
- Before servicing solution system.
- When changing chemicals being applied.
- When changing crop being sprayed.
- Before changing tank modes.
Items Accessible on Rinse System | Solution System Page:
NOTE: Some items included are only displayed if machine is equipped with the associated options.

Solution System Rinse Procedure:
CAUTION: Spray system can contain hazardous material that can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use rinse system in an area where people, animals, vegetation, water supply, and so on, cannot be contaminated.
NOTE: Chemical buildup in aspirators can occur if not cleaned out thoroughly and regularly. To clean, close all nozzles except the aspirator nozzles during boom rinse.
NOTE: If throttle position has not been adjusted, engine rpm reverts to the previous level when solution pump is turned off.
NOTE: Rinse system can be operated from the load station using the keypad. See your Operator’s Manual for more details.
To rinse entire system, solution tank must be empty.
1. Verify that desired boom sections are enabled. See the Boom Sections tab of the Nozzle System application.
N119111—UN—14NOV16
Solution System
2. If equipped with dual product solution system, select the solution system or systems you want to rinse.
N119111—UN—14NOV16
Rinse Cycles
3. Select desired number of rinse cycles from the Rinse Cycles list box.
N119111—UN—14NOV16
Cycle Fluid Usage
4. Select desired cycle fluid usage from the Cycle Fluid Usage list box.
N119477C—UN—23JUN25
Solution System 1 Pump Toggle Button
5. If equipped with dual product solution system, turn ON the solution system 1 pump using the Toggle Button if solution system 1 will be rinsed.
6. Verify that the solution pump is off.
