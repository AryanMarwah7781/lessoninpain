# Tread Adjust Maintenance Mode | Tread Outputs

Tread Outputs allows you to view sensor readings and valve states.
Use Tread Outputs To:
- Diagnose sensor problems.
- Diagnose tread adjust valve problems.
Items Displayed on Tread Outputs Page:
Sensor to Target— displays the distance from the sensor to the target for each tread. Used to indicate a faulty sensor or if a calibration is needed. If only one tread is selected for adjustment, then the state should only change for that tread.
Valve IN— displays the state of the hydraulic valve used to adjust treads IN. Used to check operation of switch, solenoid, and hydraulic valve. If only one tread is selected for adjustment, then the state should only change for that tread.
Valve OUT— displays the state of the hydraulic valve used to adjust treads OUT. Used to check operation of switch, solenoid, and hydraulic valve. If only one tread is selected for adjustment, then the state should only change for that tread.
