# Perform Visual Nozzle Check

CAUTION: Read the directions printed on the chemical manufacturer's labels carefully before handling chemicals or you may be exposed to hazardous materials, which could poison and injure you.
IMPORTANT: Do not add chemical to the solution tank until just before field use. Follow the chemical manufacturer's instructions for mixing the spray solution to obtain the desired application rate and effect.
NOTE: Nozzle check feature will not function unless the boom is unfolded.
Nozzle check is intended for locating plugged or malfunctioning nozzles.
NX1440536—UN—15JAN26

![[NX1440536.png]]
**Figure NX1440536** — A: Solution Pump On/Off Button

1. Press solution pump on/off button (A).
NX1440541—UN—15JAN26

![[NX1440541.png]]
**Figure NX1440541** — A: Speed Increase Button; B: Speed Decrease Button

2. Adjust pump speed if desired using speed increse button (A) and speed decrease button (B) on the micro display.
NX1440543—UN—15JAN26

![[NX1440543.png]]
**Figure NX1440543** — A: Visual Nozzle Check Button

3. Press visual nozzle check button (A) to start the nozzle check routine. Routine starts with the left most section and works section by section across the boom.
NOTE: Nozzle check has a delayed start to allow the operator to get in position to visually inspect nozzles.
4. Press the pump on-off button and then the visual nozzle check button to stop the nozzle check proceudre.
