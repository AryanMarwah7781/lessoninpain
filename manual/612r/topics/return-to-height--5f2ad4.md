# Return to Height

Return to Height raises/lowers the boom sections to set heights based on the settings you select. Using the correct height mode helps to prevent you from lowering the boom too low and damaging the crop or the boom structure.
NOTE: You can raise/lower beyond the set points by pressing the boom raise/lower switches again.
