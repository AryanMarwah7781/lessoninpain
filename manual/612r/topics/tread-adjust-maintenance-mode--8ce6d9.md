# Tread Adjust Maintenance Mode

This procedure can be used to control the movement of treads manually when adjusting width. Treads can be moved individually or together, while moving or stationary.
IMPORTANT: Wheels must be lifted off the ground if tread adjust is activated while stationary or machine damage occurs.
Use Tread Adjust Maintenance Mode To:
- Diagnose tread width sensor problems.
- Adjust tread width for only one wheel.
