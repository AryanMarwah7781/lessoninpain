# Manual Tread Adjust Procedure

This procedure allows you to adjust the tread width without using the minimum or maximum tread width buttons or one of the 3 presets.
For more information on how to adjust the tread width using the minimum/maximum and preset buttons, refer to Auto Mode Tread Adjust Procedure.
CAUTION: Always use the narrowest possible tread width when transporting the machine on a road.
NOTE: If tread width does not adjust properly, perform Tread Adjust Calibration and verify that tread adjust shims are properly adjusted. (See Operator's Manual for more information.)
N118483—UN—10NOV16

![[N118483.png]]
**Figure N118483**

Target Speed Encoder
1.Start the machine and shift to the lowest target speed using the Target Speed encoder on the multi-function lever.
N120615—UN—10NOV16

![[N120615.png]]
**Figure N120615**

Transport Lock
2.If the transport lock has been enabled, press the Transport Lock switch to disable the transport lock. An error message is displayed if attempting to adjust the tread width when the transport lock is engaged.
NOTE: Tread adjust only operates from 1 through 8 km/ h (1 and 5 mph).
If driving too slowly, wheels may become unevenly adjusted. Adjust the wheels to the minimum or maximum tread width to equalize the wheels.
3.Drive the machine slowly forward.

Tread OUT
4.Press the Tread IN or Tread OUT button on the CommandARM.
5.Release the button and stop the machine when the desired tread width has been achieved.
NOTE: Wheels can be moved independently using tread adjust Maintenance and Calibration mode within the Calibrations and Procedures application.
If sticking occurs, remove debris from axle knees and spray with TY25733 Teflon based lubricant. Activate tread adjust in and out until free.
