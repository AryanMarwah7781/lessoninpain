# Enabled Spray Tip

Enabled Spray Tip checkboxes allow you to select from three combinations available in the automatic mode. The selection of spray tip combinations can be used to overcome gaps in spray speeds if other methods cannot be used.
Modify When:
- The size between small and large tips is too large.
- The size difference between large tip and combination of tips is too large.
