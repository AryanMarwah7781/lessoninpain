# Operating Load Command

NOTE: The Load Command system takes priority over all other spray command system functions.
The Load Command system locks the sprayer from moving by applying the park brake until the Load Command procedure is complete.
CAUTION: Swinging nurse arm can cause injury to you and others. DO NOT PARK the nurse tank on a hill where the nurse arm could swing out. ALWAYS park the nurse tank on flat ground.
IMPORTANT: Determine the appropriate sprayer approach to the nurse vehicle before operation. Folding of the booms and distance from the nurse arm varies based on the nurse vehicle setup and field conditions.
N107965—UN—24OCT13

![[N107965.png]]
**Figure N107965** — A: Nurse Arm

1. Park the sprayer at an appropriate distance from the nurse vehicle to allow nurse arm (A) to swing out and connect to the sprayer.
2. Engage the park brake and exit the cab with the engine still on.
CAUTION: Swinging nurse arm can cause injury to you and others. Always maintain control of the nurse arm when it is unlatched or disconnected.
N83185—UN—19FEB09

![[N83185.png]]
**Figure N83185** — A: Latch; B: Pin

3. Remove pin (B).
4. Unlatch the secondary chain from the nurse coupler.
5. Release latch (A).
6. Unfold and position the nurse arm near the sprayer coupler.
TS206—UN—15APR13
CAUTION: Operator must wear appropriate personal protection equipment when operating Load Command.
NX1440573—UN—15JAN26

![[NX1440573.png]]
**Figure NX1440573** — A: Fill Menu Button

7. Press fill menu button (A) on the micro-display to access the fill menu.
NX1440574—UN—15JAN26

![[NX1440574.png]]
**Figure NX1440574** — A: Pull On Fill Button; B: Back Button

8. Press pull on fill button (A).
NOTE: To go back, press back button (B).
NX1440575—UN—15JAN26

![[NX1440575.png]]
**Figure NX1440575** — A: Load Command Arming Button; B: Back Button

NX1440576—UN—15JAN26

![[NX1440576.png]]
**Figure NX1440576** — A: Load Command Arming Button; B: Back Button

Timer for Connecting Nurse Arm
9. Press load command arming button (A).
NOTE: To go back, press back button (B).
Once load command is armed, the timer will start until the nurse arm is connected. If timer reaches 0, the process is aborted.
NOTE: Hold the nurse arm coupler firmly to the sprayer coupler momentarily (several seconds) until the proximity sensors fully activate the Load Command system.
N107971—UN—05NOV13

![[N107971.png]]
**Figure N107971** — A: Sprayer Coupler; B: Nurse Arm Coupler

10. Align the sprayer and nurse arm couplers (A and B) and push together. Couplers lock together and begin pumping solution.
NX1440577—UN—15JAN26

![[NX1440577.png]]
**Figure NX1440577** — A: Cancel Fill Button

NOTE: The screen above appears on the display once Load Command operation has begun. The operator can shut off the Load Command system or cancel the armed system at any time by pressing cancel fill button (A). The Load Command system shuts down when the coupler becomes disconnected.
The 612R Load Command system slows pumping down at 4353 L (1150 gal) and shuts off at 4542 L (1200 gal). The 616R system slows pumping down at 5867 L (1550 gal) and shuts off at 6056 L (1600 gal). Air seal locking couplers deflate and the nurse arm coupler falls away on its own or when the operator backs the sprayer away.
11. Return to the cab and wait for the Load Command operation to finish, or to cancel the fill, press cancel fill button (A).
CAUTION: Solution could remain in the nurse arm coupler after disconnecting from the sprayer coupler. Wear protective equipment to ensure that excess solution does not come into contact with you or others.
NOTE: (See the CommandCenter Display Applications section for calibration, evacuation, and rinsing instructions).
12. Remove the sprayer from the park position and back the sprayer away from the nurse arm when the Load Command operation is complete.
