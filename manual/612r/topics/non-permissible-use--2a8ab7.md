# Non-Permissible Use

Pay attention to the following applications for which the machine is NOT SUITABLE:
Spraying or atomization of substances other than crop protection chemicals and/or liquid fertilizers.
Use of the tank as a storage medium for substances not intended for crop protection or fertilization purposes.
CAUTION: Working on an uncleaned machine poses unnecessary danger and is therefore forbidden.
