Numeric Input Buttons
Micro displays (A and B) on the load station allow the operator to view various information during the loading process. There are three main screens that are visible during most operations showing a combination of pump speed, pump pressure, and tank volume. The operator can toggle between these screens using the buttons on the micro display. To enter values on the micro displays, such as target fill amount, use the numeric input buttons (D) on the keypad (C).
The micro display also allows the operator to select between options when performing some functions, such as rinse procedures and target filling. The buttons on the micro display are used to toggle screens, select or confirm options, and cancel operations, depending on the specific machine function.
