# Edit Rate Presets

Edit the desired application rate for each product bin for each rate preset. Rate presets must be adjusted to apply the correct amount of product.
Modify When:
- Changing application rates.
- Changing products being applied.
Items Accessible on Edit Rate Presets Page:
N119612—UN—16FEB16

![[N119612.png]]
**Figure N119612**

Rate
Rate— displays the application rate.
N120899—UN—16FEB16

![[N120899.png]]
**Figure N120899**

Prescription
Prescription— opens the Work Setup application. Allows for selection of prescription if one is loaded to the machine.
NOTE: Prescriptions must be created externally and then loaded to the machine before they can be accessed for rate control.
N118004—UN—22OCT15

![[N118004.png]]
**Figure N118004**

Advanced Settings
Advanced Settings— access further adjustments and less common settings.
Procedure to Modify:
N119608—UN—16FEB16

![[N119608.png]]
**Figure N119608**

Target Rate
1. Select Target Rate.
N131716—UN—08FEB21

![[N131716.png]]
**Figure N131716**

Product Bin
NOTE: Product bins not selected for application are displayed in gray.
N131715—UN—08FEB21

![[N131715.png]]
**Figure N131715**

Conveyor Disabled
Product bins selected but disabled are displayed with conveyor disabled. Application rates can be edited for a disabled product bin.
N121510—UN—16FEB16

![[N121510.png]]
**Figure N121510**

Edit Rate Presets
When prescriptions are loaded in Work Setup for a given product, the rate input fields are disabled. This shows that the prescription is handling all of the rate adjustments for that bin and product.
N119612—UN—16FEB16
Input Box
2. Select the input box.
3. Enter the desired application rate using the keypad.
N118151—UN—16FEB16

![[N118151.png]]
**Figure N118151**

OK
4. Select OK to save the value.
5. Repeat the procedure as necessary for the remaining product bins.
