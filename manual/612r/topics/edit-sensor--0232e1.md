# Edit Sensor

Edit Sensor allows you to turn the sensor ON/OFF, view the sensor's software version, and edit the sensor's placement on the boom.
Modify When:
- A sensor has been replaced.
- A sensor location has been changed.
- You need to disable one individual sensor while leaving the rest active.
- You need to verify the software version of each sensor for diagnostic purposes.
NOTE: Sensor setup buttons can also have a Disabled Sensor icon, which indicates that the setup is incomplete or the sensor is turned off.
