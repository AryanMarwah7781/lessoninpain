# Clean Diesel Exhaust Fluid (DEF) Tank Vent Filter—As Required

NOTE: Use a commercial ladder to access DEF tank vent filter.
N153545—UN—18NOV20

![[N153545.png]]
**Figure N153545** — A: Cap Screw (2 used)

1. Remove cap screws (A).
N153546—UN—18NOV20

![[N153546.png]]
**Figure N153546** — A: P-Clamp; B: DEF Tank Vent Filter

2. Lift cover, then remove and retain P-clamp (A).
3. Remove DEF tank vent filter (B) and clean in soapy detergent solution.
4. Blow dry with compressed air and install.
5. Retain DEF tank vent filter with previously removed P-clamp.
6. Install cover.
