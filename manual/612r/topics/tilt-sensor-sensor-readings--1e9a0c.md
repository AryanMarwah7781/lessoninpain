# Tilt Sensor | Sensor Readings

Sensor Readings displays the current readings from the spray boom tilt sensors. Sensor voltages can be used when diagnosing spray boom movement problems.
Items Accessible on Sensor Readings Page:
NX1458182—UN—05MAY26

![[NX1458182.png]]
**Figure NX1458182**

Sensor Reading Gauge
There is an indicator for each sensor, which displays the current boom tilt percentage. The readings are displayed as a gauge as well as by their individual numerical values.
N119115—UN—14NOV16

![[N119115.png]]
**Figure N119115**

Current Reading Indicator
Current Reading Indicator— indicates the current reading from the sensor as shown on the gauge.
NX1458181—UN—05MAY26

![[NX1458181.png]]
**Figure NX1458181**

Tilt Sensor Range
Tilt Sensor Range— the shaded area of the gauge displays the range of readings, with the raised value being the maximum of the range and the lowered value being the minimum of the range.
NX1459620—UN—05MAY26

![[NX1459620.png]]
**Figure NX1459620**

Boom Tilt Raised
Boom Tilt Raised— displays the sensor value when the boom tilt was raised.
NX1459621—UN—05MAY26

![[NX1459621.png]]
**Figure NX1459621**

Boom Tilt Lowered
Boom Tilt Lowered— displays the sensor value when the boom tilt was lowered.
NX1459622—UN—05MAY26

![[NX1459622.png]]
**Figure NX1459622**

Boom Tilt Range
Boom Tilt Range— displays the range value between the raised and lowered values.
NX1459623—UN—05MAY26

![[NX1459623.png]]
**Figure NX1459623**

Current Sensor Reading
Current Sensor Reading— displays the current sensor reading value.
NX1458204—UN—05MAY26

![[NX1458204.png]]
**Figure NX1458204**

Current Sensor Reading Out of Range
If the Current Sensor Reading value is red, then the current reading is either above the maximum raised reading value or below the minimum lowered reading value.
