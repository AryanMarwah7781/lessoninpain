# Clean Pressure Strainers—Daily

CAUTION: Spray system can contain hazardous material, which can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Clean filter in an area where people, animals, vegetation, water supply, and so on, cannot be contaminated.
NOTE: Clean the boom supply line strainers if the following conditions exist:
- Pump fails to obtain maximum flow rate.
- Pump fails to maintain dead head pressure.
- Application rates fluctuate.
- Difference between solution pump pressure and spray pressure is greater than expected for a given application.
NX1432687—UN—25NOV25

![[NX1432687.png]]
**Figure NX1432687** — A: Flowmeter Shutoff Valve

CAUTION: Do not close flowmeter shutoff valve (A) with the solution pump running. This can trap pressure in the system that can be hazardous when opening strainers for cleaning.
Do not drain solution onto the ground. Drain into a container. Drain solution in an area where people, animals, vegetation water supply, and so on, cannot be contaminated.

1. Close valves to prevent excessive solution loss:
a. Close flowmeter shutoff valve (A).
