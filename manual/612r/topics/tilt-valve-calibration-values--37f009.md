# Tilt Valve | Calibration Values

Tilt Valve | Calibration Values allow you to view the calibration values from the boom tilt valve calibration.
NOTE: Some of the following items are only displayed if machine is equipped with the associated option.
Items Accessible on Tilt Valve | Calibration Values Page:
N158677—UN—08FEB22

![[N158677.png]]
**Figure N158677**

Calibration Values
Calibration Values— displays the maximum, minimum, and range of detected values for each valve.
- Values displayed in red indicate that the value is outside the allowable range.
- Missing values are displayed as three dashes and indicate that there is no valid calibration.
NX1459969—UN—05MAY26

![[NX1459969.png]]
**Figure NX1459969**

Sensor Gauge
There is an indicator for each sensor, which displays the current electrical readings. The readings are displayed as a gauge as well as by their individual numerical values.
NX1459970—UN—05MAY26

![[NX1459970.png]]
**Figure NX1459970**

Tilt Sensor Range
Tilt Sensor Range— the shaded area of the gauge displays the range of readings, with the maximum value being the top of the range and the minimum value being the bottom of the range.
