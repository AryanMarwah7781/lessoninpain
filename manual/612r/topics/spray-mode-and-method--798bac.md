# Spray Mode and Method

Spray Mode and Method allows you to select the desired nozzle and solenoids to use during application. Available spray modes and methods depend on machine configuration.
Modify When:
- Application rates change.
- Application speeds change.
- You want to change the application method.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
If Equipped With Dual Product Solution System:
Spray mode options are available on machines equipped with dual product solution tanks. The available spray modes on the Spray Mode and Method screen vary depending on tank configuration. To change the tank configuration, refer to the Tank Configuration screen in the See & Spray System or Machine Profile display applications.
Available Spray Modes:
WZ1408781—UN—09JUN25

![[WZ1408781.png]]
**Figure WZ1408781**

A Only
A Only— the A (left-hand) solenoid is active. Solution is sprayed from the front spray tip only. Use for maximum speed ranges, better curve compensation performance, and 15 or smaller tip sizes.
A Only spray mode is available in the following tank configurations:
- Single - Independent Tank 2
- Single - Combined Tank Normal Flo
- Single - Combined Tank High Flow
- Dual Independent Tanks (Tank 2 Only)
WZ1408784—UN—09JUN25

![[WZ1408784.png]]
**Figure WZ1408784**

B Only
B Only— the B (right-hand) solenoid is active. Solution is sprayed from the rear spray tip only. Use for maximum speed ranges, better curve compensation performance, and 15 or smaller tip sizes.
B Only spray mode is available in the following tank configurations:
- Single - Independent Tank 1
- Single - Independent Tank 2
- Single - Combined Tank Normal Flow
- Single - Combined Tank High Flow
- Dual Independent Tanks (Tank 1 Only)
NOTE: To use B Only with Single - Independent Tank 2, open the Equipment Manager application. In the Machine Profile, select Tank Configuration and the Enable B Valve checkbox.
WZ1408782—UN—09JUN25

![[WZ1408782.png]]
**Figure WZ1408782**

A+B
A+B— both solenoids are active. Solution is sprayed from both front and rear spray tips. Use with size 15 or smaller spray tips.
A + B spray mode is available in the following tank configurations:
- Single - Combined Tank Normal Flow
- Single - Combined Tank High Flow
- Dual Independent Tanks
NOTE: When A + B spray mode is selected, the system can be configured to spray dual product or single product. Select Dual - Independent Tanks under Tank Configuration in Work Setup to spray two different products simultaneously. Select Single - Combined Tank Normal Flow or Single - Combined Tank High Flow to spray one product out of both nozzles A and B.
Select Single - Combined Tank High Flow configuration in A + B spray mode to achieve a higher combined flow rate than in Combined A + B spray mode.
WZ1408785—UN—09JUN25

![[WZ1408785.png]]
**Figure WZ1408785**

Combined A+B
Combined A+B— both solenoids are active. Solution is sprayed from the front spray tip. When pulsing is selected, the nozzle is pulsed at twice the pulse rate of a single nozzle. This mode is only available when spray tip 4, 5, or 6 is in the front position.
Combined A + B spray mode is available in the following tank configurations:
- Single - Combined Tank Normal Flow
- Single - Combined Tank High Flow
WZ1408783—UN—09JUN25

![[WZ1408783.png]]
**Figure WZ1408783**

Automatic
Automatic— nozzle control unit determines which solenoid or solenoid combination to operate. Solenoids are not pulsed in this mode. Solution is sprayed from the front, rear, or both spray tips. Use with size 15 or smaller spray tips.
Automatic spray mode is available in the following tank configurations:
- Single - Independent Tank 2
- Single - Combined Tank Normal Flow
- Single - Combined Tank High Flow
Available Spray Methods:
NOTE: On machines equipped with INC Pro, the spray method can only be changed for the front nozzle A.
WZ1408777—UN—09JUN25

![[WZ1408777.png]]

Broadcast
Broadcast— all nozzle tips will spray continuously across the entire boom.
WZ1408779—UN—09JUN25

![[WZ1408779.png]]
**Figure WZ1408779**

See & Spray
See & Spray— solution is sprayed from the B spray tip with 4, 5, or 6 in the rear position. Pulsing is not available in this mode.

Spray Method (machines with See & Spray or INC Pro)
1. On machines equipped with dual product solution systems, select Spray Mode and Spray Method. On machines with INC Pro, select Spray Method.
NOTE: Selecting either spray mode or spray method opens the same display application screen.
a94261—UN—24AUG18

![[A94261.png]]
**Figure A94261**

Spray Mode Radio Button
2. On machines equipped with dual product solution systems, select the radio button next to the desired spray mode.
a94261—UN—24AUG18
Spray Method Radio Button
3. Select the radio button next to the desired spray method.
NOTE: On machines equipped with dual product solution systems, spray method may need to be selected for both front and rear nozzles depending on tank configuration.
For example, Combined A+B spray mode includes both nozzles when selecting the spray method. Alternatively, the spray method may only need to be selected for the rear nozzles, such as when using the A+B spray mode.
On machines equipped with INC Pro, the spray method can only be changed for front nozzle A.

OK
4. Select the OK button to confirm.
