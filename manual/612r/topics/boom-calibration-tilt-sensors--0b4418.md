# Boom Calibration | Tilt Sensors

This procedure calibrates the boom tilt sensors. Tilt sensors must be calibrated so that automatic boom fold/ unfold and Return to Height operate correctly.
Perform Calibration When:
- Automatic boom fold/unfold is not operating correctly.
- Return to Height feature for tilt is not working properly.
- A sensor has been replaced.
