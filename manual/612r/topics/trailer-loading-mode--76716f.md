# Trailer Loading Mode

Trailer loading mode allows the operator to move a machine that is parked on an incline or slope forward without the machine rolling back. This mode can be used in the field or for loading the machine onto a trailer for transport. It is available in all speed ranges in both forward and reverse.
N166441—UN—08MAR24

![[N166441.png]]
**Figure N166441** — A: Brake Pedal; B: Multi-Function Lever

1. With the machine running, press down and hold brake pedal (A).
2. Move multi-function lever (B) out of the PARK position and push slowly forward or pull back. The hydro system attempts to start motion even with the brake applied.
3. Slowly release the brake and continue pushing the multi-function lever forward or pulling the multi-function lever back as needed.
