# Setup Wizard | Auto Prime

Setup Wizard | Auto Prime allows you to charge the solution system and direct injection plumbing with a chemical or mixed solution so that the sprayer is ready to begin spraying.
NOTE: Refer to Auto Prime Procedure for a step-by-step guide to using Auto Prime.
