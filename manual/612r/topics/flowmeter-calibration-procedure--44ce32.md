# Flowmeter Calibration Procedure

Procedure Requirements:
Engine State | Key ON
Wheel Speed | 0 km/h (0 mph)
Operating State | Parked, not applying product
Procedure Overview:
N118477—UN—14NOV16

![[N118477.png]]
**Figure N118477**

Input Box
1.Select the Input Box.
NOTE: Flowmeters utilized depend on tank mode configuration.
NOTE: The calibration values are stamped on tags attached to the flowmeters. Ensure that the flowmeter tag corresponds with the selected input box. (See Operator's Manual for flowmeter location.)
2.Enter the calibration value using the keypad.
N118151—UN—16FEB16

OK
