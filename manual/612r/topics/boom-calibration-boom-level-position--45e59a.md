# Boom Calibration | Boom Level Position

This procedure calibrates the roll angle in the boom sensor. Roll angle must be calibrated so that BoomTrac operates correctly.
Perform Calibration When:
- BoomTrac is not working properly.
- Roll angle sensor has been replaced.
