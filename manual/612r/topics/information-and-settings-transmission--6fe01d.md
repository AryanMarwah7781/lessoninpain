# Information and Settings | Transmission

Information and Settings | Transmission provides access to adjustable sensitivities and other transmission-related features.
Items Available on Information and Settings | Transmission:

Multi-Function Lever Sensitivity
Multi-Function Lever Sensitivity—increase the value to raise sensitivity of the Multi-Function Lever, decrease the value to lower sensitivity.

Acceleration Aggressiveness
Acceleration Aggressiveness—adjust the value to increase or decrease how quickly the machine accelerates.

Deceleration Aggressiveness
Deceleration Aggressiveness—adjust the value to increase or decrease how quickly the machine decelerates.
N144005—UN—08APR19

![[N144005.png]]
**Figure N144005**

Rate Control/Display Speed
Rate Control/Display Speed—displays the current source for speed readings. To change the speed source, press the box and a list of available sources to choose from will appear. Below are some examples of other sources:
- Radar Speed
- GPS Speed
- Wheel Speed
N142934C—UN—19JUN25

![[N142934C.png]]
**Figure N142934C**

Auto Idle
Auto Idle—automatically reduces the engine speed to idle once the multifunction lever is placed in the park position.
Select the checkbox to enable/disable Auto Idle.
Select the input box to open a keypad that allows you to adjust the delay time between when the multi-function lever is placed into park and when the engine speed drops to idle.
NOTE: Auto Idle is only available when the transmission is in Auto Mode. Auto Idle is disabled when using Manual Mode.
