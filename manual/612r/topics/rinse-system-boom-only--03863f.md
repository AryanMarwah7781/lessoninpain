# Rinse System | Boom Only

Boom Only allows you to remove spray solution from the solution pump, flowmeter, and boom plumbing when the solution tank still contains spray solution.
Perform Boom Only Rinse:
- Before servicing solution pump, flowmeter, or boom plumbing.
- As necessary to clean nozzle bodies and prevent tip plugging.
Boom Only Rinse Procedure:
CAUTION: Spray system can contain hazardous material, which can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use rinse system in an area where people, animals, vegetation, water supply, and so on, cannot be contaminated.
NOTE: Chemical buildup in aspirators can occur if not cleaned out thoroughly and regularly. To clean, close all nozzles except the aspirator nozzles during boom rinse.
Engine rpm reverts to the previous level when solution pump is turned off, if throttle position has not been adjusted.
NOTE: Rinse system can be operated from the load station using the keypad. See Operator’s Manual for more details.
1. Verify that the desired boom sections are enabled. See the Boom Sections tab of the Nozzle System application.

6. Press the Spray System Master switch on the multi-function lever. Boom rinsing begins.
7. A message confirming that boom rinse is complete appears on the screen and can be viewed in the Status Center on the display.
8. Close all nozzle bodies that are not on an aspirator. (See Operator's Manual for more information.)
9. Set aspirator nozzles to open positions. (See Operator's Manual for more information.)
WZ1406733—UN—27MAY25
Start
10. Select Start button to perform a second boom rinse. Rinse only one boom section at a time for 5—10 seconds until all sections are flushed.
NOTE: Rinsing all sections at once may not produce enough system pressure to properly flush boom plumbing. Active boom sections must be controlled from the cab using the Boom Sections tab of the Nozzle System application or the Boom Section Control Scroll Wheels on the CommandARM.
11. A message confirming that boom rinse is complete appears on the screen and can be viewed in the Status Center on the display.
12. Return nozzle bodies to previous positions.
