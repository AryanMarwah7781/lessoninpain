# Procedure | Machine AirRinse

This procedure purges residual solution from the pressure function and spray lines. Each circuit is purged individually using the on-board air compressor system.
Residual solution accumulates in the solution tank. Spray lines are purged to the tank via the recirculation return line. Product can then be drained for additional processing.
Procedure can be completed while moving or stationary with booms folded or unfolded.
