# Tank Fill Volume

Tank Fill Volume allows you to enter the current solution tank level using one of two presets. Tank fill volume must be used after adding solution to the tank to display the current tank volume accurately. Tank fill volume must be used to allow the low tank alarm to function properly and to allow you to verify that proper application rates are being achieved.
Modify When:
- Filling the tank with a known volume of liquid. Use tank fill presets 1 or 2.
- You want to know the current tank volume. Press the button with the target icon.
- Filling solution tank from empty.
- Adding to the solution in the tank.
