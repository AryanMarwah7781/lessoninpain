# Removing Machine from Storage

1. Lubricate Load Command pump and nurse arm.
2. Prime pump, if necessary. (See Fill Load Command Pump in Service section.)
3. Rinse Load Command system.
4. Evacuate Load Command system and sprayer booms.
5. Begin normal operation.
