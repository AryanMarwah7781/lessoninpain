# Operate Boom Return to Height

N153021—UN—11NOV20

![[N153021.png]]
**Figure N153021** — A: Center Boom Raise Switch; B: Center Boom Lower Switch; C: Left-Hand Boom Tilt (fold) Switch; D: Left-Hand Boom Tilt (unfold) Switch; E: Right-Hand Boom Tilt (fold) Switch; F: Right-Hand Boom Tilt (unfold) Switch

1. Enable boom return to height. (See Return to Height Mode in the Boom and Nozzles Application section.)
2. Select desired return to height mode. (See Height Mode in the Boom and Nozzles Application section.)
3. Move boom up or down and adjust boom wings to desired height.
4. Press the set to current position button on boom and nozzles main page.
5. Start spraying operation.
6. Boom responds as described in the Return to Height Mode Operation table.
Mode | Return to Height Action | Multi-Function Lever
Off Return to Height function inactive.
Controls function normally with no stop points.
Center | Center frame stops at set height, wings retain
full range of motion.
Press boom raise switch (A) to raise boom. Press and hold boom lower switch (B) to lower boom. Boom stops at set height. Wings can be tilted to desired location using boom tilt switches (C, D, E, and F).
Left and Right | Center frame has no set stop point, wings stop
at set tilt point.
Press left-hand and right-hand boom tilt switches (C and E) to tilt up boom wings. Press and hold left-hand and right-hand boom tilt switches (D and F) to tilt boom wings down to preset position. Center frame can be moved to desired position using boom raise and lower switches.
Left, Center, Right | Center frame and wings stop at set points. | Press boom raise switch (A) to raise boom.
Press and hold boom lower switch (B) to lower
boom. Boom stops at set height. Press left-
hand and right-hand boom tilt up switches (C
and E) to tilt up boom wings. Press and hold
left-hand and right-hand boom tilt down
switches (D and F) to tilt boom wings down to
preset position.
Return to Height Mode Operation
NOTE: Boom automatically stops at set point. Boom can be lowered or tilted beyond set point by pressing switch (B, D, or F) again.
"Boom Return to Height" remains active while boom is folding or completely folded. When lowering boom onto the boom cradle rests, boom may stop at set point if it is above the boom cradle rest height. Boom can be lowered or tilted beyond set point by pressing switch (B, D, or F) again.
