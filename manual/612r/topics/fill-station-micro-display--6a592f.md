# Fill Station Micro Display

N103598—UN—13MAY13

![[N103598.png]]
**Figure N103598** — A: Micro Display

The micro display (A) is located at the Fill Station and allows the operator to view various information during the loading process. There are three main screens that are visible during most operations showing a combination of pump speed, pump pressure and tank volume. The operator can toggle between these screens using the buttons on the micro display.
The micro display also allows the operator to select between options when using some functions, such as rinse procedures, and target filling. The buttons on the micro display perform various functions depending on what function is selected. Button functions can include toggle, select or confirm, and cancel.
