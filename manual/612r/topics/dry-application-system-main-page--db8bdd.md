# Dry Application System Main Page

N121528—UN—16FEB16

![[N121528.png]]
**Figure N121528**

Dry Application System
NOTE: Underscored text identifies that additional information is available within this section or another section of this publication.
Main page shown is for example only. Your main page may differ depending on options or connected equipment.
Number of bins available is determined by machine type and your input using the Machine Profile application. (See Machine Profile in the display Operator’s Manual for more information.)
Dry Application System application is used to configure the dry spreader to ensure the proper application of fertilizer or chemicals.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Spinner
Use When:
- Changing application rates.
- Changing the product being applied.
- Changing the spinner settings.
- Operating the roll tarp, chain oiler, and conveyor priming.
- Performing the Conveyor Feed Rate (CFR) calibration.
