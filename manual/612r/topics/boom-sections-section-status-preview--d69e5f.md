# Boom Sections | Section Status Preview

Boom Sections | Section Status Preview indicates the status of each boom section, allows you to turn sections ON/OFF, and allows you to customize sections.
Modify When:
- Spraying at a reduced width is required.
- Sections must be turned on one at a time.
