# Auto Prime Procedure

Procedure Requirements:
Boom State | Unfolded
Center Frame Position | Lowered position
Direct Inject Pumps | Primed
Direct Inject Pump Mode | AUTO
Spray System Setting | Rate mode
NOTE: Refer to Setup Wizard | Auto Prime for more information on items displayed on-screen.
Auto Prime Procedure:
N19498—UN—04JUN19

![[N19498.png]]
**Figure N19498**

Simulated Spray Speed
1. Select Simulated Spray Speed. Select plus (+) to increase or minus (-) to decrease desired level.
N119582—UN—02NOV16

![[N119582.png]]
**Figure N119582**

System Prime Volume
2. Select System Prime Volume.
N119584—UN—02NOV16

![[N119584.png]]
**Figure N119584**

Pump Prime Selections
3. If equipped with direct injection, select desired Pump Prime Selections.
N124435—UN—18NOV16

![[N124435.png]]
**Figure N124435**

Spray System Target Rate
4. Select the desired Spray System Target Rate using the Rate Select switches on the CommandARM.
WZ1409638—UN—17JUN25

![[WZ1409638.png]]
**Figure WZ1409638**

Spray System Target Rate
If desired rate is not available, select the Spray System Target Rate to change rate presets.
NOTE: Settings cannot be changed once procedure begins. A greyed out symbol is displayed on each setting when it cannot be changed.
N120497—UN—02NOV16

![[N120497.png]]
**Figure N120497**

Solution Pump
5. Press Solution Pump switch on the CommandARM.
N120251—UN—04JAN17

![[N120251.png]]
**Figure N120251**

Spray System Master
6. Press Spray System Master switch on the multi-function lever.
N118091—UN—16FEB16

![[N118091.png]]
**Figure N118091**

Progress Indicator
NOTE: A progress indicator is displayed under each pump when actively priming.
N118025—UN—09MAR16

![[N118025.png]]
**Figure N118025**

Checkmark
NOTE: A green checkmark is displayed under each pump when successfully primed.
If an error occurs during procedure, a message is displayed on-screen.
NX1458344—UN—05MAY26

![[NX1458344.png]]
**Figure NX1458344**

Boom Section Indicator
NOTE: Boom sections being primed are in green. Sections not being primed are empty.
n120245—UN—23FEB16

![[N120245.png]]
**Figure N120245**

OK
7. Select OK to close the application when procedure is complete.
