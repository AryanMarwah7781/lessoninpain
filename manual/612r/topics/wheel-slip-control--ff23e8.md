# Wheel Slip Control

Wheel slip control system is designed to provide additional tractive effort when needed. The system is always active and provides additional tractive effort to the non-spinning wheels when one or more wheels spin out. The wheel slip control system helps the machine avoid becoming mired; it does not keep wheels from “spinning out” when mired.
