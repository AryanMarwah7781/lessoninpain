# Front Load Station Micro Display

N161073—UN—02MAR22

![[N161073.png]]
**Figure N161073** — A: Micro Display

Front Load Station Micro Display
Micro display (A) on the front load station allows the operator to view various information during the loading process. There are three main screens that are visible during most operations showing a combination of pump speed, pump pressure, and tank volume. The operator can toggle between these screens using the buttons on the micro display.
The micro display also allows the operator to select between options when performing some functions, such as rinse procedures and target filling. The buttons on the micro display are used to toggle screens, select or confirm options, and cancel operations, depending on the specific machine function.
