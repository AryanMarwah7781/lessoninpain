Unlocked Height Mode

![[NX1458243.png]]
**Figure NX1458243**

Unlocked Height Mode
Unlocked Height Mode—allows the operator to set different boom height targets for the left wing, right wing, and center frame sections of the boom. This mode provides the highest level of manual control over boom height targets and is intended for situations where the wings must operate at heights different from the center frame to avoid obstacles or terrain-related interference.
In Unlocked Height Mode, BoomTrac will maintain each section at its own independently selected height setpoint rather than using a shared, uniform height across the full boom.
When to Use Unlocked Height Mode
Use this mode when the wings require a different operating height than the center frame to maintain proper clearance or avoid contact with the crop, soil, or field features. Typical scenarios include:
- Rough or highly uneven terrain.
Raising the wings above the center frame can help prevent the tips from dipping into the crop, striking the ground, or hitting sharp terraces or ridges.
- Operating in waterways, ditches, or rolling field transitions.
The center frame may need to stay low for target spray height while the wings must run higher for safe clearance.
- Field edges, obstructions, or boundaries.
Keeping a wing elevated can prevent contact with fences, posts, trees, washouts, or raised headlands.
- Specialty crops or fields with inconsistent canopy height.
When crop height varies across the boom width, the operator may choose to run one or both wings higher than the center to avoid leaf or tassel contact.
Locked Height Mode

![[NX1458245.png]]
**Figure NX1458245**

Locked Height Mode
Locked Height Mode—keeps the entire boom operating at the same height above the target (ground or canopy) by matching the wing heights to the established center frame height. This creates a uniform spray pattern across the full boom width.
- When operating in Locked Height Mode, only the center target height can be adjusted.
- Wing target heights are locked to match the center frame target height.
When to Use Locked Height Mode
- Recommended for most applications where consistent spray height across the full boom is critical for optimal coverage and drift control.
- Ideal when operating in fields with moderate to dense canopy, where maintaining a stable, uniform spray height prevents wings from reacting independently to noisy canopy variations.
- Useful in relatively smooth terrain, where the center frame height provides a reliable reference point for the rest of the boom.
