# Load Command

Load Command is a high-speed tank loading system. It displays the status and allows you to choose evacuation mode. Load Command evacuation allows you to remove the remaining solution from the system after the fill procedure. Evacuation helps prevent contamination between loads and removes excess weight from the system.
NOTE: Load Command system must be activated from the switch outside the cab near the coupler.
