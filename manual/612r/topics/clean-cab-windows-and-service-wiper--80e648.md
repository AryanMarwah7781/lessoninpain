# Clean Cab Windows and Service Wiper

- Use landing on left-hand side of machine to clean front, left-hand and rear cab windows. Use appropriate cleaning tools to reach front and rear glass from landing if necessary.
IMPORTANT: Do not manually move wiper arm, this could cause damage to the wiper mechanism.
- Use landing for replacing and servicing windshield wiper.
CAUTION: Avoid serious injury from falling. Do not stand on fuel tank.
- Use a commercial ladder to access the right-hand window for cleaning. If necessary use a suitable tool with extension.
