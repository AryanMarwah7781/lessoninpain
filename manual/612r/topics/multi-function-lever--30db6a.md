# Multi-Function Lever

NOTE: For information on how to fold and unfold the booms, see Boom Fold/Unfold Procedures.
N152958—UN—25NOV20

![[N152958.png]]
**Figure N152958**

Movements
Movements— multi-function lever can be pushed forward to move the machine forward, pulled backward to move the machine in reverse, and placed in the middle position to put the machine in a neutral state.
N152634—UN—25NOV20

![[N152634.png]]
**Figure N152634**

Quick Stop Switch
Quick Stop Switch— allows you to simultaneously shut OFF multiple systems in the case of an emergency.
N152635—UN—25NOV20

![[N152635.png]]
**Figure N152635**

IBS Reset
Index Boom Sections (IBS) Reset— use to restart all shut-off sections that are enabled.
N152636—UN—25NOV20

![[N152636.png]]
**Figure N152636**

IBS Left
IBS Left— use to sequentially shut off individual boom sections starting at the right-hand end of boom moving to the left.
N152637—UN—25NOV20

![[N152637.png]]
**Figure N152637**

IBS Right
IBS Right— use to sequentially shut off individual boom sections starting at the left-hand end of boom moving to the right.
N152638—UN—25NOV20

![[N152638.png]]
**Figure N152638**

HMS
Headland Management System (HMS)— allows you to configure how multiple machine systems function by pressing a single switch when leaving a headland.
N152639—UN—25NOV20

![[N152639.png]]
**Figure N152639**

Programmable Button F
Programmable Button F— press to activate configured function. (See Controls Setup Application for more information.)
N152641—UN—25NOV20

![[N152641.png]]
**Figure N152641**

Center Boom Raise/Lower
Center Boom Raise/Lower (Fold/Unfold)— push top of switch to raise the boom center section and bottom of switch to lower the boom center section.
N152640—UN—25NOV20

![[N152640.png]]
**Figure N152640**

Programmable Button E
Programmable Button E— press left or right side of switch to activate configured function. (See Controls Setup Application for more information.)
N152642—UN—25NOV20

![[N152642.png]]
**Figure N152642**

Left-Hand Boom Tilt
Left-Hand Boom Tilt (Fold/Unfold)— push top of switch to raise left-hand boom sections and bottom of switch to lower left-hand boom sections.
N152643—UN—25NOV20

![[N152643.png]]
**Figure N152643**

Right-Hand Boom Tilt
Right-Hand Boom Tilt (Fold/Unfold)— push top of switch to raise right-hand boom sections and bottom of switch to lower right-hand boom sections.
N152644—UN—25NOV20

![[N152644.png]]
**Figure N152644**

Spray System On/Off
Spray System On/Off— press to turn enabled boom sections ON and press again to turn OFF. Indicator light illuminates when spray system on/off is enabled.
NOTE: Spray System On/Off switch functions as the Spread System Master switch when dry spreader is installed.
N152645—UN—25NOV20

![[N152645.png]]
**Figure N152645**

AutoTrac Resume
AutoTrac Resume— allows you to activate the system.
N152646—UN—25NOV20

![[N152646.png]]
**Figure N152646**

BoomTrac Resume
BoomTrac Resume— allows you to activate the system.
N152648—UN—25NOV20

![[N152648.png]]
**Figure N152648**

Programmable Buttons A, B, C, and D
Programmable Buttons A, B, C, and D— depending on the machine options, the buttons are programmable to different functions. (See Controls Setup Application in Onscreen Help for more information.)
N152647—UN—25NOV20

![[N152647.png]]
**Figure N152647**

Speed Range Adjustment Wheel
Speed Range Adjustment Wheel— rotate adjustment wheel to change target speed.
Depress the adjustment wheel to toggle between Field 1 and Field 2 set speeds. The maximum speed using Field 1 is limited to the maximum field speed. To reach transport speeds, use Field 2.
