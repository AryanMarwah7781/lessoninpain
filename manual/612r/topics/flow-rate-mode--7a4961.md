# Flow Rate Mode

Flow Rate Mode allows you to choose between high, standard, intermediate (electronically-controlled valves only), and low flow rates. The correct flow rate must be selected to obtain the desired application rate.
If your machine is equipped with physical valves, the flowmeter and orifice valve positions must be changed manually to match the flow setting selected. If your machine is equipped with electronically-controlled valves, the valve positions will change automatically based on Flow Rate Mode selections.
Modify When:
- Changing application rates.
- Application speed changes significantly.
