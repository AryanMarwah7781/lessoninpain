# Auto Mode Tread Adjust Procedure

Auto Mode allows you to automatically adjust the tread width to the minimum or maximum tread width or one of the presets.
For more information on how to adjust the tread width using the buttons on the CommandARM, refer to Manual Tread Adjust Procedure.
Procedure to Modify:
N152896a—UN—18JUN25

![[N152896A.png]]
**Figure N152896A**

Tread Preset
1. Select the desired Tread Preset.
NOTE: Actual tread width may vary slightly from presets due to tire and wheel size differences.
For more information on the default preset tread width values and minimum and maximum tread width dimensions, refer to Tread Width Dimensions.
N118128—UN—10NOV16

![[N118128.png]]
**Figure N118128**

Edit Preset
2. Select the Edit Preset input box to change the tread width preset. Enter the desired tread width using the keypad if you want to change the value.
N152884—UN—08JAN21

![[N152884.png]]
**Figure N152884**

Start
3. Press the Start button to enable Auto Mode.
WZ1405096—UN—15MAY25

![[WZ1405096.png]]
**Figure WZ1405096**

Status
4. The page will display the status and update the actual tread width values as they move.
NOTE: The input fields will disable when system is in a working state.
For more information on the status indicator, refer to Tread Adjust | Status.
5. Slowly drive the machine forward.
NOTE: Tread adjust only operates while driving from 1 through 8 km/h (1 and 5 mph).
WZ1405087—UN—15MAY25

![[WZ1405087.png]]
**Figure WZ1405087**

Stop
6. If the tread adjustment needs to be stopped while still in progress, press the Stop button.
