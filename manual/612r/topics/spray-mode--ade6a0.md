# Spray Mode

Spray Mode allows you to select the desired nozzle and solenoids to use during application.
NOTE: For more information on spraying at varying application rates, see Multi-Rate.
Modify When:
- Application rates change.
- Application speeds change.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Select Solution System Type:
Standard Solution System
Dual Product Solution System
Standard Solution System
Spray Modes with Nozzle 1, 2, or 3 in Front:
A Only— the A (left-hand) solenoid is active. Solution is sprayed from the front spray tip only. Use for maximum speed ranges, better curve compensation performance, and 15 or smaller tip sizes.
B Only— the B (right-hand) solenoid is active. Solution is sprayed from the rear spray tip only. Use for maximum speed ranges, better curve compensation performance, and 15 or smaller tip sizes.
A + B— both solenoids are active. Solution is sprayed from both front and rear spray tips. Use with size 15 or smaller spray tips.
Automatic— nozzle control unit determines which solenoid or solenoid combination to operate. Solenoids are not pulsed in this mode. Solution is sprayed from the front, rear, or both spray tips. Use with size 15 or smaller spray tips.
Spray Mode with Nozzle 4, 5, or 6 in Front:
Combined A + B— both solenoids are active. Solution is sprayed from the front spray tip. When pulsing is selected, the nozzle is pulsed at twice the pulse rate of a single nozzle. This mode provides a higher flow rate for use with size 30 and smaller spray tips. This mode is only available when spray tip 4, 5, or 6 is in the front position.

Dual Product Solution System
Spray Modes with Nozzle 1, 2, or 3 in Front:
A Only— the A (left-hand) solenoid is active. Solution is sprayed from the front spray tip only. Use for maximum speed ranges, better curve compensation performance, and 15 or smaller tip sizes.
NOTE: A Only is not available with Single - Independent Tank 1.
B Only— the B (right-hand) solenoid is active. Solution is sprayed from the rear spray tip only. Use for maximum speed ranges, better curve compensation performance, and 15 or smaller tip sizes.

A + B— both solenoids are active. Solution is sprayed from both front and rear spray tips. Use with size 15 or smaller spray tips.
NOTE: When A + B spray mode is selected, the system can be configured to spray dual product or single product. Select Single - Combined Tank Normal Flow or Single - Combined Tank High Flow to spray one product out of both nozzles A and B.
Select Single - Combined Tank High Flow configuration in A + B spray mode to achieve a higher combined flow rate than in Combined A + B spray mode.
