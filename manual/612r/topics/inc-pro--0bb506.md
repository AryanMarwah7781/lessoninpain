# INC Pro

INC Pro tab allows you to view the system status, set the spray method, adjust nozzle boost values, change active spray tips, access broadcast pulsing settings, and select the auto pulsing target pressure.
NOTE: For more information on spraying at varying application rates, see Multi-Rate.
Items Accessible on INC Pro Tab:
WZ1408739—UN—09JUN25

![[WZ1408739.png]]
**Figure WZ1408739**

Status Indicator
Status Indicator— displays the nozzle sizes and turret positions selected for the front and rear positions.
WZ1408737—UN—09JUN25

![[WZ1408737.png]]
**Figure WZ1408737**

Nozzle Boost Buttons
Nozzle Boost Buttons— press the nozzle boost button to turn ON/OFF nozzle boost for the selected nozzle.
WZ1408741—UN—09JUN25

![[WZ1408741.png]]
**Figure WZ1408741**

Edit Setup
Edit Setup— press to edit the nozzle boost settings for all nozzles.
WZ1408778—UN—09JUN25

![[WZ1408778.png]]
**Figure WZ1408778**

Spray Method
Spray Method—select the desired application method for front nozzle A.
N127733C—UN—27APR26

![[N127733C.png]]
**Figure N127733C**

Active Spray Tips
Active Spray Tips— indicates which tip or tips are currently active. Selecting the nozzle tip icon opens the nozzle tip library.

![[WZ1408793.png]]
**Figure WZ1408793**

Broadcast Pulsing Mode
Broadcast Pulsing Mode— displays the selected pulsing mode that will be used with nozzles set to broadcast spray.
WZ1408757—UN—09JUN25

![[WZ1408757.png]]
**Figure WZ1408757**

Broadcast Pulsing Nozzle Flow
Broadcast Pulsing Nozzle Flow— displays the amount of flow from a nozzle when operating in fixed pulse mode. The input box is inactive when pulsing mode is set to Auto Pulsing or No Pulsing.

Auto Pulsing Target Pressure
Auto Pulsing Target Pressure— displays target spray pressures and allows them to be changed. Select an input box to change the target pressure.
