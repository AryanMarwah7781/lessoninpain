# Variable Rate Setup Procedure

Procedure Requirements:
Machine Location | Appropriate environment where
cameras can detect live plant
material
Engine State | Running at high idle
Solution Tank State | Filled with clean water
Boom State | Unfolded and within supported
spray heights
Spray Mode | Supported by See & Spray and
matches intended application
use
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Select Solution System Type:
Standard Solution System
Dual Product Solution System
