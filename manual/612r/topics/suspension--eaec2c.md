# Suspension

Suspension page allows you to adjust suspension settings.
Modify When:
- Frequent cornering requires stiffer chassis suspension. Enable airlock.
- Operating on hillsides. Enable airlock.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Items Accessible on Suspension Page:
Airlock Items:
NX1455637—UN—06APR26

![[NX1455637.png]]
**Figure NX1455637**

Airlock AUTO/ON/OFF
Airlock AUTO/ON/OFF—press to change the suspension airlock setting. Airlock helps reduce body roll when cornering and improves stability and recovery when operating on hillsides.
- When OFF is selected, suspension airlock is disabled.
- When ON is selected, airlock stiffens the chassis suspension at all times.
- When AUTO is selected, airlock stiffens the chassis suspension when excessive machine sway is detected and deactivates during normal operating conditions resulting in a smoother ride.
Run Page Modules
Modules for this application can be added to run pages using Layout Manager.

Airlock AUTO/ON/OFF— allows you to turn airlock AUTO/ON/OFF.
