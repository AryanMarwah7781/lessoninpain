# See & Spray Nozzle Control System (Dual Solution)

NX1451624—UN—20MAR26

![[NX1451624.png]]
**Figure NX1451624**

See & Spray is a row crop or fallow application solution to target weeds from crops, or green on green. The system utilizes an internal split tank that can spray up to two different products simultaneously in combination with dual product ExactApply nozzle bodies from ports A and B. Using external tank valves, these tanks can also be combined to spray one product out of ports A, B, or both simultaneously.
The image-processing system can identify weeds from crop within the processed image. After a target is identified and the sensitivity threshold set by the operator is exceeded, the system commands the associated ExactApply nozzle to "ON" at 100% duty cycle when a weed is detected. Throughout the remainder of this manual, “weeds” will be referred to as a “target.”
The system can be set up to have only nozzle B apply product when a target is recognized, or it can have nozzle A apply a traditional broadcast of product using the ExactApply system and activate nozzle B when a target is recognized using the See & Spray system.
NOTE: Nozzle B has limited ExactApply functionality when using the See & Spray system. Curve compensation and pulsing are disabled for nozzle B when the See & Spray system is active.
The See & Spray application on the display provides the operator with operation parameters, system health, and status information. The operator receives a notification on the display when the system inputs are out of range for optimal system performance.
The system application is composed of four user configurable settings:
(Details for each configurable setting will be described on the following pages.)
- Fallback mode
- Weed Size
- Spray buffer width
- Spray buffer length
