# Rate Control/Display Speed

Rate Control/Display Speed displays available speed sources for the rate control unit. Speed source must be adjusted based on ground conditions, availability of Global Positioning System (GPS) signal, and options installed.
Select Global Positioning System (GPS) When:
- Wheel slip is likely to occur.
- Performing normal operations.
Select Wheel Speed When:
- GPS signal is degraded.
- GPS is not installed.
- Wheel slip is not likely to occur.
