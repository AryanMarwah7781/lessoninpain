# Performance Related Alerts

If the system recognizes a performance-related condition that will activate the fallback mode for the affected nozzles, a window shade will drop down on the display to alert the operator of the condition so operating changes can be made.
See Operate Machine in the Operate See & Spray section for a list of drop-down notifications.
