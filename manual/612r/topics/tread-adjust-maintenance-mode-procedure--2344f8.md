# Tread Adjust Maintenance Mode Procedure

This procedure can be used to control the movement of treads manually when adjusting width. Treads can be moved individually or together, while moving or stationary.
NOTE: If the wheels are raised off the ground, then tread width can be adjusted while stationary.
Items Accessible on Tread Adjust Maintenance Mode Page:
N118407—UN—14NOV16

![[N118407.png]]
**Figure N118407**

Select Tread— current tread selected for adjustment.

![[N119104.png]]

Tread Outputs— view sensor readings and valve positions.

N118483—UN—10NOV16

![[N118483.png]]

Target Speed
1.Select the lowest target speed using the Target Speed switch on the multi-function lever.

Tread
2.Press the Select Tread input box.
3.Select the desired tread for adjustment.

4.If the transport lock has been enabled, press the Transport Lock switch to disable the transport lock.
5.Drive the machine slowly forward.

Tread IN
6.Press the Tread IN button on the CommandARM to adjust the desired tread width.
