# Multi-Function Lever Button Configuration

NX711654—UN—10APR26

![[NX711654.png]]
**Figure NX711654**

A1—Headland Management System (HMS) - allows to configure how multiple machine systems function by pressing single switch when leaving a headland. B1—Programmable Button F - press to activate configured function. (See Controls Setup Application for more information.) C1—Right-Hand Boom Tilt (Fold/Unfold) - push top of switch to raise right-hand boom sections. D1—Right-Hand Boom Tilt (Fold/Unfold) - push bottom of switch to lower right-hand boom sections. E1—Left-Hand Boom Tilt (Fold/Unfold) - push bottom of switch to lower left-hand boom sections. F1—Left-Hand Boom Tilt (Fold/Unfold) - push top of switch to raise left-hand boom sections. G1—IBS Right - use to sequentially shut off individual boom sections starting at the left-hand end of boom moving to the right. H1—IBS Left - use to sequentially shut off individual boom sections starting at the right- hand end of boom moving to the left. I1—Spray System Master - press to turn enabled boom sections ON and press again to turn OFF. Indicator light illuminates when spray system master is enabled. J1—Programmable Button E - press left or right side of switch to activate configured function. (See Controls Setup Application for more information.) K1—Center Boom Lower (Fold/Unfold) - push bottom of switch to lower the boom center section. L1—Programmable Button E - press left or right side of switch to activate configured function. (See Controls Setup Application for more information.) M1—Center Boom Raise(Fold/Unfold) - push top of switch to raise the boom center section. N1—Index Boom Sections (IBS) Reset - use to restart all shut-off sections that are enabled. O1—AutoTrac Resume - allows to activate the system. V1—Quick Stop Switch - allows to simultaneously shut off multiple systems in emergency. Z1—BoomTrac Resume - allows to activate the system.
