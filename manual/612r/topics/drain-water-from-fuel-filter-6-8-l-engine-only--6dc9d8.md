# Drain Water from Fuel Filter—6.8 L Engine Only

N154910—UN—31MAR21

![[N154910.png]]
**Figure N154910** — A: Primary Fuel Filter; B: Drain Valve

CAUTION: Always shut off engine, remove key, and set park brake before performing maintenance work on the fuel filter.
Drain filter by opening drain valve (B) on primary fuel filter (A).
Bleed the fuel system. (See Bleed Fuel System in this section.)
