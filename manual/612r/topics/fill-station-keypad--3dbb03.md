Raise cover (A) to access the keypad.
Keypad button functions are as follows:
- Fill Station Light (B)—turns the Fill Station light on/ off.
- Solution Pump On/Off (C)—turns the solution pump on/off (solution pump runs at 50% speed until adjusted).
- Menu Page (D)—displays additional functions on the micro display.
- Agitation On/Off (E)—turns agitation on/off (agitation volume must be set from the CommandCenter display in the cab).
- Eductor Rinse (F)—turns the eductor on/off. Rinse solution comes from a source selected by the operator. (Default eductor volume must be set from the CommandCenter display in the cab)
- Eductor On/Off (G)—turns the eductor on/off (default eductor volume must be set from the CommandCenter display in the cab).
- Push-on Fill (H)—press the button to begin filling with the nurse pump, press the button again when fill is complete.
- Pull-on Fill (I)—pressing the button begins fill process, pressing the button again stops fill process.
- Rinse Water Select (J)—pressing the button gives the operator access to the clean water for rinsing options.
- Rinse Cycle (K)—begins rinse procedure; full system or boom rinse can be selected using the micro display.
- Visual Nozzle Check (L)—allows operator to perform nozzle check. (See Perform Nozzle Check in this section.)
- Spray System On/Off (M)—turns the enabled spray sections on/off (spray sections must be enabled or disabled on the display).
Indicators (N) display the status (on-off) of the function controlled by that button. Indicator light ON indicates that the function is ON. Indicators can also display the setting that the function is using for operation.
Buttons (B—J and L) can be used to enter values 0—9 on the micro display when required.
