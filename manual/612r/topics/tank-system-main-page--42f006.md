# Tank System Main Page

WZ1406705—UN—27MAY25

![[WZ1406705.png]]
**Figure WZ1406705**

Tank System
NOTE: Underscored text identifies that additional information is available within this section or another section of this publication.
Main page shown is for example only. Your main page may differ depending on options or connected equipment.
Tank System application is used to manage solution level, agitation settings, target fill, and Load Command evacuation.
Modify When:
- Filling or adding solution to the tank.
- Changing low tank alarm level.
- Using target fill.
- Changing eductor and agitation levels.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Select Solution System Type:
Standard Solution System
Dual Product Solution System
