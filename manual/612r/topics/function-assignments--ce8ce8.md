# Function Assignments

Function Assignments is a list of functions that can be assigned to the reconfigurable buttons.
Single Position Function Assignments Available:
H118518—UN—20JAN17

![[H118518.png]]
**Figure H118518**

Center Track
Center Track— select to establish a new track.
H118520—UN—20JAN17

![[H118520.png]]
**Figure H118520**

Swap Track
Swap Track— select to change from the current guidance system track you are using and change to the next track.
H118521—UN—20JAN17

![[H118521.png]]
**Figure H118521**

Close Overlay
Close Overlay— select to close the overlay.
N134191—UN—20MAR19

![[N134191.png]]
**Figure N134191**

BoomTrac Pro Resume
BoomTrac Pro Resume— resumes BoomTrac control of the boom height.
N134194—UN—20MAR19

![[N134194.png]]
**Figure N134194**

Fence Row Nozzle
Fence Row Nozzle— turns the left-hand or right-hand fence row nozzle on or off.
N143724—UN—21MAR19

![[N143724.png]]
**Figure N143724**

Bin Chaining
Bin Chaining— select to initiate bin chaining between configured bins in the Dry Application System application.
Dual Position Function Assignments Available:
H118519—UN—20JAN17

![[H118519.png]]
**Figure H118519**

Shift Track
Shift Track— select to make left-hand or right-hand adjustments to your track.
H118522—UN—20JAN17

![[H118522.png]]
**Figure H118522**

Run Page Swap
Run Page Swap— select to change the displayed run page to the next or previous page in the system.
N134197—UN—20MAR19

![[N134197.png]]
**Figure N134197**

Tread Width Adjust
Tread Width Adjustment— adjusts tread width in or out.
N134192—UN—20MAR19

![[N134192.png]]
**Figure N134192**

Left-Hand Boom Tilt
Left-Hand Boom Tilt— raises or lowers the left-hand boom.
N134193—UN—20MAR19

![[N134193.png]]
**Figure N134193**

Right-Hand Boom Tilt
Right-Hand Boom Tilt— raises or lowers the right-hand boom.
