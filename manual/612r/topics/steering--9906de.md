# Steering

Steering page allows you to change four-wheel steering modes.
Modify When:
Needing to change between two-wheel steering and four-wheel steering.
Items Accessible on Tread Adjust Page:
Steering Mode Items:
WZ1405080—UN—15MAY25

![[WZ1405080.png]]
**Figure WZ1405080**

Steering Mode
Steering Mode— displays the active steering mode and current angle of the wheels.
NX1455652—UN—06APR26

![[NX1455652.png]]
**Figure NX1455652**

Max Speed
Four-Wheel Steering Max Speed— displays the maximum travel speed at which four-wheel steering is still engaged. Speeds above the maximum set speed causes the the machine to revert to two-wheel steering mode.
- Select the plus (+) symbol to increase the maximum speed.
- Select the minus (-) symbol to decrease the maximum speed.
- Select the current maximum speed value to open a keypad and enter the desired maximum speed.
