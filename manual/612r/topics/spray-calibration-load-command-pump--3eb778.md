# Spray Calibration | Load Command Pump

This procedure calibrates the Load Command pump. Load Command pump must be calibrated to load the solution tank properly.
Perform Calibration When:
- Load Command pump is replaced.
- Hydraulic motor assembly is replaced.
- Proportional valve is replaced.
- Hydraulic combo valve is replaced.
- Spray rate control unit is replaced.
- Load Command control unit is replaced.
