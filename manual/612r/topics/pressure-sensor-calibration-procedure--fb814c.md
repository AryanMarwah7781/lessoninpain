# Pressure Sensor Calibration Procedure

Procedure Requirements:
Engine State | Engine OFF, key in Run position
Wheel Speed | 0 km/h (0 mph)
Operating State | Parked, not applying product
Solution System | Empty and open to atmosphere
Readings Displayed on Page:
n161136—UN—02MAR22

![[N161136.png]]
**Figure N161136**

Solution Pump Pressure
Solution Pump Pressure— displays the pressure at the solution pump.
If equipped with a dual product solution system, the displayed solution pump pressure is for the selected solution system.
n161137—UN—02MAR22

![[N161137.png]]
**Figure N161137**

Spray Boom Pressure
Spray Boom Pressure— displays the pressure in the spray boom for the selected system.
If equipped with a dual product solution system, the displayed spray boom pressure is for the selected solution system.
Calibration Overview:
CAUTION: Do not drain solution onto the ground. Drain into a container. Drain solution in an area where people, animals, vegetation, water supply, and so on, cannot be contaminated.

![[N118095.png]]
**Figure N118095**

Next

2.Follow the messages on-screen to complete the procedure.

N118122—UN—02MAY16

Retry
1.Select the Retry button.
2.Verify that all requirements listed on-screen have been met.
3.If the calibration fails twice, contact your John Deere dealer or other service provider.
