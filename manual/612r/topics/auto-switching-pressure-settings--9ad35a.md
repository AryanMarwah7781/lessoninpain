# Auto Switching | Pressure Settings

Auto Switching | Pressure Settings allow you to select the nozzle tips to use and set the minimum and maximum pressures for those nozzle tips.
Modify When:
- Automatic mode is selected.
- The turret position is changed.
- The target rate is changed.
Items Accessible on Auto Switching | Pressure Settings Page:
N118434—UN—22JAN20

![[N118434.png]]
**Figure N118434**

Enabled Spray Tip
Enabled Spray Tip— allows you to enable or disable a spray tip or combination of spray tips.
N127733—UN—25JAN17

![[N127733.png]]
**Figure N127733**

Active Tips
Active Tips— displays the selected spray tip sizes for individual tips and a combination of those tips.
For the best results when using automatic nozzle selection, ensure that the larger spray tip is not more than double the size of the smaller tip. Example: Use a 03 tip with a 06.
N128456—UN—25JAN17

![[N128456.png]]
**Figure N128456**

Minimum Pressure
Minimum Pressure— the lowest pressure for the active spray tip that will maintain the desired rate and pattern.
Verify that the selected pressure is within the approved range for the selected spray tip size and provides the desired droplet size.
N128457—UN—25JAN17

![[N128457.png]]
**Figure N128457**

Maximum Pressure
Maximum Pressure— the highest pressure for the active spray tip that will maintain the desired rate and pattern.
Procedure to Modify:
N118434—UN—22JAN20
Checkbox
1. Enable the desired spray tips by selecting or deselecting the corresponding checkbox.
NOTE: The following conditions must be met before auto mode select is available: Valve pulsing set to OFF, nozzle body turret set in separate flow position (1, 2, or 3 in the front position), spray tips set up for both front and rear turret positions, and rate-based application selected.
N128456—UN—25JAN17
Minimum Pressure Input Box
2. Set the minimum pressure for each enabled spray tip. Select the Input Box to change the value.
N128457—UN—25JAN17
Maximum Pressure Input Box
3. Set the maximum pressure for each active spray tip. Select the Input Box to change the value.
4. Verify that the correct speed overlap is occurring by checking the values under the Auto Enabled Spray Speeds heading found on the Auto Switching screen.
