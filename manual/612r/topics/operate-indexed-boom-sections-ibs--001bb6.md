# Operate Indexed Boom Sections (IBS)

This machine is equipped with indexed boom section (IBS) switching. This gives the operator another way to shut off boom spray sections in sequence without removing their hand from the multi-function lever. An audible beep sounds when the buttons are pressed. This function is useful when working with point rows and waterways.
N153020—UN—11NOV20

![[N153020.png]]
**Figure N153020** — A: IBS Left Button; B: IBS Reset Button; C: IBS Right Button

There are three buttons. They operate as follows:
- Use IBS Left Button (A) to shut off the individual boom sections sequentially, starting at the right-hand end of the boom and moving to left.
- Use IBS Reset Button (B) to restart all shut off sections that are enabled.
- Use IBS Right Button (C) to shut off the individual boom sections sequentially, starting at the left-hand end of the boom and moving to right.
N155496—UN—18JUN21

![[N155496.png]]
**Figure N155496** — A: IBS Right Button; B: “L5” Boom Spray Section; C: “L4” Boom Spray Section; D: “L3” Boom Spray Section; E: “L2” Boom Spray Section; F: “L1” Boom Spray Section; G: “C” (center) Boom Spray Section; H: “R1” Boom Spray Section; I: “R2” Boom Spray Section; J: “R3” Boom Spray Section; K: “R4” Boom Spray Section; L: “R5” Boom Spray Section; M: IBS Left Button; N: IBS Reset Button

NOTE: Based on machine configuration and setup number of sections will vary.
EXAMPLE: If you are coming upon an angled waterway and you would like to shut off sections in sequence from left to right, press and release IBS right button (A) once to shut off left-hand outer boom section (B). Sections disabled by the IBS feature have a white background with an outlined box. Press and release button (A) again to shut off section (C). Continue to press and release the button (A) to shut off remaining sections across the entire boom.
Once all sections have been shut off, press and release button (A) again to turn ON section (B), then (C), and so on.
If only a few sections have been turned off using button (A), you can turn them back on in sequence one-at-a-time using the IBS left button (M) or turn them all back on at once using IBS reset button (N).
NOTE: The fence row nozzles shut off when the outermost boom sections are switched off.
If a boom section is disabled using the display, it is ignored when turning boom sections on-off using IBS function.
Sections can be shut off from the right-to-left using button (N).
