# Prepare Nurse Arm for Transport

CAUTION: Do not rely on load command nurse arm to hold solution in nurse tank. Close tank valve (A) on nurse vehicle before filling tank, before transporting, and when not in use.
N83462—UN—24FEB09

![[N83462.png]]
**Figure N83462** — A: Tank Valve

1. Close tank valve (A) on nurse vehicle.
N88463—UN—04JUN10

![[N88463.png]]
**Figure N88463** — A: Nurse Arm; B: Latch; C: Pin; D: Chain

2. Install nurse arm (A) into latch (B).
3. Install lock pin (C).
4. Install secondary locking chain (D).
