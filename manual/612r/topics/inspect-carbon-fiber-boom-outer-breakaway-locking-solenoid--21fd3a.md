# Inspect Carbon Fiber Boom Outer Breakaway Locking Solenoid

NOTE: Procedure for the right-hand side boom is shown. Left-hand side is similar.
1. Unfold boom and lower on to a suitable jackstand placed at intermediate joints and ends of boom.
2. Turn key to the OFF position.
NOTE: Solenoid does not have to be removed for cleaning drain holes, but is recommended.

3. Disconnect the harness connector (B).
4. Remove cap screws (C), bracket (D), and locking solenoid (A).
5. Inspect the solenoid drain holes (E) for cleanliness, clean as necessary using Electric Contact Cleaner (TY26632).Lubricate when cleaned with Super Lube Multipurpose Synthetic Lubricant (TY25733).
6. Inspect push pin for cleanliness, clean as needed.
7. Install in reverse order of removal.
