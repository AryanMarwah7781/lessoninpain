# Wheel Motor Calibration Procedure

Procedure Requirements:
Engine State | Running
Wheel Speed | 0 km/h (0 mph)
Operating State | In Park, not applying product
Calibration Overview:
N145174—UN—09JUN20

![[N145174.png]]
**Figure N145174**

Calibrate
1. Select Calibrate to begin the procedure.
2. Follow the messages on-screen to complete the procedure.
N118093—UN—16FEB16

![[N118093.png]]
**Figure N118093**

Save
3. Confirm the calibration by selecting Save.
If Calibration Fails:
N118122—UN—02MAY16

![[N118122.png]]
**Figure N118122**

Retry
1. Select the Retry button.
2. Verify that all requirements listed on-screen have been met.
3. If the calibration fails twice, see your John Deere dealer or service provider.
