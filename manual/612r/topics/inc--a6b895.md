# INC

INC allows you to access information about the nozzle system status and active spray tips.
Items Accessible on INC Tab:
WZ1408739—UN—09JUN25

![[WZ1408739.png]]
**Figure WZ1408739**

Status
Status— displays the overall status of the nozzle system. Selecting the status indicator opens the Nozzle Turret | Status screen, which provides more specific information about each nozzle turret.
