# Fill Load Command Pump

IMPORTANT: Load Command pump must have fluid prior to operating. Lack of fluid in pump could cause pump to malfunction.
N83590—UN—13MAR09

![[N83590.png]]
**Figure N83590** — A: Port

1. Unplug port (A).
2. Fill port with minimum of 3.7 L (1 gal) of water.
3. Plug port.
