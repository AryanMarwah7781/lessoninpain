# Enter Center Sensor Offset

WZ1407990—UN—04JUN25

![[WZ1407990.png]]
**Figure WZ1407990**

Center Sensor Offset
Sensor Offset is the distance from the bottom of the spray tip to the bottom of the sensor. Enter the center sensor offset from the bottom of the spray nozzle to the bottom of the sensor (3). A sensor located above the nozzles will have a positive number entered. A sensor below will have a negative number.
Procedure to Modify:
1. Measure the distance as described on screen.
2. Enter the measured distance using the keypad.
