# Use Remote Terminals

N99107—UN—17SEP12

![[N99107.png]]
**Figure N99107** — A: Remote Terminal

Use remote terminals (A) to provide power for operating auxiliary items (such as using shuttle tank pump to put chemicals into eductor).
IMPORTANT: Do not attempt to jump start machine from these terminals. They are protected with 30-amp fuse.
