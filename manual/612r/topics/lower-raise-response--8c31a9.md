# Lower/Raise Response

WZ1407979—UN—04JUN25

![[WZ1407979.png]]
**Figure WZ1407979**

Lower/Raise Response
Lower/Raise Response allows you to set the response speed of the boom lower/raise function.
Modify When:
- Spray boom response speed is not fast enough. Increase the lower/raise response.
- Spray boom motion is not smooth or continuously adjusts height when minimal terrain height difference is present. Decrease the lower/raise response.
Available Response Rates:
- Setting 1 (least aggressive)— for use on flat ground where boom motion should be minimized.
- Setting 2 (less aggressive)— provides a less active boom track for flat to gentle rolling terrain and mild water ways while maintaining good performance.
- Setting 3 (nominal position)— provides the best stability for booms when cornering or performing S-curve operations. This setting can be used for most operating conditions, including flat to moderately rolling terrain and waterway crossings.
- Setting 4 (more aggressive)— provides improved ability to protect booms when encountering moderate terraces, aggressive water ways, or ditches. Booms appear more active during all operations.
- Setting 5 (most aggressive)— provides improved boom height performance on significant terraces, aggressive water ways, or other terrain features. Booms appear active across all terrains and become less stable during hard cornering or performing S-curve operations.
Procedure to Modify:
WZ1407979—UN—04JUN25
Lower/Raise Response
Select the plus (+) symbol to increase or the minus (-) symbol to decrease the response rate.
