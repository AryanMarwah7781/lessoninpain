# Agitation | Solution System 1 and 2

Agitation | Solution System 1 and 2 circulates solution in the tank to aid in keeping chemicals in suspension. It is also used to mix chemical solution in the tank when required.
Modify When:
- Solution contents require more or less agitation.
- Manual control of agitation is desired. Turn off automatic agitation.
- Reduced risk of foaming at low solution levels is desired. Turn on automatic agitation.
Items Accessible on the Agitation Page:
WZ1406719—UN—27MAY25

![[WZ1406719.png]]
**Figure WZ1406719**

Auto Agititation Stop
Auto Agitation Stop— stops tank agitation when a preset amount of product is left in the tank. Press the button to turn Auto Agitation Stop ON/OFF.
Select the Input Box to change the amount of product remaining in the tank at which auto agitation stops.
WZ1406712—UN—27MAY25

![[WZ1406712.png]]
**Figure WZ1406712**

Agitation Level
Agitation Level— displays the current agitation level setting. Select the Input Box to change the agitation level.
NOTE: Agitation Level will be set to 100% if Power Agitation is turned ON.
- Use a lower agitation level for easily mixed products to minimize foaming.
- Use a mid-range agitation level for products not likely to foam.
- Use a higher agitation level for dry-flowable and heavy or thick liquids to keep them in suspension.
WZ1406713—UN—27MAY25

![[WZ1406713.png]]
**Figure WZ1406713**

Agitation Boost Level
Agitation Boost Level— uses separate boost nozzles to increase agitation at the set level. The Input Box displays the current agitation boost level setting. Select the Input Box to change the agitation boost level.
NOTE: Agitation Boost Level will be set to 100% if Power Agitation is turned ON.
WZ1406713—UN—27MAY25
Mechanical Agitation Level
Mechanical Agitation Level (if equipped)— displays the current agitation mechanical level setting. Select the Input Box to change the mechanical agitation level.

Input Box
2.Select the input box to change the auto off threshold.
This is the solution tank level when agitation is turned off.
NOTE: For automatic agitation to operate correctly, solution tank volume must be reset when tank is filled or solution is added. See Tank Fill Volume.
NOTE: The auto off threshold is the combined tank level from tank 1 and tank 2 when in combined tank mode. The input level is split between tank 1 and tank 2 depending on each tank volume proportional to the combined tank volume. Agitation for each individual tank will automatically turn off when the volume for that tank has reached the proportional threshold.
