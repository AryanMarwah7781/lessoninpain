# Remove RowSense Sensors and Bracket

NOTE: 410R is shown. 408R, 412R, 612R, and 616R are similar.
The right-hand side is shown. The left-hand side is similar.
RowSense brackets can remain installed with tires up to 420 mm (16.5 in) in width.
1. Set the machine to the widest tread setting.

4. Remove cap screws and nuts (A), P-clamps (B), and tie band (C).
5. Disconnect RowSense harness (D) from sensor harness (E).

6. Coil the RowSense harness and place it in storage location (A), securing with tie bands as needed.

Machine with Fenders Only
NOTE: If row-crop tires are to be used, then remove only the RowSense sensor assembly and lower bracket. The upper RowSense bracket will not interfere with the wheel and tire.
7.
For machines equipped with crop shields,
support the crop shield (A) and fender frame (B) using an appropriate lifting device.
8. For machines with fenders only, support fender frame (B) using an appropriate lifting device.
9. Support the RowSense bracket assembly (C) and remove cap screws (D).
10. Remove the RowSense bracket assembly from the machine.
NOTE: 408R, 410R, and 412R Only—Machines equipped with fenders and crop shields use M16 x 80 cap screws. Machines with fenders only use M16 x 70 cap screws.
612R and 616R Only—Four M16 x 70 cap screws are used on all machine configurations.
NOTE: Four cap screws (C) are used on the 612R and 616R.
11. Reinstall the fender mount using the previously removed hardware.
12. Reinstall the crop shield frame (if equipped) using the previously removed hardware.
13. Install the wheel motor cover using the previously retained hardware.
