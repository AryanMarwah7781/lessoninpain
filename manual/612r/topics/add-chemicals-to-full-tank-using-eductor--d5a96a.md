# Add Chemicals to Full Tank Using Eductor

N161198—UN—14MAR22

![[N161198.png]]
**Figure N161198** — A: Latch Lever; B: Eductor Handle; C: Eductor On/Off Button (tank system 1); D: Eductor On/Off Button (tank system 2)

NX1434998—UN—10DEC25

![[NX1434998.png]]
**Figure NX1434998** — A: Latch Lever; B: Eductor Handle; C: Eductor On/Off Button (tank system 1); D: Eductor On/Off Button (tank system 2)

CAUTION: Read the directions printed on the chemical manufacturer's labels carefully before handling chemicals to prevent exposure to hazardous materials that could cause injury or be poisonous.
IMPORTANT: Do not add chemical to the tank until just before field use. Follow the chemical manufacturer's instructions for mixing the spray solution to obtain the desired application rate and effect.
1. Pull on the latch lever (A) and unlatch the eductors.
2. Pull on handle (B) and rotate the eductors down into the fill position.
3. Raise the lid on the eductor for the desired tank system.
4. Press the eductor on/off button (C or D) on the load system keypad for the desired tank system.
NOTE: Do not start the eductor before the solution tank is half full to prevent foaming when the chemical is added. Tank level can be viewed using the micro display at the side load station and the sight gauge.
The operator can select different eductor pressure settings (1—3) using the CommandCenter display in the cab.
Setting 1 is the lowest pressure setting and 3 is the highest pressure setting.
The pressure can also be adjusted using the micro display.
NX1441266—UN—22JAN26

![[NX1441266.png]]
**Figure NX1441266** — A: Pump Speed Increase Button; B: Pump Speed Decrease Button

5. If necessary, adjust the eductor pressure using pump speed increase button (A) or pump speed decrease button (B).
N161210—UN—14MAR22

![[N161210.png]]
**Figure N161210** — A: Eductor Sump Valve (tank system 1); B: Eductor Sump Valve (tank system 2)

Eductor Sump Valves
6. Open the eductor sump valve (A or B) for the desired tank system. This valve allows chemicals to be drawn from the eductor hopper.
NX1441270—UN—22JAN26

![[NX1441270.png]]
**Figure NX1441270** — A: Eductor Rinse Button (tank system 1); B: Eductor Rinse Button (tank system 2)

7. Select the desired eductor to rinse using the load station keypad.
a. Select eductor rinse button (A) to rinse the system 1 eductor.
b. Select eductor rinse button (B) to rinse the system 2 eductor.
NX1441304—UN—22JAN26

![[NX1441304.png]]
**Figure NX1441304** — A: Rinse Button (from solution tank); B: Rinse Button (from rinse tank)

8. Select the desired rinse source using the micro display of the selected system.
a. Select rinse button (A) to rinse the eductor from the solution tank.
b. Select rinse button (B) to rinse the eductor from the rinse tank.

![[NX1441305.png]]

9. Select start button (A) to begin the rinse procedure. During the rinse procedure, box (B) appears around the selected rinse source on the micro display.
N161211—UN—14MAR22

![[N161211.png]]
**Figure N161211** — A: Eductor Rinse Valve (tank system 1); B: Eductor Rinse Valve (tank system 2)

Eductor Rinse Valves
NOTE: Turn the valve handle clockwise to open the valve.
10. To rinse the eductor hopper, open the eductor rinse valve (A or B) for the tank system being used.
11. Pour chemicals into the eductor.
N161214—UN—14MAR22

![[N161214.png]]
**Figure N161214** — A: Rinse Nozzle

Rinse Nozzle
N161212—UN—14MAR22

![[N161212.png]]
**Figure N161212** — A: Rinse Nozzle

Rinse Chemical Container
12. Place the chemical container over the rinse nozzle (A) in the tank and push down on the container to rinse.
13. Verify that the eductor is empty.
NX1441310—UN—22JAN26

![[NX1441310.png]]
**Figure NX1441310** — A: Eductor Rinse Button (tank system 1); B: Eductor Rinse Button (tank system 2); C: Eductor On/Off Button (tank system 1); D: Eductor On/Off Button (tank system 2)

14. To shut off the rinse, press eductor rinse button (A or B) on the load station keypad for the desired tank system.
15. To shut off the eductor fill, press eductor on/off button (C or D) on the load station keypad for the desired tank system.
16. Close the eductor rinse valve and the eductor sump valve.
17. Close the eductor lid and lift the eductors back to the original position.
