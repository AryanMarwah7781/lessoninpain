# Minimum Pressure

Minimum Pressure is maintained when 0 km/h (0 mph) ground speed is detected or if target pressure is below minimum set pressure for given application rate and nozzle tip size selected. This pressure setting must be higher than the nozzle check valve pressure to keep all check valves open, but not too high to prevent over application during normal speed adjustments in the field.
NOTE: This setting is typically 83—104 kPa (0.83—1.03 bar) (12—15 psi) and should be set below the spray pressure setting. If the setting is set near or equal to the spray pressure there will be fluctuations in rate/ pressure.
Modify When:
- Changing carrier solutions.
- Visual nozzle check valves are changed.
- Spray tip size or type is changed.
Procedure to Determine and Modify:
Determine and set the minimum pressure required using the following procedures:
1. Fill solution tank with carrier to be used.
2. Unfold booms. See Boom Fold/Unfold Procedures for more information.
3. Enable all spray sections. See See the Boom Sections tab of the Nozzle System application.
