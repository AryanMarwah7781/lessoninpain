# Auto Enabled Spray Speeds

Auto Enabled Spray Speeds display the speed ranges achievable for each active spray tip using the selected pressure settings. An overlap in speeds should occur between the highest speed for a smaller tip and the lowest speed for a larger tip or combination of tips.
