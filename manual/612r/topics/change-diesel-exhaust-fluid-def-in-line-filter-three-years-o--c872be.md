# Change Diesel Exhaust Fluid (DEF) In-Line Filter—Three years or 8500 Hours

CAUTION: Avoid possible personal injury. In case of DEF contact, immediately flush eyes with large amounts of water for a minimum of 15 minutes. Reference the Materials Safety Data Sheet (MSDS) for additional information. Do not ingest DEF. In the event DEF is ingested, contact a physician immediately. Reference the Materials Safety Data Sheet (MSDS) for additional information.
IMPORTANT: Avoid corrosion of vehicle parts or surfaces. If DEF is spilled or contacts any surface other than the storage tank, immediately clean the surface with clear water. DEF is corrosive to painted and unpainted metallic surfaces and can distort some plastic and rubber components. Spilled DEF, if left to dry or if only wiped away with a cloth, will leave a white residue. Improperly cleaned DEF spill may interfere with diagnosis of selective catalytic reduction (SCR) system leakage problems.
NOTE: See a John Deere equipment technical manual or OEM manufacturer’s technical manual for in-line DEF filter location.
IMPORTANT: Avoid system and filter damage. Ensure that DEF system is not frozen before changing filter. If system is frozen, operate engine until system has thawed completely.

DEF Fluid Removal
1. Remove drain plug with O-ring (A) and discard.
NOTE: Container must be DEF compatible and hold at least 300 mL (0.32 qt).
2. Drain DEF into a proper container.
RG30727—UN—08AUG18

![[RG30727.png]]
**Figure RG30727** — A: Filter Housing

Filter Removal
3. Rotate filter housing (A) counterclockwise and pull down.
4. Remove and discard filter from housing (A).
NOTE: If necessary, tap filter to loosen from filter housing (A).
RG30726—UN—08AUG18

![[RG30726.png]]
**Figure RG30726** — A: O-Ring; B: Foam Compensation Element; C: Filter Housing

Filter Housing Components
5. Remove and discard O-ring (A) and foam compensation element (B).
NOTE: Filter housing should be cleaned with clean DEF before installing new components to remove any sediment debris or contamination.
6. Install new O-ring (A) and foam compensation element (B) into filter housing (C).

![[RG30725.png]]
**Figure RG30725** — A: Filter; B: Filter Housing

Filter Housing and Components Installation
7. Install new filter (A) into filter housing (B).

In-Line DEF Filter Housing Installation
8. Install filter housing (A) with O-ring, foam compensation element, and filter element.
9. Rotate filter housing (A) clockwise and tighten to specification.
