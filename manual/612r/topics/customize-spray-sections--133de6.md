# Customize Spray Sections

Spray sections can be customized to include various numbers of nozzles. Sections can contain only one nozzle or several. All machines can be configured with up to 11 or 13 sections regardless of width or factory configuration. See Section Setup in the Boom and
Nozzles Application section for setup of the number of sections and number of nozzles per section.
NOTE: The total number of nozzles entered during setup must equal the number of nozzles installed on the machine.
