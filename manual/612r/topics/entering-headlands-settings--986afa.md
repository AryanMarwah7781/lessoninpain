# Entering Headlands Settings

Entering Headlands Settings allows you to enable or disable particular features when you are entering a headland. This assists the operator by automatically performing actions that the operator would otherwise have to perform manually.
For example, the system can be configured to turn OFF the Master Spray control or Master Spread control when a headland is entered.
