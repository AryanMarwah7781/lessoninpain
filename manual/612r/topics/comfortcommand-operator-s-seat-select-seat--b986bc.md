# ComfortCommand Operator’s Seat (Select Seat)

H128693—UN—03MAR20

![[H128693.png]]
**Figure H128693**

ComfortCommand Operator’s Seat (Select Seat)
ComfortCommand Operator’s Seat (Select Seat) is identified by a storage compartment in the left-hand armrest. Describes the controls for the select seat.
H127296—UN—26SEP19

![[H127296.png]]
**Figure H127296**

Fore/Aft Adjustment Handle
Fore/Aft Adjustment Handle— pull up on the handle to slide seat forward or rearward for the best working position.
N152694—UN—25NOV20

![[N152694.png]]
**Figure N152694**

Lateral Isolation Adjustment Handle
Lateral Isolation Adjustment Handle— push the handle forward to release side-to-side movement. Pull the handle rearward to lock.
H127097—UN—26SEP19

![[H127097.png]]
**Figure H127097**

Vertical Shock Dampener Control
Vertical Shock Dampener Control— limits amount of upward motion that the seat suspension provides. Push control forward for a soft ride or pull handle rearward for a firm ride. Between these two positions is medium firmness.
H127098—UN—26SEP19

![[H127098.png]]
**Figure H127098**

Fore/Aft Isolation Adjustment Handle
Fore/Aft Isolation Adjustment Handle— push control forward to lock forward or rearward movements. Push control rearward to allow forward or rearward movements.
H127099—UN—26SEP19

![[H127099.png]]
**Figure H127099**

Lumbar Adjustment Handle
Lumbar Adjustment Handle— rotate handle forward to increase lumbar support.
N152681—UN—25NOV20

![[N152681.png]]
**Figure N152681**

Seat Swivel Handle
Seat Swivel Handle— lift the handle to allow the seat to swivel. Push down on the handle to lock seat in position.
H127121—UN—26SEP19

![[H127121.png]]
**Figure H127121**

Backrest Angle Adjustment Handle
Backrest Angle Adjustment Handle— adjusts the seat back angle. Pull up on the handle and adjust backrest to desired position and release handle.
H127122—UN—26SEP19

![[H127122.png]]
**Figure H127122**

Armrest Height Adjustment Knob
Armrest Height Adjustment Knob— adjusts the left-hand armrest angle up or down. Rotate knob clockwise to decrease angle and counterclockwise to increase angle.
N152680—UN—25NOV20

![[N152680.png]]
**Figure N152680**

Weight/Height Adjustment Switch
Weight/Height Adjustment Switch— press and hold to increase or decrease seat height.
N152683—UN—25NOV20

![[N152683.png]]
**Figure N152683**

Left-Hand Armrest Height Adjustment
Left-Hand Armrest Height Adjustment— loosen the nut to adjust the left-hand armrest. Tighten the nut to lock the height into the desired position.
H117047—UN—22JUL21

![[H117047.png]]
**Figure H117047**

Right-Hand Armrest Control Console
Right-Hand Armrest Control Console— loosen knob and slide the armrest control console up/forward or down/back in slots on outer plate. Tighten knob.
