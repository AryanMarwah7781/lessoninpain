# BoomTrac | Diagnostics

BoomTrac | Diagnostics provides a list of prerequisites to aid you in troubleshooting system faults and errors. All prerequisites must be met before BoomTrac will operate.
Available Prerequisite Status Indicators:
WZ1405331—UN—16MAY25

BoomTrac Prerequisites:
- BoomTrac Active— press the BoomTrac Resume button on the multi-function lever to activate.
- BoomTrac Enabled— enable using the ON/OFF switch on the BoomTrac Main Page.
- Operator in Seat— the operator presence switch must detect that the operator is seated.
- Transmission in Field Range— the transmission is shifted to the correct speed range.
- Boom Unfolded— indicates the status of the inner fold sensors. An inner wing that is not unfolded completely will keep BoomTrac from operating. For more information on how to unfold the booms, see Boom Fold/Unfold Procedures.
- Boom Height and IMU Sensors Available for Control— the center sensor and one other sensor are functioning for control. The Sensor Icons on the BoomTrac main page indicate the status of each height sensor.
- Boom Fold Sensors Calibrated— the boom fold sensors were successfully calibrated. If necessary, perform the Auto Boom Fold/Unfold Calibration.
- Roll Sensor Present— the roll angle sensor has no faults. The current roll sensor reading can be viewed on the BoomTrac Main Page.
- Roll Sensor Calibrated— the boom level calibration is valid. If necessary, perform the Boom Level Calibration.
- Tilt Valves Calibrated— the tilt valves calibration is valid. If necessary, perform the Tilt Valves Calibration.
- Air Purge Inactive— actively performing the Boom Air Purge procedure prevents BoomTrac from functioning.
