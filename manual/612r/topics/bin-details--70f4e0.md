# Bin Details

Bin Details allow you to set up bin controls, operate the roll tarp, oil a chain, purge the bin, and prime the conveyor. Bins must be set up properly to achieve the selected target rate.
Modify When:
- Changing product.
- Changing the feed gate opening.
- Enabling or disabling a bin.
- Priming the conveyor.
- Purging a bin.
- Oiling chains.
- Operating bin covers.
