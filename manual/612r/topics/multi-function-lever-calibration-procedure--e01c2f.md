# Multi-Function Lever Calibration Procedure

Procedure Requirements:
Engine State | Engine OFF, key ON
Operating State | Parked
Multi-Function Lever Position | Park
Calibration Overview:
N145174—UN—09JUN20

![[N145174.png]]
**Figure N145174**

Calibrate
1.Select Calibrate to begin procedure.
2.Follow messages on-screen to complete procedure.
N118093—UN—16FEB16

![[N118093.png]]
**Figure N118093**

Save
3.Confirm Calibration by selecting Save.
If Calibration Fails:
N118122—UN—02MAY16

![[N118122.png]]
**Figure N118122**

Retry
1.Select Retry button.
2.Verify all requirements listed on-screen have been met.
3.If calibration fails twice, contact your John Deere dealer or other service provider.
