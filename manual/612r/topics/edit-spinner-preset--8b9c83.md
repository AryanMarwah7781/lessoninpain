# Edit Spinner Preset

Edit Spinner Preset configures the spinner target speed, spread width, and fan frame setting for the selected product blend. Spinner settings must be correct to ensure proper application pattern and coverage.
Modify When:
- Changing application product or mix.
- Product is pulverized by spinners.
- Desired spread width is not achieved.
- Adding a new preset.
