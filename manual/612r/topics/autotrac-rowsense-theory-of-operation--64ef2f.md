# AutoTrac RowSense Theory of Operation

N155450—UN—28APR21

![[N155450.png]]
**Figure N155450**

AutoTrac RowSense Sensor
CAUTION: Do not use the AutoTrac RowSense system on roadways. Always turn off (disable) AutoTrac RowSense system before entering a roadway. Do not attempt to turn on (activate) AutoTrac RowSense system while transporting on a roadway.
When the system is activated, stay alert and pay attention to the surrounding environment. Take control of steering when necessary to avoid field hazards, bystanders, equipment, or other obstacles. To operate and steer the machine safely, stop operation if poor visibility conditions impair steering ability.
IMPORTANT: The AutoTrac RowSense system is intended to aid the operator in performing field operations more efficiently. The operator is always responsible for the machine path and must continue to pay attention to the surrounding environment while operating the machine. To identify people or obstacles in the machine path, stop operation if poor visibility conditions impair steering ability.
Always operate machine from operator’s seat. Always use seat belt.
NOTE: Max tire width for row-crop is 380 mm (14.9 in) when operating in 762 mm (30 in) rows.
If the machine has AutoTrac RowSense, crop maturity and plant structure is susceptible to damage. Remove the RowSense paddles to avoid crop damage.
AutoTrac RowSense is comprised of the following components:
- Integrated AutoTrac installed and activated on the machine, with upgraded AutoTrac RowSense software programmed into the Steering System Unit (SBBC or SSU)
- AutoTrac RowSense License
- RowSense Sensors mounted to the machine
- StarFire Receiver with SF1, SF-RTK, or RTK License
AutoTrac RowSense is an enhancement to integrated AutoTrac on the CommandCenter Display. The row sensors mounted to the front suspension assemblies detect crop to know where the row is. Signals provided by the row sensors are integrated with existing AutoTrac signals to help keep the machine on rows. When there is no signal coming from the row sensors (for example, driving through a waterway), normal GPS guidance applies.
Most other characteristics of AutoTrac remain unchanged. The row sensor is simply another position input for steering the machine. All tracking modes are set up the same way as they are with GPS-based AutoTrac. Read and understand the AMS Applications CommandCenter Display Operator’s Manual.
