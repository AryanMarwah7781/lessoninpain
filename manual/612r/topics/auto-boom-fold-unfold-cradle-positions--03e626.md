Left Tilt
There are indicators for right-hand and left-hand tilt, which display the current amount of boom tilt as a percentage.
NOTE: Limits for carbon fiber tilt between 35% and 75%.

Current Position Value (Failed)

NX1460846—UN—06MAY26

![[NX1460846.png]]
**Figure NX1460846**

Set to Current
Set to Current— press to set the current boom tilt as the target position value.
Minimum— 0 percent, boom wing tilted fully down.
Maximum— 100 percent, boom wing tilted fully up.
