# Section Setup

Section Setup allows you to enter the number of nozzles and nozzle spacing for each section. Sections must be properly configured to obtain the desired application rate.
Modify When:
- The number of sections has changed.
- Band spraying.
- Custom plumbing configurations are installed.
Section Setup Procedure:
N118046—UN—30NOV16

![[N118046.png]]
**Figure N118046**

Section Setup
1. Select the section you want to change.
2. Change the Nozzle Count (the number of nozzles spraying on each section) and/or the Nozzle Spacing (the distance between nozzle bodies) as required.
NOTE: Section Width is automatically calculated based on the input number of nozzles and nozzle spacing. Total Boom Width is calculated based on the Section Width.
N118093—UN—16FEB16

![[N118093.png]]
**Figure N118093**

Save
3. Select the Save button to complete section setup.
N118394—UN—17FEB16

![[N118394.png]]
**Figure N118394**

Cancel
Select the Cancel button to return to the previous screen without making any changes to the configuration.
N118415—UN—30NOV16

![[N118415.png]]
**Figure N118415**

Reset
4. Select the Reset button to return the machine to the factory configurations. Any previous changes are lost.
