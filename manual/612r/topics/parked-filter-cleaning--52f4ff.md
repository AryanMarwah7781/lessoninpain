# Parked Filter Cleaning

Parked Filter Cleaning is a process that you initiate to clean the exhaust filter when required.
During the process, engine speed is controlled by the system and the machine must remain parked to complete procedure. Time required for the Parked Filter Cleaning process is dependent upon the level of exhaust filter restriction, ambient temperatures, and current exhaust gas temperature.
Perform When:
- Depending on the machine type or model year, the exhaust filter cleaning indicator is flashing on corner post display or a message displayed on-screen indicates that cleaning is required.
Parked Filter Cleaning is Commonly Caused By:
- Constantly disabling Automatic cleaning mode.
- Excessive idling.
- Use of incorrect fuel quality.
Request Filter Cleaning is Commonly Caused By:
- Ignoring machine request for Parked filter cleaning.
- Exhaust system components nearing the end of their service life.
Procedure to Modify:
CAUTION: When AUTO, PARKED, or REQUESTED cleaning is enabled, the exhaust temperature can be high under no load or light load conditions at certain times during the exhaust filter cleaning cycle.
Servicing machine or attachments during exhaust filter cleaning can result in serious personal injury. Avoid exposure and skin contact with hot exhaust gases and components.
During automated or manual/stationary exhaust filter cleaning operations, the engine runs at elevated idle and hot temperatures for an extended period. Exhaust gases and exhaust filter components reach temperatures hot enough to cause burns to people, or ignite or melt common materials.
IMPORTANT: Damage to exhaust cleaning components can occur if engine is turned OFF while performing exhaust filter cleaning or shortly after cleaning is complete.
NOTE: Parked Filter Cleaning requires 1 hour to complete. Request Exhaust Filter Cleaning requires 2 to 3 hours to complete.

Request Exhaust Filter Cleaning
IMPORTANT: If Request Exhaust Filter Cleaning is displayed, the system will not allow you to perform an exhaust filter cleaning. Contact your John Deere dealer or other service provider immediately so an exhaust filter cleaning can be performed.
2. Verify that the machine is configured for Parked Exhaust Filter Cleaning.
- Stop machine motion.
- Set engine speed to low idle.
- Engage park brake.
- Stop remote loading.
- Turn spray or spread system master OFF.
