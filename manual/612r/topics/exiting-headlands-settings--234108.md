# Exiting Headlands Settings

Exiting Headlands Settings allows you to enable or disable particular features when you are exiting a headland. This assists the operator by automatically performing actions that the operator would otherwise have to perform manually.
For example, the system can be configured to turn ON the Master Spray control or Master Spread control when a headland is exited.

Speed— enable to automatically change the machine target speed when exiting a headland. Select the Checkbox to enable/disable this feature.
When enabled, select the Input Box to change the exit speed.
n118434—UN—22JAN20
Checkbox
Auto Exit— allows the machine to automatically detect when it is exiting a headland. Detection is triggered when the section control working width is is greater than 0. Select the Checkbox to enable/disable this feature.
If Auto Exit is enabled when Master Spray OFF or Master Spread OFF are already enabled on the Entering Headlands Settings screen, Master Spray OFF or Master Spread OFF will be automatically disabled.
NOTE: Auto Exit may trigger unintentionally when part of the boom is over a portion of the field that has not been sprayed even if the rest of the machine is still fully in the headland.
