# Target Height

Target Heights are the distance from the bottom of the nozzle tips to the crop canopy or ground. Use the input boxes to adjust each boom section to the desired height.
WZ1408019—UN—05JUN25

![[WZ1408019.png]]
**Figure WZ1408019**

Target Height Input Boxes
Each boom section can be adjusted separately unless Height Mode is set to Locked. If Height Mode is set to Locked, only the center boom section input box allows changes. Change Height Mode to Unlocked to adjust the height of each boom section separately.
Procedure to Modify:
NOTE: Only the Center section input box allows changes if the Match Center Height mode has been selected in Advanced Settings.
