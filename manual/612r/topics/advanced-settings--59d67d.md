# Advanced Settings

Advanced Settings allow you to access further adjustments and less common settings.
Items Accessible on Advanced Settings Page:
NX1455939—UN—08APR26

![[NX1455939.png]]
**Figure NX1455939**

Button C with Independent Mode Enabled
Independent Mode—allows you to use assign two single position functions to a dual position button. This provides greater flexibility when assigning functions and the ability to assign more single position functions rather than being limited to dual position functions for dual position buttons.
WZ1406741—UN—28MAY25

![[WZ1406741.png]]
**Figure WZ1406741**

ON/OFF Button
Select the ON/OFF button to enable/disable independent mode for the selected button.
NOTE: Activating/Deactivating independent mode removes the current assignments from the selected button.
