# Sprayer Setup | Tank Configuration Icons

Sprayer Setup | Tank Configuration Icons explains the different tank configuration icons that are available on the Sprayer Setup screen.
To change the tank configuration settings, refer to the Tank Configuration screen.
Available Tank Configuration Icons:
Machines Equipped With Standard Solution System:
WZ1408715—UN—09JUN25

![[WZ1408715.png]]
**Figure WZ1408715**

Single Tank
Single Tank— only one solution tank is available on this machine.
NOTE: All other tank configuration icons apply to machines with dual product solution system.
Machines Equipped With Dual Product Solution System:
WZ1408713—UN—09JUN25

![[WZ1408713.png]]
**Figure WZ1408713**

Dual Independent Tanks
Dual Independent Tanks— solution tanks are configured to operate separately from each other. Apply different products from each tank.
WZ1408716—UN—09JUN25

![[WZ1408716.png]]
**Figure WZ1408716**

Single Independent Tank 1
Single Independent Tank 1— apply solution from tank 1. Solution tank 2 is inactive, but agitation is available.
WZ1408717—UN—09JUN25

![[WZ1408717.png]]
**Figure WZ1408717**

Single Independent Tank 2
Single Independent Tank 2— apply solution from tank 2. Solution tank 1 is inactive, but agitation is available.
WZ1408714—UN—09JUN25

![[WZ1408714.png]]
**Figure WZ1408714**

Combined Tanks
Combined Tanks— both tanks are operating together. Apply the same product from both tanks using a single solution pump when Normal Flow is selected or using both solution pumps when High Flow is selected.
