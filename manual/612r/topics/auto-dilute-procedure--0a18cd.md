# Auto Dilute Procedure

Auto Dilute Procedure allows you to view and change Auto Dilute settings and perform the Auto Dilute procedure.

N118021—UN—13JAN17

**Figure N118021**

![[WZ1409505.png]]

Dilution Options— select to choose whether the remaining product will be sprayed or drained once it has been diluted.

![[N158555.png]]

Spray Dilution Factor
Spray Dilution Factor— select to input the dilution factor of the liquid to be sprayed out after the first dilution cycle.
Select the Input Box to open the keypad and enter the spray dilution factor.

![[WZ1409506.png]]

Drain Dilution Factor
Drain Dilution Factor— select to input the dilution factor to be achieved at the end of the dilution process for the liquid that will be drained.
Select the Input Box to open the keypad and enter the drain dilution factor.
