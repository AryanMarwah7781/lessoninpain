# Spray Calibration | Pressure Sensor

This procedure calibrates the pressure sensor(s) for the solution system.
NOTE: This procedure requires exposing the system to the atmosphere by opening the sump and Quik-Fill valves and removing the boom strainer. Ensure that the tank is empty and boom plumbing is drained.
Perform Calibration When:
- Pressure sensor reading does not return to zero when the system is open to atmosphere.
- The pressure sensor has been replaced.
- Applied rate does not equal target rate.
- Boom pressure relief does not function.
