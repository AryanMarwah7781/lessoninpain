# CommandDrive Theory of Operation

CommandDrive is an electronically controlled system consisting of a single hydrostatic drive pump and wheel motors synced with the engine. This system maximizes the efficiency of the power train and provides improved system response, which allows the machine to maintain consistent application and transport speeds in challenging conditions while also reducing overall fuel consumption and cab noise levels.
On machines equipped with CommandDrive, the operator can choose from Manual and Auto performance modes.
Manual Mode
While operating in Manual mode, engine speed is adjusted manually by the operator with the throttle controls on the armrest. Anti-stall and engine overspeed features still apply.

Manual Mode Select
To activate, select Manual from the Transmission Mode selection on the display or change the engine speed while operating in Auto mode.
Auto Mode
NOTE: Auto mode operates within an engine speed range of 1350—2000 rpm.
While operating in Auto mode, the hydraulic transmission is automatically controlled to minimize engine rpm at all times. In light engine load conditions, the system automatically shifts up and throttles back. In heavy engine load conditions, the system automatically shifts down and throttles up.

Auto Idle
NOTE: Auto Idle is only available when the transmission is in Auto mode and no other machine functions require the engine speed to be higher than 900 rpm.
Operating in Auto mode also activates Auto Idle. With Auto Idle active, the engine rpm will automatically come down to minimum engine speed after a period of inactivity from the operator. The time length of the inactivity period can be adjusted by the operator between 1—30 seconds.

Auto Mode Select
To activate, set the throttle speed to maximum and select Auto from the Transmission Mode selection on the display. Engine speed is then determined by the control system. This mode can be activated while driving the vehicle.
The CommandDrive system also allows the operator to adjust the sensitivity of the multi-function lever and acceleration/deceleration aggressiveness. (See Information and Settings | Transmission in the CommandDrive Transmission Application section.)
