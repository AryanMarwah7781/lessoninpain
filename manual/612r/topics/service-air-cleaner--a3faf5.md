# Service Air Cleaner

When cautionary statement appears on bottom of monitor screen, caution indicator glows and alarm sounds. Replace PRIMARY filter element.
The smaller SECONDARY element should be removed only when being replaced. Replace secondary element every second primary element change.
(See Replace Primary and Secondary Engine Air Filters for procedures.)
