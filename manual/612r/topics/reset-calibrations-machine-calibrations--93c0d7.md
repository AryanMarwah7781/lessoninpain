# Reset Calibrations | Machine Calibrations

This procedure resets all machine calibration values to the factory defaults.
Perform When:
- Accurate calibration values cannot be replaced.
- Major machine components are replaced.
Items Accessible on Reset Calibrations | Machine Calibrations Page:
N119598—UN—02MAY16

![[N119598.png]]
**Figure N119598**

Reset
Reset—begin the reset procedure.
Procedure to Reset Calibrations:
NOTE: This process cannot be undone. Once calibrations have been reset, you will have to perform each calibration again.
N119598—UN—02MAY16
Reset
1.Select the Reset button.
2.The following calibrations are reset:
- AutoTrac Wheel Angle Sensor
- AutoTrac EH Valve
- Multi-Function Lever
- Speed Sensor
- Tread Adjust (if equipped)
