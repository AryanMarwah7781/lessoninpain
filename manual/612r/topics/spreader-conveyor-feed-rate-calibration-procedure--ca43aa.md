# Spreader | Conveyor Feed Rate Calibration | Procedure

Spinner Procedure Requirements
Procedure Requirements:
Engine State | Running at 1800 rpm minimum
Wheel Speed | Parked
Spinner State | Pulse width modulation (PWM)
valve disconnected (See
Operator's Manual for valve
location.)
Product Quantity Used per Test Bins 1 and 2 — 362.8 kg (800 lb) Bins 3 and 4 — 11.34 kg (25 lb)
Select Product Bin | Loaded with product to be spread
Catch Container | Large enough to catch the
amount of product to be
dispensed
NOTE: Calibration procedure requires the ability to capture the product dispensed from the spreader conveyor with the spinners off. Increasing the CFR increases the amount of product dispensed. Decreasing the CFR decreases the amount of product dispensed.
It is important to measure the actual product depth dispensed on the conveyor. Enter measured value at the Feed Gate Opening for accurate calibration and application.
Use the following table when prompted to input expected Conveyor Feed Rate (CFR) value.

IMPORTANT: Metric CFR value is based on a 1.0 centimeter feed gate opening. English CFR value is based on a 1-inch feed gate opening.
Before performing CFR calibration, ensure that product is dispensing all the way to the product funnels. This check is critical for the front bin (Bin 1) if a second product bin is installed. If the product is not dispersing all the way, the belt runs for a period without any product on it. This situation results in a false calibration value.

If Calibration Fails:
N120225—UN—23FEB16

![[N120225.png]]
**Figure N120225**

Repeat Calibration
1. Select the Repeat Calibration button.
2. Verify that all requirements listed on-screen have been met.
3. If the calibration fails twice, see your John Deere dealer or service provider.
