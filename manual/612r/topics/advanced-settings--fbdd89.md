# Advanced Settings

Advanced Settings allow you access to further adjustments and less common settings.
Items Accessible on Advanced Settings Page:
WZ1406741—UN—28MAY25

![[WZ1406741.png]]
**Figure WZ1406741**

Push-On Target Fill Alarm ON/OFF
Push-On Target Fill Alarm ON/OFF—select to turn ON/OFF the alarm for push-on target fill. When turned ON, an alarm will sound at the set value when filling from a nurse tank.
WZ1406739—UN—27MAY25

![[WZ1406739.png]]
**Figure WZ1406739**

Push-On Target Fill Alarm Level
Push-On Target Fill Alarm Level—select the Input Box to input the value for when the push-on target fill alarm will sound before the actual target fill amount is achieved.
NX1456144—UN—09APR26

![[NX1456144.png]]
**Figure NX1456144**

Auto Filling Offset Fill Pump Filling
Auto Filling Offset Fill Pump Filling—adjust when the target fill value is consistently over or under filling the tank.
WZ1406991—UN—28MAY25

![[WZ1406991.png]]
**Figure WZ1406991**

Eductor Level
Eductor Level—allows you to change the amount of suction produced in the eductor.
