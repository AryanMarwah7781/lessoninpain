# Exhaust Filter Cleaning Indicator

N120475—UN—06DEC16

![[N120475.png]]
**Figure N120475**

Exhaust Filter Cleaning Indicator
Exhaust Filter Cleaning Indicator illuminates when exhaust filter system is actively performing exhaust filter cleaning. When indicator is illuminated and flashing, a parked cleaning is required.
IMPORTANT: Final Tier 4/Stage IV: Damage to exhaust cleaning components may occur if the engine is turned OFF while performing exhaust filter cleaning or shortly after cleaning is complete. Alarm sounds and a warning message appears on the display. Start the machine and follow messages on the display to allow the components to cool.
