# CommandARM - Controls Setup

CommandARM Controls Setup is used to assign application and functions to the commandARM.
NOTE: See Function Assignments for a list of functions that can be set to the configurable buttons.
Items Accessible on the CommandARM Controls Setup Page:
H118139C—UN—20JUN25

![[H118139C.png]]
**Figure H118139C**

CommandARM
CommandARM Button—allows you to make assignments to the buttons on the CommandARM.
H125750C—UN—20JUN25

![[H125750C.png]]
**Figure H125750C**

Programmable Button
Button 1—is used for applications that require you to select a Single Position Function such as ON/OFF.
N153271C—UN—20JUN25

![[N153271C.png]]
**Figure N153271C**

Programmable Button
Button 2—is used for Dual Position Functions that require you to select from multiple positions, to increase or decrease a value, or to make a left-hand or right-hand adjustment.
NOTE: If equipped with Independent Mode, dual position buttons can also be assigned single position functions.
H118140C—UN—20JUN25

![[H118140C.png]]
**Figure H118140C**

Lock Indicator
Lock Indicator— illuminates to indicate that the control group lock button is locked.
