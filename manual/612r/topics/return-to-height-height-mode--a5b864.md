# Return to Height | Height Mode

Height mode raises/lowers the boom sections to set heights based on the settings you select. Height mode allows you to choose which boom sections are controlled by set points or have full range of motion.
To adjust the set heights, use the Set to Current button.
Modify When:
- Field terrain changes.
- Crop height changes.
Height Modes Available:
- OFF— height mode function is not active. All boom sections have full range of motion.
- Center— center frame stops at set height. Wings retain full range of motion.
- Left and Right— center frame has no set point. Wings stop at selected set point.
- Left, Center, Right— center frame and wings stop at selected set points.
