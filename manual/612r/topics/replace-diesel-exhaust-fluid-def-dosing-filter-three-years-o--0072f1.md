# Replace Diesel Exhaust Fluid (DEF) Dosing Filter—Three Years or 3500 Hours

CAUTION: DEF contains urea. Do not get the substance in eyes. In case of contact, immediately flush eyes with large amounts of water for a minimum of 15 minutes. Do not take internally. In the event DEF is ingested, contact a physician immediately. Reference Materials Safety Data Sheet (MSDS) for additional information.
IMPORTANT: If DEF is spilled or contacts any surface other than the storage tank, immediately clean the surface with clear water. DEF is corrosive to painted and unpainted metallic surfaces and can distort some plastic and rubber components.
Spilled DEF, if left to dry or if only wiped away with a cloth, leaves a white residue. An improperly cleaned DEF spill can interfere with diagnosis of selective catalytic reduction (SCR) system leakage problems.
N153904—UN—27JAN21

![[N153904.png]]
**Figure N153904** — A: Cap

1. Remove and retain cap (A).
N155011—UN—08APR21

![[N155011.png]]
**Figure N155011** — A: Equalizing Element; B: Filter Tool; C: Filter

2. Remove and discard equalizing element (A).
3. Check inside of the filter for color code (black or gray).
4. Insert same color end of the filter tool (B) into the filter (C) until a click is felt or heard. This indicates tool is fully engaged.
NOTE: If necessary, a tool such as a screwdriver can be inserted into the slot of the filter tool to assist in removal.
5. Pull filter tool to remove filter from the dosing unit.
6. Discard filter and tool.
7. Clean dosing unit threads and mating surfaces with distilled water.
8. Lubricate new filter O-rings with clean engine oil.
9. Install filter and new equalizing element.
10. Install cap and tighten to specification.
