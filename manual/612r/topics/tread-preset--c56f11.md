# Tread Preset

Tread Presets are set at the factory but can be changed by the operator.
For more information on the default preset tread width values and minimum and maximum tread width dimensions, refer to Tread Width Dimensions.

Edit Preset
Select the desired tread preset before performing the
Auto Mode Tread Adjust Procedure. If the desired tread width is not shown, select a tread preset you want to change and then select the Edit Preset input box.
NOTE: If you want to adjust the tread width manually without the use of preset values, use the CommandARM buttons. Refer to Manual Tread Adjust Procedure for more information.
