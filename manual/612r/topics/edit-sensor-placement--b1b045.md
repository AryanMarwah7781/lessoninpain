# Edit Sensor Placement

Edit Sensor Placement allows you to set the current distance from the center of the machine and the current distance from the spray tip to the bottom of the sensor.
IMPORTANT: Except for the center sensor, when one sensor is repositioned on the boom its corresponding sensor must also be moved. Both sensors must be the same distance from the center of the boom and have the same offset.
Modify When:
- The system is installed for the first time.
- A sensor is relocated due to interference.
