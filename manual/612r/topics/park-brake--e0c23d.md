# Park Brake

IMPORTANT: Pressing the park brake switch applies the park brakes at vehicle speeds below 0.8 km/ h (0.5 mph).
If park brake switch is engaged, it must be manually disengaged before moving machine. Park brakes will not automatically release when park brake switch has been engaged.
NOTE: Park brake switch does not need to be engaged when parking machine. Park brakes are automatically applied when multi-function lever is in park position.
Park brakes will automatically be disengaged when multi-function lever is moved from the park position if the park brake switch has not been engaged.
