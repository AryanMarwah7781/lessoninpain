# Performance Mode

Performance Mode allows you to optimize fuel efficiency and load control.
Modify When:
- Desiring automated control of fuel economy and load control.
- No automatic control is desired.
Performance Modes Available:
Auto— automatically adjusts Fuel Economy and Minimum Engine Speed, allowing the machine to use the most fuel efficient engine speed for the current load.
Manual Mode— you are in full control of machine operation. Transmission and engine react to manual control inputs. No Fuel Economy or Load Control functions are active.
Procedure to Modify:
