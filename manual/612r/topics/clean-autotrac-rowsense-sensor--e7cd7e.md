# Clean AutoTrac RowSense Sensor

N155450—UN—28APR21

![[N155450.png]]
**Figure N155450**

AutoTrac RowSense Sensor
CAUTION: To avoid serious injury or death, shut OFF the engine, set the parking brake, and remove the key prior to cleaning the row sensor.
The AutoTrac RowSense sensor should be checked daily to see if cleaning is necessary.
If material has accumulated on the sensor, it may prevent free movement and affect performance. To clean the row sensor, remove debris from the sensor and surrounding area at both sides of machine.
Check that the sensor paddles move freely without obstruction.
Verify that all hardware is tight and is not missing.
