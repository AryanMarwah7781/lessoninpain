# Load Station Rinse—Independent Tank 2 with B Valve Enabled

System Rinse
NX1441530—UN—22JAN26

![[NX1441530.png]]
**Figure NX1441530** — A: Rinse Cycle Button

NOTE: System rinse must be set up using the display before the rinse procedure can be operated from the Fill Station. (See the Rinse System Application section of this manual.)
The operator must still open eductor valves manually to rinse the hopper.
1. Press rinse cycle button (A) on the keypad.
NX1441531—UN—22JAN26

![[NX1441531.png]]
**Figure NX1441531** — A: Solution System Rinse Button

2. Press solution system rinse button (A) on the system 2 micro display.
NX1441683—UN—22JAN26

![[NX1441683.png]]
**Figure NX1441683** — A: System 2 Rinse Button

3. Press system 2 rinse button (A) to begin the rinse procedure.
NX1441535—UN—22JAN26

![[NX1441535.png]]
**Figure NX1441535** — A: Skip Button; B: Cancel Button

NOTE: When rinsing the eductor, the operator must manually open the eductor rinse and sump valves when the display shows that portion of the rinse cycle.
4. Follow the procedure progress shown on the display. The following systems are rinsed:
- Eductor
- Agitation
- Equalizer
- Recirculation
- Solution Tank
- Boom
5. Press skip button (A) to skip to the next step of the procedure if desired.
6. Press cancel button (B) to end and exit the rinse procedure if desired.
7. The rinse procedure automatically stops when complete.
NX1441650—UN—22JAN26

![[NX1441650.png]]
**Figure NX1441650** — A: Solution Pump On-Off Button (system 2); B: Spray System On-Off Button

8. Press solution pump on-off button (A) on the keypad to turn on the system 2 solution pump.
9. Press spray system on-off button (B) to spray out rinsate through the boom.
10. Turn off the spray system and solution pump when the tank runs empty.
