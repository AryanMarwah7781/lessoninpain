# Yaw Valve Calibration Procedure

Procedure Requirements:
Boom State | Fully unfolded
Hydraulic Oil Temperature | Above 43° C (110° F)
Calibration Overview:
IMPORTANT: This procedure requires unfolding the inner boom and will automatically roll damper valves. Ensure that adequate space is available.
NX1460858—UN—06MAY26

![[NX1460858.png]]
**Figure NX1460858**

Begin Calibration
1.Select Begin Calibration to start the procedure.
2.Follow the messages on-screen to complete the procedure.
N158675—UN—19JUN25

![[N158675.png]]
**Figure N158675**

Calibration Values
3.After the calibration has finished, select Calibration
Values if you want to view the values detected during the calibration.

![[WZ1408298.png]]
**Figure WZ1408298**

Save
4.Confirm the calibration by selecting Save.
If Calibration Fails:
N118122C—UN—27JUN25

![[N118122C.png]]
**Figure N118122C**

Retry
1.Select the Retry button.
2.Verify that all requirements listed on-screen have been met.
3.If the calibration fails twice, see your John Deere dealer or service provider.
