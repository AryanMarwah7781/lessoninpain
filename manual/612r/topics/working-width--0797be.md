# Working Width

N124860—UN—30NOV16

![[N124860.png]]
**Figure N124860**

Working Width
Working Width is automatically calculated by the spray rate control unit based on the number of sections, section configuration, and the number of outer nozzles turned off.
N118017—UN—30NOV16

![[N118017.png]]
**Figure N118017**

Working Width
Adjustments to Working Width (1) may require changes in Track Spacing (2) as a result.
If working width displayed is not equal to expected width, then verify the following:
- Nozzle Setup is correct.
- Proper number of Boom Sections are enabled.
- Total number of boom sections entered in Advanced Settings is correct.
- Section Setup information is entered correctly in Advanced Settings.
