# See & Spray Detection

NOTE: Some items below are only displayed if machine is equipped with the associated option.
This procedure is used to verify the operation of the See & Spray system. A red object is used as the detection tool for this procedure. The detection tool is placed in front of the cameras to verify that the system is triggered. This determines if the intended targets will trigger the system and achieve the desired results or if adjustments are needed.
Recommendations:
- Complete the Service Spray Equipment Safety Procedure.
- Fill the tank(s) with water.
- Park the machine on an appropriate non-red topography.
- Complete the Nozzle Flow Check before starting this procedure to ensure proper flow.
- Stand upwind and in front of the boom.
- Set boom height between 500—1200 mm (20—47 in).
