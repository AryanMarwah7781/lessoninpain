# Fallback Mode

Fallback Mode allows you to configure the spray method that is engaged when See & Spray operational conditions are not satisfactory. The triggers for fallback mode are boom height, speed, and camera health. The factors that affect camera health include dust, obstructions, and low-light conditions.
- Select Off if you want the system to turn off if conditions fall below a trigger level. This setting results in higher product savings. Using this setting may require additional passes in the same field to maximize coverage.
- Select Broadcast if you want the system to continue to spray in a broadcast pattern if conditions fall below a trigger level. This setting results in maximized coverage. Using this setting may result in lower product savings. Select Broadcast if the top priority is to apply product to the target.
