RowSense Sensor Adjustment
For crop row spacing smaller than 762 mm (30 in), adjust sensor assembly (A) to the appropriate poistion (B—D) on the sensor mounting bracket.
For 762 mm (30 in) crop row spacing, install the sensor assembly at position (E) on the sensor mounting bracket.
For crop row spacing larger than 762 mm (30 in), extension kit BPF11507 must be ordered so that the sensor mounting brackets can be replaced.
