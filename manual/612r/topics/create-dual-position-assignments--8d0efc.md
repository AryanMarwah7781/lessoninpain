# Create Dual Position Assignments

Create Dual Position Assignments to assign and activate your preferred applications, then make function assignments. Use the controls setup reconfigurable buttons to personalize your machine and perform tasks quickly with the press of a button.
For more information on which reconfigurable buttons can be assigned dual position assignments, see Multi-Function Lever - Controls Setup and CommandARM - Controls Setup.
Procedure to Modify:
NOTE: The example shown is typical for making application assignments. For a list of available application or function assignments, see Application Assignments or Function Assignments. This example shows assigning the AutoTrac Guidance application to reconfigurable button C.
H117027C—UN—20JUN25

![[H117027C.png]]
**Figure H117027C**

Control Group Lock
1. Press the Control Group Lock button on the CommandARM.
NOTE: Light is on when locked. Light is off when unlocked. When unlocked, applications and functions may be modified.
N153276C—UN—20JUN25

![[N153276C.png]]
**Figure N153276C**

Dual Position Assignment Button
2. Select the desired dual position assignment button that you wish to assign the control to. Button C is selected in this example.
NOTE: Programmable buttons are rocker switches. They are programmed one way. Example: Left = down (close) and right = up (open).
N153595C—UN—20JUN25

![[N153595C.png]]
**Figure N153595C**

Select Application
3. Select to activate the Select Application display.

Remove Assignment
