# ExactApply

ExactApply tab allows you to view the system status, set the spray mode, adjust nozzle boost values, change active spray tips, and select auto pulsing target pressure.
NOTE: For information on how to diagnose ExactApply issues, see ExactApply| Troubleshooting.
For more information on spraying at varying application rates, see Multi-Rate.
Modify When:
- Adjusting the target pressure to achieve the desired droplet size.
- The specific gravity of the solution changes.
- Changing the spray mode.
- Changing the auto pulsing target pressure.
