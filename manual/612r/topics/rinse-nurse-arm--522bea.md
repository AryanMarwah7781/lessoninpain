# Rinse Nurse Arm

IMPORTANT: Do not pressurize nurse arm plumbing beyond pressure capacity of hose and components.
N83157—UN—03FEB09

![[N83157.png]]
**Figure N83157** — A: Port

NOTE: Port (A) on nurse arm coupler allows operator to manually rinse and drain nurse plumbing as needed.
Rinse nurse arm with normal Load Command fill cycle.
1. Fill nurse tank with rinse water and rinse agents.
2. Run fill cycle.
