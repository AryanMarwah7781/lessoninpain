# BoomTrac Status

BoomTrac Status displays the status of the BoomTrac system and a message about that status. The boom height sensor icons also indicate the status of each sensor.
NOTE: The BoomTrac | Diagnostics page opens when attempting to activate BoomTrac without having all prerequisites met, and a message informs you which prerequisite is not met.
