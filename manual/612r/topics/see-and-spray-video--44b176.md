# See & Spray - Video

See & Spray - Video allows you to access live video feeds and toggle between available cameras. Detected targets are highlighted in blue. When a See & Spray capable crop type is selected, the identified crops (non-target) are highlighted in green.

Video Feed
Video Feed— displays the live video feed from the selected camera.
When Using Targeted Herbicide:
- Dark Blue— detected targets that are being sprayed.
- Light Blue— target detected but ignored due to weed size.
- Green— system identifies as selected crop.
- No Color Overlay— no crop or targeted weeds are detected in these areas.
When Using Variable Rate:
- Dark Blue— detected targets that are being sprayed.
- Light Blue and Green— should not be seen while using Variable Rate.
- No Color Overlay— no targeted weeds are detected in these areas.
