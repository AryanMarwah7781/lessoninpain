# Spray Calibration | Solution Pump

This procedure calibrates the solution pump. The solution pump must be calibrated in order to achieve the desired application rate and maintain the desired solution pressure.
Perform Calibration When:
- Solution pump is replaced.
- Hydraulic motor assembly is replaced.
- Proportional valve is replaced.
- Hydraulic combo valve is replaced.
- Spray rate control unit is replaced.
- Pump values A and B are not within correct ranges.
