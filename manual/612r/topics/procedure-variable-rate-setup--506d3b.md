# Procedure | Variable Rate Setup

This procedure is used to verify the operation of the See & Spray variable rate system. The procedure uses camera detections of live plant material to command rate based upon See & Spray Variable Rate biomass and rate settings.
Ensure that minimum and maximum rate, test speed, nozzle tip(s), and spray mode align to intended application to verify ability to achieve minimum and maximum rates.
Use Variable Rate Setup When:
- Performing the first application of the spray season.
- A See & Spray camera has been replaced.
- Testing a configuration of settings, nozzle tips, and crops that have not been used before.
