# Spray Tip Selection

Each spray tip type is designed to produce a specific spray pattern. Spray tips are offered in different sizes to achieve the desired application rates. See the Wet System section in your machine Operator’s Manual for more information on each spray tip type.
Some spray tips create an angled spray pattern. Do NOT alternate the direction of the angle when using these tip types. Skips can occur when operating in automatic or fixed pulsing modes and the angle directions are alternated.
The nozzle calculator is only accurate if the same spray tip type and size on the entire boom width without nozzle pulsing.
