# Install and Position Nozzle Tips and Strainers

1. Use the nozzle tip calculator to determine size of tips.
2. Install nozzle tips.
N33978—UN—05JUN89

![[N33978.png]]
**Figure N33978** — A: Flat Spray (weed Control, broadcast, pre-emerge); B: Cone Spray (insect control); C: Flood Spray (broadcast); D: Even Spray (banding)

3. Position nozzles for the desired spray pattern. Set flat or even nozzles (A—D) so the slot in the bottom is at right angles to the row.
N135932—UN—02MAR18

![[N135932.png]]
**Figure N135932** — A: Slotted Adjustment Hole

N135933—UN—02MAR18

![[N135933.png]]
**Figure N135933** — A: Slotted Adjustment Hole

4. Boom nozzle section brackets are slotted (A) for adjustment. Loosen hardware to raise or lower the nozzle section.
5. Install strainers if desired. Several different-sized mesh strainers are available. (See a John Deere dealer or other service provider.)
N42173CZ—UN—26NOV96

![[N42173CZ.png]]
**Figure N42173CZ** — A: One Nozzle per Row (broadcast); B: Two Nozzles per Row (broadcast); C: One Nozzle per Row (banding); D: Two Nozzles per Row (banding); E: Three Nozzles per Row (banding)

6. Position nozzles for either broadcast spraying (A—B) or banding (C—E).
