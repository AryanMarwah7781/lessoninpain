# Enter Sensor Offset

N118041C—UN—20JUN25

![[N118041C.png]]
**Figure N118041C**

Sensor Offset
Sensor Offset is the distance from the bottom of the spray tip to the bottom of the sensor. Enter the outer sensor offset from the bottom of the spray nozzle to the bottom of the sensor (2). Be sure that both outer sensors have the same offset distance for best results.
Procedure to Modify:
1. Measure the distance as described on screen.
2. Enter the measured distance using the keypad.
