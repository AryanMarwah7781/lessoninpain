# Target Fill

Target Fill system allows you to automatically fill the tank to a desired level. The correct volume must be entered to ensure proper concentration of chemical and to have enough solution to complete your job.
Procedure to Modify:
WZ1406740—UN—27MAY25

![[WZ1406740.png]]
**Figure WZ1406740**

Target Fill Input Box
1.Verify that the desired fill level is shown. Select the Input Box if you want to change the target fill preset.
WZ1406733—UN—27MAY25

![[WZ1406733.png]]
**Figure WZ1406733**

Start
2.Select the Start button to begin filling the tank.
WZ1406708—UN—27MAY25

![[WZ1406708.png]]
**Figure WZ1406708**

Status Indicator
3.Status Indicator changes to Active once the target fill procedure has begun.
WZ1406734—UN—27MAY25

![[WZ1406734.png]]
**Figure WZ1406734**

Stop
4.If needed, select the Stop button to end the target fill procedure before the selected level is reached.
