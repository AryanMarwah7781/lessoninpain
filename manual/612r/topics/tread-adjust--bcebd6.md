# Tread Adjust

Tread Adjust page is used to change machine tread width. Front and rear axles can be set to different widths if desired. Tread width equals wheel spacing.
Modify When:
- You want to adjust the tread to a specific width. Use Auto Mode.
- You want to quickly adjust the tread width. Use the CommandARM Buttons.
- Crop row spacing changes.
- Beginning road transport.
CAUTION: Always use the narrowest possible tread width when transporting the machine on a road.
