# Boom Calibration | Center Frame Valve Calibration | Calibration Values

Center Frame Valve | Calibration Values allow you to view the calibration values from the center frame valve calibration.
Items Accessible on Center Frame Valve | Calibration Values Page:
WZ1409900—UN—18JUN25

![[WZ1409900.png]]
**Figure WZ1409900**

Calibration Value Gauge
Calibration Value Gauge— represents the detected values for the center frame valve. One gauge displays the detected values for the valve with the center frame in the raised positioned. The other gauge shows the detected values for the valve with the center frame in lowered position.
The darkened portion of the gauge represents the range of detected values.
WZ1409902—UN—18JUN25

![[WZ1409902.png]]
**Figure WZ1409902**

Maximum
Maximum— displays the maximum value detected by the calibration for both center frame up and center frame down.
WZ1409903—UN—18JUN25

![[WZ1409903.png]]
**Figure WZ1409903**

Minimum
Minimum— displays the minimum value detected by the calibration for both center frame up and center frame down.
WZ1409904—UN—18JUN25

![[WZ1409904.png]]
**Figure WZ1409904**

Range
Range— displays the range between the minimum and maximum values for both center frame up and center frame down.
WZ1411032—UN—25JUN25

![[WZ1411032.png]]
**Figure WZ1411032**

Out of Range
Out of Range— value is highlighted in red when the range between the minimum and maximum values detected by the calibration is not within acceptable limits.
