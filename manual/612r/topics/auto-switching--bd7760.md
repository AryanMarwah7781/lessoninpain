# Auto Switching

Auto Switching tab allows you to view the system status, adjust pressure settings, adjust nozzle boost values, change active spray tips, and select auto pulsing target pressure.
Items Accessible on Auto Switching Page:
NOTE: Some of the following items are only displayed if machine is equipped with the associated option.
N118420—UN—02NOV16

![[N118420.png]]
**Figure N118420**

Status
Status— displays the status of the auto switching system. Selecting the status indicator opens the Auto Switching | Diagnostics screen.
N127734—UN—25JAN17

![[N127734.png]]
**Figure N127734**

Target Rate
Target Rate— displays the selected target rate.
WZ1408725—UN—09JUN25

![[WZ1408725.png]]
**Figure WZ1408725**

Auto Enabled Spray Speeds
Auto Enabled Spray Speeds— displays the speed ranges achievable for each active spray tip using the selected pressure settings. Gaps in speed range are also indicated if they occur.
WZ1408766—UN—09JUN25

![[WZ1408766.png]]
**Figure WZ1408766**

Pressure Settings
Pressure Settings— allows you to enable/disable the active spray tips and set the minimum and maximum pressure for the active spray tips.
If Equipped With Standard Solution System:
n127627—UN—16DEC16

![[N127627.png]]
**Figure N127627**

Auto Pulsing Target Pressure Enable
Auto Pulsing Target Pressure Enable— enables the desired target spray pressure.
n127628—UN—16DEC16

![[N127628.png]]
**Figure N127628**

Auto Pulsing Target Pressure
Auto Pulsing Target Pressure— displays target spray pressures and allows them to be changed. Select an input box to change the target pressure.
If Equipped With Dual Product Solution System:
WZ1408789—UN—09JUN25

![[WZ1408789.png]]
**Figure WZ1408789**

Auto Pulsing Target Pressure Enable
Auto Pulsing Target Pressure Enable— enables the desired target spray pressure. On machines with dual product solution systems, there are two target pressure settings for each solution system.

![[WZ1408790.png]]
**Figure WZ1408790**

Auto Pulsing Target Pressure
Auto Pulsing Target Pressure— displays target spray pressures and allows them to be changed. Select an input box to change the target pressure.

Advanced Settings— allows you to access further adjustments and less common settings.
