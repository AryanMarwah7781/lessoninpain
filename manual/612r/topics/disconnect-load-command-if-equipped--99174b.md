# Disconnect Load Command—If Equipped

NOTE: Install caps or plugs at all connections to prevent contamination.
Catch any remaining solution in a suitable container.
Retain all hoses in locations to avoid damage while solution system is not in use.
N109338—UN—20JAN14

![[N109338.png]]
**Figure N109338** — A: Clamp; B: Tank Fill Hose; C: Load Command Pump

1. Remove clamp (A) and disconnect tank fill hose (B) from the Load Command pump (C).
N135430—UN—26FEB18

![[N135430.png]]
**Figure N135430** — A: Cap Screw; B: Bracket

2. Remove and retain cap screw (A).
3. Position bracket (B) so it will not interfere during removal.
N109340—UN—20JAN14

![[N109340.png]]
**Figure N109340** — A: Clamp; B: Evacuation Hose

4. Remove clamp (A) and disconnect evacuation hose (B).
N135431—UN—26FEB18

![[N135431.png]]
**Figure N135431** — A: Clamp; B: Rinse Hose

5. Remove clamp (A) and disconnect the rinse hose (B).
N109495—UN—20JAN14

![[N109495.png]]
**Figure N109495** — A: Hydraulic Hose

6. Disconnect hydraulic hose (A).
