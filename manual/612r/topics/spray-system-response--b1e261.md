# Spray System Response

Spray System Response is the time it takes for the actual application rate to reach the target rate. Response setting must be correct to ensure that the correct application rate is achieved.
Increase Response When:
- Target rate is never reached.
- Time to acquire target rate is longer than 4 seconds.
Decrease Response When:
- Application rate is erratic.
Procedure to Modify:
N118430—UN—09NOV16
