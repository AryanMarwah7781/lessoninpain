# Spray Mode

N127719—UN—06DEC16

![[N127719.png]]
**Figure N127719**

Spray Mode
Press desired Spray Mode switch to enable or disable that spray mode. Indicator lights illuminate when a mode is selected.
N127720—UN—06DEC16

![[N127720.png]]
**Figure N127720**

A Only
A Only— the A solenoid and front spray tip are enabled.
N127721—UN—06DEC16

![[N127721.png]]
**Figure N127721**

B Only
B Only— the B solenoid and rear spray tip are enabled.
N124846—UN—06DEC16

![[N124846.png]]
**Figure N124846**

A + B
A + B— both solenoids are enabled. Solution is sprayed from both tips. This mode is available when spray tips 1, 2, or 3 are in the front position. Press and hold the disabled spray mode to enable A + B mode. Both indicator lights illuminate in this mode. Press and release an enabled spray mode to disable that solenoid. For example, when A+B is enabled, press and release of the B Only button will disable the B solenoid and revert the system to A Only mode.
N124845—UN—06DEC16

![[N124845.png]]
**Figure N124845**

Automatic
Automatic— select to enable automated pulsing to maintain target nozzle pressure. Disable to return to non-pulsed operation.
