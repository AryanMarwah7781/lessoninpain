# Before Field Operation

CAUTION: Do not turn on the machine until you are sure that nobody is in the danger zone.
Verify that the machine is properly prepared for field operation. Check the following items before operating:
- Ensure that all maintenance has been performed.
- Verify that the correct nozzle tips are installed and set for the desired spray pattern and row spacing. (See the Wet System section.)
- Verify that the wheel tread width is adjusted for row spacing. (See the Chassis System Application section for tread adjust procedures.)
- Verify that the display has been correctly programmed with the following:
- Application Rates
- Tank Volume
- Minimum Spray Pressure
- Spray Off Pressure
- Number of Boom Sections
- Nozzle Spacing
- Spray Width
- Check Flowmeter Calibration Number
- Calibrate Pressure Sensor
- Calibrate Wheel Speed Sensor
- Calibrate Radar Sensor (if equipped) (See the CommandCenter Display Applications section.)
- Perform the Boom Air Bleed Process. (See
Recommendations for Eliminating Air from Solution System in the Wet System section.)
- Verify that the solution tank is filled, solution valves are correctly positioned, and agitation valve (if necessary) is open. (See the Wet System section.)
- Ensure that the operator is familiar with all machine controls, control functions, and safe operations. (See the Operator’s Station and Safety sections.)
- Verify that the clean water tank is filled with clean water. (See Clean Water Tank in the Wet System section.)
