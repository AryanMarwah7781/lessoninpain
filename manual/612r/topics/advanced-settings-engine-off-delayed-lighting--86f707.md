# Advanced Settings | Engine Off Delayed Lighting

Engine Off Delayed Lighting allows you to set the time limit for the lights to shut off after exiting the machine.
NOTE: Operators are able to set the timeout delay for the egress lighting upon engine off.
Procedure to Modify:
H125410—UN—01FEB19

**Figure H125410**

Time Limit
Select to open a list of available time limits.
- OFF
- 1 minute
- 3 minutes
- 5 minutes
