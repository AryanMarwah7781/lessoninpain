# AutoTrac RowSense Sensor

Symptom | Problem | Solution
RowSense will not change from disabled to enabled.
AutoTrac or RowSense License missing.
Purchase License at ISG price page.
Installed on wrong sprayer. | Installed on approved sprayer.
Symptom | Problem | Solution
No RowSense sensor detected (Diagnostic page showing steering left and right voltage as zero).
Check hardware installation is correct and all connectors are connected. If problem persists, contact a John Deere dealer or other service provider.
Display software is out of date. | Update to latest software version.
