# Machine Calibration | Multi-Function Lever

This procedure calibrates the multi-function lever position range for the drivetrain control. The multi-function lever must be calibrated to provide the desired machine performance and control.
Perform Calibration When:
- Multi-function lever has been replaced.
- Power train domain control unit has been replaced.
- Armrest control unit has been replaced.
- Hydrostatic cable has been replaced (if equipped).
