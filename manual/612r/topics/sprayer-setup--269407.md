# Sprayer Setup

Sprayer Setup displays the current sprayer configuration and settings from several display applications. Selecting items displayed on the Sprayer Setup screen takes you to the associated application and allows you to quickly make changes.
Items Accessible on Spray System Main Page:
NX1453237—UN—17APR26

![[NX1453237.png]]
**Figure NX1453237**

Crop Type
Crop Type—displays the name of the selected crop. The crop type can be configured in the Work Setup application.
WZ1408708—UN—09JUN25

![[WZ1408708.png]]
**Figure WZ1408708**

Product Name and Type
Product Name and Type—displays the name of the product and type of product in the associated tank. The product can be configured in the Work Setup application.
For dual product solution systems, two separate products will be listed if the tank configuration is set to independent tanks.
WZ1408715—UN—09JUN25

![[WZ1408715.png]]
**Figure WZ1408715**

Tank Configuration (Single Tank)
Tank Configuration—displays the current tank configuration. Select to change the tank configuration.
Machines Equipped With Dual Product Solution System:
WZ1408713—UN—09JUN25

![[WZ1408713.png]]
**Figure WZ1408713**

Tank Configuration (Dual Independent Tanks)
For machines with dual product solution system, the tank icon varies depending on the tank configuration.
For more information on the tank configuration icons, refer to Sprayer Setup | Tank Configuration Icons.
WZ1408703—UN—09JUN25

![[WZ1408703.png]]
**Figure WZ1408703**

Boom Settings
Boom Settings—displays the current boom height settings and sensor target. Select the Input Box to open the Boom System application.
WZ1408705—UN—09JUN25

![[WZ1408705.png]]
**Figure WZ1408705**

Tank and Nozzle Configuration (Dual Independent Tanks Shown)
Tank and Nozzle Configuration—indicates the configuration between the tank or tanks and nozzle A and/or nozzle B.
WZ1408707—UN—09JUN25

![[WZ1408707.png]]
**Figure WZ1408707**

Nozzle Turret
Nozzle Turret—represents a nozzle turret on the boom and identifies nozzle A, which is the front nozzle, and nozzle B, which is the rear nozzle.
Within the nozzle turret icon, information about the nozzle system and target spray rates are displayed.
WZ1408706—UN—09JUN25

![[WZ1408706.png]]
**Figure WZ1408706**

Nozzle System Settings
Nozzle System Settings—displays the current spray methods and the nozzle tip sizes being used for nozzles A and B. The top portion of the input box represents nozzle A. The bottom portion of the input box represents nozzle B.
Select the Input Box to open the Nozzle System application.
WZ1408718—UN—09JUN25

![[WZ1408718.png]]
**Figure WZ1408718**

Target Rates
Target Rates—displays the current target rates for nozzles A and B. The top portion of the input box represents nozzle A. The bottom portion of the input box represents nozzle B.
If the nozzle is set to broadcast spray, selecting the target rate input box opens the Target Rate/Rx page.
If the nozzle is set to See & Spray, selecting the target rate input box opens the See & Spray Target Rate page.
WZ1408711—UN—09JUN25

![[WZ1408711.png]]
**Figure WZ1408711**

Spray Mode
Spray Mode—displays the current spray mode. Selecting the input box opens the Spray Mode and Method page.
WZ1408709—UN—09JUN25

![[WZ1408709.png]]
**Figure WZ1408709**

Pulsing Mode
Pulsing Mode—displays the valve pulsing mode for the nozzle or nozzles set to broadcast spray. Select the input box to change the pulsing mode for the displayed nozzle.
Refer to Valve Pulsing Mode for more information on the available modes.
If Equipped With See & Spray:
WZ1408710—UN—09JUN25

![[WZ1408710.png]]
**Figure WZ1408710**

See & Spray Settings
See & Spray Settings—displays the current See & Spray settings. Select the Input Box to open the See & Spray application.
