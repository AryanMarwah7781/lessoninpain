# Headland Management System Main Page

WZ1406688—UN—27MAY25

![[WZ1406688.png]]
**Figure WZ1406688**

Headland Management System
NOTE: Underscored text identifies that additional information is available within this section or another section of this publication.
Main page shown is for example only. Your main page may differ depending on options or connected equipment.
Headland Management System (HMS) allows you to configure multiple machine systems to be switched ON/ OFF automatically or manually when entering or exiting a headland. HMS increases ease of machine operation and allows you to give more attention to driving the machine.
Modify When:
- Enabling or disabling HMS.
- Changing functions controlled by HMS.
HMS Status Items:
WZ1405506—UN—19MAY25

![[WZ1405506.png]]
**Figure WZ1405506**

HMS Status
HMS Status— informs you of the current status of HMS.
n118160—UN—09FEB17

![[N118160.png]]
**Figure N118160**

HMS ON/OFF
HMS ON/OFF— press the toggle button to turn ON/OFF HMS. With HMS OFF, no settings will be changed when entering or exiting headlands.
Entering Headlands Items:
NOTE: Selecting any of the Entering Headlands items will take you to the Entering Headlands Settings screen, where settings changes can be made.
n118160—UN—09FEB17
Entering Headlands ON/OFF
Entering Headlands ON/OFF— press the toggle button to turn ON/OFF settings for Entering Headlands. When turned OFF, no settings will be changed when the HMS entry switch is pressed.

Auto Entry
Auto Entry— allows the machine to automatically detect when it is entering a headland. Detection is triggered when the section control working width is 0.

Procedure to Configure and Operate:
NOTE: HMS only controls selected features. You must operate other features manually. Systems selected for use with the HMS function may require setup using its system application before HMS is operated.
n118160—UN—09FEB17
Toggle Button
1. On the Headlands Management System main page, select the Toggle Buttons to turn ON HMS, Entering Headlands, and Exiting Headlands as desired.
WZ1405506—UN—19MAY25
Status Indicator
2. Verify that the system is ready to use by checking the Status Indicator. If the system is not ready, check the message next to the status indicator for more information.
3. To change the settings for entering and exiting headlands, go to the Entering Headlands Settings and Exiting Headlands Settings pages.
WZ1406324—UN—24MAY25

![[WZ1406324.png]]
**Figure WZ1406324**

HMS Entry and Exit Switches
4. Press the HMS Exit and Entry Switches on the multi-function lever when exiting and entering headlands to manually activate all enabled functions as configured in the HMS display application.
To automatically enable functions when entering or exiting headlands, turn ON the Auto Entry and Auto Exit features.
