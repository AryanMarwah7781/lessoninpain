# RowSense Settings

N118160—UN—09FEB17

![[N118160.png]]
**Figure N118160**

ON/OFF
RowSense Items accessible on the Information and Settings page:
RowSense Master—Select toggle to turn RowSense application ON or OFF.
When RowSense Master is OFF, RowSense features and settings are disabled. RowSense Master is only available if a RowSense sensor or a Vision sensor is connected to the machine.
N128464—UN—09FEB17

![[N128464.png]]
**Figure N128464**

RowSense Controls
RowSense Controls—Select button to view RowSense Status.
RowSense Status window displays sensor offsets, sensor calibration, and system status information.
Sensor Selection
Select sensor configuration.
- Vision + RowSense—Vision sensor and RowSense sensor are installed.
- Vision—Vision sensor is installed.
- RowSense—RowSense sensor is installed.
Row Entry Mode
Select mode to determine procedure when entering a row.
GPS Steer:
1. Drive machine into row.
2. Press resume button first time to lower head and engage guidance.
3. Press resume button second time to engage row sensors.
Manual Steer:
1. Drive machine into row.
2. Press resume button first time to lower head.
3. Press resume button second time to engage guidance and row sensors.
