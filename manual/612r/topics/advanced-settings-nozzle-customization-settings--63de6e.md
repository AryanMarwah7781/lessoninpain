# Advanced Settings | Nozzle Customization Settings

Advanced Settings | Nozzle Customization Settings allow you to enable/disable settings related to nozzle coverage mapping and grouping outer nozzles when experiencing poor global positioning system (GPS) signal.
Modify When:
Operating in areas with poor or intermittent global positioning system (GPS) signal. Enable Group Outer Rows.
Advanced Settings | Nozzle Customization Settings Items:
WZ1408747—UN—09JUN25

![[WZ1408747.png]]
**Figure WZ1408747**

Checkbox
Map Applied Rate Across Boom Width— allows you to record map coverage for all nozzles including nozzles that have been disabled. If this setting is disabled, the system will not map nozzles that are turned OFF.
Select the Checkbox to enable/disable this setting.
WZ1408747—UN—09JUN25
Checkbox
Group Outer Rows— allows you to group the outermost nozzles or outermost enabled sections in order to avoid unintentional nozzle shut-offs caused by poor GPS signal.
Select the Checkbox to enable/disable this setting.
NOTE: Additional settings related to nozzle customization can be accessed on the Nozzle Customization screen. Nozzle Customization allows you to turn ON/ OFF individual nozzles across the entire boom for a custom nozzle configuration.
