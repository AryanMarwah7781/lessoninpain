# Solution Pump Calibration Procedure

Procedure Requirements:
Engine State | Running at low idle
Wheel Speed | 0 km/h (0 mph)
Operating State | Parked, not applying product
Hydraulic Fluid Temperature | Normal operating temperature
Solution System
- Contains enough water to prevent pump cavitation. Minimum volume 567.8 L (150 gal)
- Solution pump OFF
- System pressure less than 0.34 bar (34.4 kPa) (5 psi)
- Filling operations not active
Dual Product Solution System Only
Filling operations not active
Calibration Overview:
NOTE: Do not perform this procedure for erratic solution pump rate or pressure if the A and B numbers are within range. If A and B numbers are within range, see Operator’s Manual.
Perform calibration using ONLY water. Using other solutions causes inaccurate calibration values.
Standard-Flow Pump:
Speed (rpm) | Current (mA)
A | 800—1200 | 350—750
B | 5500—6000 | 1275—1625
High-Flow Pump:
Speed (rpm) | Current (mA)
A | 750—1200 | 400—670
B | 4000—4600 | 1450—1750
