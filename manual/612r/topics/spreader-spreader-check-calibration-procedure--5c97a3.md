# Spreader | Spreader Check Calibration | Procedure

NOTE: Some of the following items are only displayed if machine is equipped with the associated option.
Spreader Spinner Procedure Requirements:
Procedure Requirements:
Master Switch State | OFF
Conveyor State | OFF
Spinner State | OFF
Engine State | Running
Machine State | Parked, not applying product
Spreader Spinner Procedure:
NOTE: If spinner is running, it disengages when Begin Procedure is selected.
N119102—UN—23FEB16

![[N119102.png]]
**Figure N119102**

Begin Procedure
1. Select Begin Procedure.
N120898—UN—12MAY16

![[N120898.png]]
**Figure N120898**

Rate Selection Buttons
2. Select the desired Rate Preset or Manual Rate Control using the rate selection buttons on the CommandARM.
N118434—UN—22JAN20

![[N118434.png]]
**Figure N118434**

Checkbox
3. Select the bin(s) to check. Product, target rate, and conveyor speed are displayed.
N120244—UN—23FEB16

![[N120244.png]]
**Figure N120244**

Test Speed
4. Select to enter the test speed. Use the desired application speed for the test.
N120673—UN—23FEB16

![[N120673.png]]
**Figure N120673**

Conveyor Speed
5. If manual rate mode is selected, select the input box to enter the desired conveyor speed.
N120497—UN—02NOV16

![[N120497.png]]
**Figure N120497**

Solution Pump
6. Enable the spreader hydraulic system. Press the Solution Pump switch on the CommandARM.
NOTE: Solution Pump switch functions as the hydraulic enable switch when a dry spreader is installed.
N120670—UN—06DEC16

![[N120670.png]]
**Figure N120670**

High Idle
7. Set the engine speed to high idle.
CAUTION: Belt(s) begin movement on button press. Product discharge can occur if product remains in bin(s).
N120251—UN—04JAN17

![[N120251.png]]
**Figure N120251**

Spray System Master
8. Press the Spray System Master switch on the multifunction lever to begin the test. Conveyor speed and the actual rate applied are displayed.
NOTE: Spray System Master switch functions as the Spread System Master switch when a dry spreader is installed.
N118091—UN—16FEB16

![[N118091.png]]
**Figure N118091**

Progress Indicator
NOTE: Progress indicator displays when a check is in progress for each selected bin.
CAUTION: Spinners cannot be completely shielded due to their function. Keep away from spinners while they are turning.
N118056—UN—17FEB16

![[N118056.png]]
**Figure N118056**

ON/OFF
9. Engage the spinners using the ON/OFF toggle button to test the speed response if desired. Target speed and actual speed are displayed.
N120251—UN—04JAN17
Spray System Master
10. Press the Spray System Master switch on the multifunction lever again to pause the test at any time.
N118396—UN—17FEB16

![[N118396.png]]
**Figure N118396**

Close
11. Select the close button to end the procedure and return to the previous page.
Interpret Check Results:
If the target rate and actual rate are equal, the spreader can achieve the desired application for that product at the entered test speed.
If actual rate is not constant, see the Troubleshooting section of your Operator's Manual, or call your John Deere dealer or service provider.
If the actual rate is higher than the target rate, decrease the gate opening.
If the actual rate does not get to the target rate, increase the gate opening.
Compare the target conveyor speed and the actual conveyor speed. These speeds are displayed for the product bin selected and show if the system can reach the target conveyor speed. Adjust machine settings as necessary to achieve desired application.
Compare the target spinner speed and the actual spinner speed to see if the system can reach the target spinner speed. Adjust machine settings as necessary to achieve desired application.
