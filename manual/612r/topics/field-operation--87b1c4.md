# Field Operation

CAUTION: Do not turn on the machine until you are sure that nobody is in the danger zone.
NOTE: Plungers do not open properly when operating above 965.3 kPa (9.65 bar) (140 psi) when a low voltage condition occurs.
N127745—UN—30NOV16

![[N127745.png]]
**Figure N127745** — A: Raise/Lower Switch

1. Unfold boom and press raise/lower switch (A) to position boom at desired operating height.
2. Set up display for your particular application. (See Display Applications section in the machine operators manual for proper setup procedures.)
3. Verify that tank is loaded with solution.
NOTE: Solution pump will automatically shut off after a brief time if no solution flow is detected to prevent overheating and damage to seals.
NX1435667—UN—12DEC25

![[NX1435667.png]]
**Figure NX1435667** — A: Solution Pump Switch

4. Push solution pump switch (A) to engage solution pump.
5. View spray operation on the display.
N127746—UN—30NOV16

![[N127746.png]]
**Figure N127746** — A: Rate Control Switch; B: Manual Pressure Setting Switch

6. Select rate control switch (A) programmed for desired application rate (1, 2 or 3) or the manual pressure setting button (B).
NOTE: Rate selected is highlighted on the display.
Only use manual pressure mode with fixed pulsing or pulsing turned off.
N166439—UN—08MAR24

![[N166439.png]]
**Figure N166439** — A: Multi-Function Lever

7. Push multi-function lever (A) slowly forward to start forward motion.
8. Verify that desired boom sections are enabled. (See Boom Sections Custom in Boom and Nozzles Application section.)
NOTE: The status of each boom section is indicated on the display. (See Section Control Status in Boom and Nozzle Application section.)
NX1435634—UN—12DEC25

![[NX1435634.png]]
**Figure NX1435634** — A: Spray System On/Off Switch; B: Indicator; C: Indicator

NX1439269—UN—02JAN26

![[NX1439269.png]]
**Figure NX1439269** — A: Spray System On/Off Switch; B: Indicator; C: Indicator

9. Press spray system on/off switch (A) to start spraying operation.
NOTE: Indicators (B and C) are illuminated when spray system On/Off switch is activated on the multi-function lever.
N124964—UN—14NOV16

![[N124964.png]]
**Figure N124964** — A: Spray System On/Off Switch

10. At the row end, press spray system on/off switch (A) to stop spraying. All other switches can remain in preset positions.
11. When aligned with the next row, press spray system on/off switch to resume spraying.
