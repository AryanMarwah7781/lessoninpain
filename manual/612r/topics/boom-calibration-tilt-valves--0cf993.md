# Boom Calibration | Tilt Valves

This procedure calibrates the boom tilt valves. Tilt valves must be calibrated so that the boom response is the correct speed and BoomTrac operates correctly when installed.
NOTE: Some of the following items are only displayed if machine is equipped with the associated option.
Perform Calibration When:
- Boom tilt response is too slow or fast.
- A valve cartridge has been replaced.
- BoomTrac is not performing as expected.
- Boom tilt cylinders are replaced.
