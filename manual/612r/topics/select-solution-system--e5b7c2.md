# Select Solution System

Select Solution System allows you to choose the solution system or systems you want to include in the rinse cycle.
Procedure to Modify:
A94261—UN—24AUG18

![[A94261.png]]
**Figure A94261**

Radio Button
1. Select solution system(s) you want to rinse by selecting the Radio button next to the desired option.
NOTE: Select Solution System 1+2 with Equalizer when you have been spraying in a combined tank configuration and need to rinse the equalizer valve.
N118025C—UN—20JUN25

![[N118025C.png]]
**Figure N118025C**

Checkbox
2. If you want to reclaim product after the rinse cycle is completed, select the Checkbox.

Cancel Button
