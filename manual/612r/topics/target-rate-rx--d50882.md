# Target Rate/Rx

Target application rate can be edited for presets 1, 2, and 3. The manual pressure setting can also be modified. A prescription for map-based application can be selected if previously loaded to the machine.
Modify When:
- Changing products being applied.
- Prescription application is desired.
- Manual rate control is desired.
- Application rate desired is not one of the current presets.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Procedure to Modify:
1.

Select the Radio button next to the desired preset.
If Equipped with Dual Product Solution System:
NOTE: If the solution systems are being operated independently, the desired preset is selected for each solution system separately.
