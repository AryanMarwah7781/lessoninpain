# Create Single Position Assignments

Create Single Position Assignments to assign and activate your preferred applications, then make function assignments. Use the controls setup reconfigurable buttons to personalize your machine and perform tasks quickly with the press of a button.
For more information on which reconfigurable buttons can be assigned single position assignments, see Multi-Function Lever - Controls Setup and CommandARM - Controls Setup.
Procedure to Modify:
NOTE: The example shown is typical for making application assignments. For a list of available application or function assignments, see Application Assignments or Function Assignments. This example shows assigning the AutoTrac Guidance application to reconfigurable button A.
H117027C—UN—20JUN25

![[H117027C.png]]
**Figure H117027C**

Control Group Lock
1. Press the Control Group Lock button on the CommandARM.
NOTE: Light is on when locked. Light is off when unlocked. When unlocked, applications and functions may be modified.
N153274C—UN—20JUN25

![[N153274C.png]]
**Figure N153274C**

Single Position Assignment Button
2. Select the desired single position assignment button that you wish to assign the control to. Button A is selected in this example.
NOTE: If equipped with Independent Mode, dual position buttons can also be assigned to single position functions.

![[H118143C.png]]
**Figure H118143C**

Select Application
3. Select to activate the Select Application display.

Remove Assignment
NOTE: If an assignment is already present on the Control Setup display, the "Remove Assignment" option is placed at the top of the list. Select to close and clear the assignment.
