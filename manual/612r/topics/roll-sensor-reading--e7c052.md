# Roll Sensor Reading

Roll Sensor Reading displays the current angle of the boom. Readings update in real-time.
Roll Sensor Readings:
WZ1408000—UN—04JUN25

![[WZ1408000.png]]
**Figure WZ1408000**

Neutral Value (level)
Neutral Value (level)— the boom is level. A reading of 0° is displayed.
WZ1408001—UN—04JUN25

![[WZ1408001.png]]
**Figure WZ1408001**

Positive Value
Positive Value— shown when the boom is rotating clockwise. Indicates the right-hand side of the boom is moving towards the ground.
WZ1407999—UN—04JUN25

![[WZ1407999.png]]
**Figure WZ1407999**

Negative Value
Negative Value— shown when the boom is rotating counter-clockwise. Indicates the left-hand side of the boom is moving towards the ground.
NOTE: If the roll sensor value on the display does not match the observed position of the boom, perform the Tilt Sensors Calibration.
