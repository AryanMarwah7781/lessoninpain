AutoTrac RowSense is an enhancement to integrated AutoTrac when harvesting corn or applying product. Signals provided by row sensors are integrated with existing AutoTrac signals to keep machine on rows. When there is no signal from row sensors (driving through a waterway), normal global positioning system (GPS) guidance is used.
AutoTrac RowSense works with all tracking methods and most standard harvesting and application patterns. All tracking modes are set up the same way as they are with GPS based AutoTrac.
Getting Started—Information about using RowSense.
RowSense Settings—Turn RowSense on / off and select row entry mode.
