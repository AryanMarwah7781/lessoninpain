# Diagnostic Pages

Diagnostic information is available for all nozzles on the spray boom. See Nozzle Controller Readings in Nozzle Ssytem Application to access fault information.
The following information is available for each nozzle:
- Nozzle Position on the spray boom
- Source Address
- Hardware Part Number
- Hardware Serial Number
- Hardware Manufacturing Date
- Software Part Number
- Software Version
- Supplied Voltage
- Valve A Current
- Valve B Current
- Valve A PWM Value
- Vavle B PWM Value
