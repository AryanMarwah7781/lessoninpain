# Auto Prime | Status Indicator

Status Indicator displays the status of the auto prime procedure and a message about that status.
Available Status Indicators:
N118420—UN—02NOV16

![[N118420.png]]
**Figure N118420**

Green
Auto Prime System Ready (green)— turn the Solution Pump and Spray System Master switches on to start.
N118020—UN—22OCT15

![[N118020.png]]
**Figure N118020**

Amber
Auto Prime System Not Ready (amber)— a message about an error is displayed.
N118021—UN—13JAN17

![[N118021.png]]
**Figure N118021**

Blue
Injection Line Prime Active (blue)— turn Spray System Master switch off to stop.
N118021—UN—13JAN17
Blue
Boom Prime Active (blue)— turn the Spray System Master switch off to stop.

![[N118022.png]]
**Figure N118022**

Red
Boom Prime Error (red)— turn the Spray System Master switch off to stop.
