# Targeted Area

Select to spray either the entire field or between rows.
NOTE: A license for Targeted Herbicide is required to spray between rows. This feature is not available in all countries.
Entire Field
WZ1408496—UN—06JUN25

![[WZ1408496.png]]
**Figure WZ1408496**

Entire Field
Entire Field— system sprays all plants in the field. Use this method for fallow ground or burn-down applications.
In order to spray all plants in the field, ensure that No Crop is selected in Work Setup.
Between Rows
WZ1408495—UN—06JUN25

![[WZ1408495.png]]
**Figure WZ1408495**

Between Rows
Between Rows— system sprays only plants that are between the rows. Use this method for emerged crop applications.
WZ1406649—UN—27MAY25

![[WZ1406649.png]]
**Figure WZ1406649**

Row Spacing
Row Spacing— enter the distance between the center of each row. Accurate row spacing improves targeting performance.
In order to spray between rows, ensure that a supported crop is selected in Work Setup. Between rows does not function with No Crop selected.
