# Nozzle Customization

Nozzle Customization allows you to turn ON/OFF individual nozzles to create a custom configuration. To use the custom nozzle configuration you have created, select the Custom Nozzles option on the Nozzle Setup page.
NOTE: Other nozzle customization settings can be accessed on the Advanced Settings page. Settings found on the Advanced Settings page allow you to enable/disable settings related to nozzle coverage mapping and grouping outer nozzles when experiencing poor global positioning system (GPS) signal.
