# Onscreen Help Navigation

There are three ways to access Onscreen Help through the armrest CommandCenter display:
Access Contextual Help
N167187—UN—15APR24

![[N167187.png]]
**Figure N167187**

Help Icon
The help icon is found in the title bar of most pages of the on-screen display. Select the help icon for quick access to information about the functions currently being displayed on-screen.
Access Help Center
T8T8742—UN—20JAN20

![[T8T8742.png]]
**Figure T8T8742**

Help
Books in the Help Center are organized according to applications found in the display menu. In addition to specific application help, there are books in the list with information about the display, machine, and implements. These books contain additional content not found in application books and cannot be accessed using contextual help.
To access the Help Center, select Help from the shortcut bar at the bottom of the run page.
