# Worklights Controls

Worklights Controls allow you to select the desired worklight preset and mode.
NOTE: Some items included are only displayed if machine is equipped with the associated options.
Procedure to Modify:
H127047—UN—26SEP19

![[H127047.png]]
**Figure H127047**

Worklights Button
1. Press the Worklights button on the CommandARM armrest.
NOTE: LED illuminates when the worklights button is selected.
H127048—UN—26SEP19

![[H127048.png]]
**Figure H127048**

Lever
2. Select desired Worklight preset.
- Pull the lever rearward (momentary high beam position) to activate worklight preset 1.
- Push the lever forward (high beam position) to activate worklight preset 2.
NOTE: After the lever is released and returns to home (middle) position, the selected preset remains active.

Worklights Preset 2
3. To customize the lighting presets, access the Lights application and make changes to Worklights Preset 1 and Worklights Preset 2 as desired.
