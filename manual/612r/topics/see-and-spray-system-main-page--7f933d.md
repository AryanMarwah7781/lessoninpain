# See & Spray System Main Page

NX1459611—UN—29APR26

![[NX1459611.png]]
**Figure NX1459611**

See & Spray System
NOTE: Underscored text identifies that additional information is available within this section or another section of this publication.
Main page shown is for example only. Your main page may differ depending on options or connected equipment.
See & Spray System applies a targeted solution to a weed when it is identified in a field and stops the application when no weeds are detected. Cost savings are gained because the amount of solution applied to a field is reduced.
