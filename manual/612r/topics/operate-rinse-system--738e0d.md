# Operate Rinse System

CAUTION: Spray system can contain hazardous material, which can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use the rinse system in an area where people, animals, vegetation, and water supply, and so on, cannot be contaminated.
The following procedure is recommended daily or anytime chemicals are switched.
NOTE: System rinse must be set up using the display before the rinse procedure can be operated from the Fill Station. (See the Rinse System Application section of this manual.)
Rinse procedures can be activated from the cab using the display, but the operator must still open eductor valves manually to rinse the hopper.
1. Drain the solution tank. (See Drain Solution Tank in this section.)
2. Operate boom air purge (if equipped) to remove solution before performing the rinse procedure.
3. Set spray pressure at 620—690 kPa (6.2—6.9 bar) (90—100 psi) to assist in chemical removal when spraying rinse water.
NOTE: Engine speed can increase when a rinse cycle is initiated.
NX1435331—UN—10DEC25

![[NX1435331.png]]
**Figure NX1435331** — A: Rinse Button

4. Press rinse button (A).
NX1440558—UN—15JAN26

![[NX1440558.png]]
**Figure NX1440558** — A: System Rinse Button

5. Press system rinse button (A).
NOTE: When rinsing the eductor, the operator must manually open eductor rinse and sump valves when the display shows that portion of the rinse cycle.
6. Rinse procedure begins automatically and rinses the following systems:
- Eductor
- Agitation
- Load Command—if equipped
- Recirculation—if equipped
- Boom
- Solution Tank
NX1440559—UN—15JAN26

![[NX1440559.png]]
**Figure NX1440559** — A: Skip Button; B: Cancel Button

7. Press skip button (A) to skip to the next step if desired.
8. Press the rinse button or cancel button (B) to stop automatic rinse. Rinse procedure automatically stops when complete.
NOTE: Starting the solution pump can increase the engine speed.
NX1440536—UN—15JAN26

![[NX1440536.png]]
**Figure NX1440536** — A: Solution Pump On-Off Button

9. Press solution pump on/off button (A) on the keypad.
NX1440567—UN—15JAN26

![[NX1440567.png]]
**Figure NX1440567** — A: Pump Speed Increase Button

10. Increase pump speed, if desired, using pump speed increase button (A) on the micro display to achieve higher spray pressure.
NX1440568—UN—15JAN26

![[NX1440568.png]]
**Figure NX1440568** — A: Spray System On/Off Button

11. Press spray system on/off button (A) to spray out rinsate through the boom.
12. Turn off the spray system and solution pump when the tank runs empty.
13. Perform a boom rinse. (See Operate Rinse System [Rinse Solution Pump, Boom, and Flowmeter Only] in this section.)
