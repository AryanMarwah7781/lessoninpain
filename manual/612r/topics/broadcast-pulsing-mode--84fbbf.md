# Broadcast Pulsing Mode

Broadcast Pulsing Mode allows you to select the desired pulsing mode for broadcast application. Pulsing allows a reduced rate to be applied while maintaining system pressure for constant droplet size. Pulsing also enables the machine to apply an even rate when curve compensation is active.
Modify When:
- Continuous spray from the tip is desired. Select OFF.
- Curve compensation is being used. Select automatic.
- Varying application speeds are used. Select automatic.
- Band spraying. Select fixed or OFF.
Available Valve Pulsing Modes:
No Pulsing— nozzles that are broadcast spraying are continuously open (no pulsing) when the spray system master switch is pressed ON.
Auto Pulsing— the control unit controls nozzle flow by pulsing the solenoid valve to achieve the desired application rate and maintain the desired spray pressure.
Fixed Pulsing— allows you to enter the desired nozzle flow percentage. No adjustments to the nozzle flow are made automatically.
NOTE: Band spraying is not supported by automatic mode but is available in fixed or OFF modes.
