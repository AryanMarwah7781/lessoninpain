# SmartView Setup

The fullscreen video is observed with camera feed at startup.
NX1403002—UN—08MAY25

![[NX1403002.png]]
**Figure NX1403002**

1. Touch the screen to get the controls.
NX1403008—UN—08MAY25

![[NX1403008.png]]
**Figure NX1403008** — A: Up Arrow Button

2. Press the Up arrow button(A) for advanced settings.
NX1404640—UN—14MAY25

![[NX1404640.png]]
**Figure NX1404640** — A: Scan Timeout Button; B: Edit Triggers Button; C: Edit Cameras Button

- Scan Timeout, Edit Triggers, and Edit Cameras can be updated from this screen.
- Scan Timeout button (A) allows operator to shoten or lengthen the scan time.
- Edit Triggers button (B) allows the operator to add or subtract edit triggers.
- Edit Cameras button (C) allows operator to edit the name of the camera, change the field of view, and set run page preferences.

Set Camera Field of View
NX1403010—UN—08MAY25
1. Press Edit Cameras button (A).
NX1403014—UN—08MAY25
2. Press the camera name (A) on the list.
NX1403017—UN—08MAY25

![[NX1403017.png]]
**Figure NX1403017** — A: Field of View Button

3. The current field of view is highlighted. Choose a different Field of View button (A) to change the field of view.
Set Run Page Preferences
View and Scan features can be toggled between ON and OFF. View (A) means this camera will show constantly on the display. The scan feature is used when there are several camera views to choose from and operator can scan through them periodically.
NX1403656—UN—12MAY25

![[NX1403656.png]]
**Figure NX1403656** — A: View; B: Scan

1. Use buttons next to View (A) toggle between ON and OFF for the current camera.
2. Use buttons next to Scan (B) toggle between ON and OFF for the current camera.
