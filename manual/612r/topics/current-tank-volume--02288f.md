# Current Tank Volume

Current Tank Volume displays the anticipated tank volume based on your input and the calculated solution usage. Every time solution is added to the tank, you must reset the current tank volume using the Tank Fill Volume presets and editing a preset if needed.
NOTE: The displayed volume is NOT the actual tank volume. Always verify tank volume using the sight gauge on the tank.
Verify the following to provide an accurate tank volume reading:
- Correct Tank Fill Volume preset is selected.
- Flow Meter Calibration is correctly performed.
- Correct Flow Rate Mode is selected (if equipped).
