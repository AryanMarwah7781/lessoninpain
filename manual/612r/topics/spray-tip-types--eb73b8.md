# Spray Tip Types

Basic spray tip types are:
- High Flow Flat Fan for fertilizer application
- Ultra Low-Drift Flat Fan for herbicide application
- Twin-Air Flat Fan for insecticide and fungicide application
- Guardian Flat Fan for insecticide and fungicide application
- Low-Drift Air for insecticide and fungicide application
- Straight Stream Ceramic for fertilizer application
Each spray tip type is designed to produce a specific spray pattern and are offered in different sizes to achieve desired application rate.
