# Key Switch

CAUTION: Sound horn before starting engine to clear people away from the machine.
To avoid the possibility of personal injury or death, start ONLY from the operator seat. Do NOT start engine by shorting across starter terminals. Machine will start in gear if normal circuit is bypassed.
H127222—UN—26SEP19

![[H127222.png]]
**Figure H127222**

Key Switch
Key switch is on the right-hand side of the steering column and has three positions:
H127127—UN—26SEP19

![[H127127.png]]
**Figure H127127**

Accessories
Stop— shuts off the engine and all accessory functions.
H127128—UN—26SEP19

![[H127128.png]]
**Figure H127128**

Run
Run— allows all accessories to operate and the engine to run once it has been started.
H127129—UN—26SEP19

![[H127129.png]]
**Figure H127129**

Start
Start— momentary switch position that automatically cranks the engine until the engine starts. Once the switch is released, it returns to the run position.
NOTE: It is not necessary to hold the key switch in the start position until the engine starts.
