# Height Mode

Height Mode allows you to choose the desired mode for BoomTrac operation.
CAUTION: Avoid damage or contamination of your surroundings. Increasing boom height excessively above the target increases the risk of spray drift.
WZ1408019—UN—05JUN25

![[WZ1408019.png]]
**Figure WZ1408019**

Unlocked Height Mode
Unlocked Height Mode— enter a different target height for each sensor. Use this setting when wing height above the target is different from the center frame target height.
An example of when this would be used is in rough terrain. Setting the wings higher than the center frame help keep them from contacting the crop on the ground.
WZ1408017—UN—05JUN25

![[WZ1408017.png]]
**Figure WZ1408017**

Locked Height Mode
Locked Height Mode— maintains the same height above the target for the entire length of the boom. Use this setting for most applications.
When in Locked Height Mode, the center target height is the only value that can be adjusted.
