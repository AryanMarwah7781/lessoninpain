# Diagnostic Pages

Diagnostic information is available for all nozzles on the spray boom. Diagnostic trouble codes (DTC) are displayed when a fault is detected. The text displayed with the DTC provides a description of the fault detected. Access fault information using the Individual Nozzle Control Status in Boom and Nozzles Application.
