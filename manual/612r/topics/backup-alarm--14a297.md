# Backup Alarm

N155115—UN—21APR21

![[N155115.png]]
**Figure N155115** — A: Backup Alarm

If the multi-function lever is moved rearward while the engine is running, the backup alarm (A) sends an acoustical signal to warn others around the machine that the operator is backing up.
