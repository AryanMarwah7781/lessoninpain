# Sensor Manual Calibrations

Sensor Manual calibration allows you to enter values without performing calibration procedures. You can also make adjustments to the calibration values if speed differences occur. Speed sensor calibrations must be correct to achieve the desired application rate.
Modify When:
- Slight adjustment to values is needed.
- Using an average of several calibration values.

IMPORTANT: Calibration procedures allow for optimal machine performance. Adjustments to these values may be necessary depending on field conditions. Improper adjustment may negatively affect system performance or damage the machine.
NOTE: Values increase/decrease at an increment of 0.1.
