# RowSense Sensor Calibration

This procedure calibrates the RowSense sensors to maximize guidance performance through varying crop conditions.
Calibration can only be performed if header is raised, no material is being collected, machine is level, and machine is in park.
Perform calibration when:
- New or different crop sensors are attached.
- Undesirable RowSense guidance performance is experienced.
Items accessible on the RowSense Sensor Calibration page:
N120226—UN—23FEB16

![[N120226.png]]
**Figure N120226**

Begin Calibration
Select Begin Calibration button to start the RowSense sensor calibration process.
Details displayed on page:
Last Calibration—Date and Time
Recommended Interval—As Needed
Estimated Time Required—Less than 1 minute
Sensor Voltages
Left and right sensor voltages display current voltage readings.
