# Replace Open Crankcase Ventilation Filter (Final Tier 4/Stage V 6.8 L Engine)—1500 Hours and as Required Thereafter

NOTE: After the initial filter change at 1500 hours, the filter will only need to be replaced when one of the following diagnostic trouble codes (DTC) are set.
- 101.16
- 101.1
- 101.0
RXA0109394—UN—16AUG10

![[RXA0109394.png]]
**Figure RXA0109394** — A: Hood Release

1. Pull hood release (A) and raise hood.
N136037—UN—05MAR18

![[N136037.png]]
**Figure N136037** — A: Filter Lid; B: Filter Housing

2. Remove filter lid (A).
3. Remove open crankcase ventilation filter from inside the filter housing (B).
4. To install new filter, align tabs on the new filter with tabs on inside of the filter housing.
5. Replace lid and hand-tighten.
