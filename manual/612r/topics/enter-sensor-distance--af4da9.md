# Enter Sensor Distance

N118040C—UN—20JUN25

![[N118040C.png]]
**Figure N118040C**

Sensor Distance
Enter Sensor Distance is the measurement between the center of the boom and each of the outer sensors. Be sure to position both sensors the same distance from the center of the boom.
Procedure to Modify:
1. Measure the distance as described on screen.
2. Enter the measured distance using the keypad.

![[WZ1406948.png]]

3. Select the OK button to confirm the measurement.
