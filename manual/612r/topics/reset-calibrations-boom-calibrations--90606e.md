# Reset Calibrations | Boom Calibrations

This procedure resets all boom calibration values to the factory defaults.
Perform When:
- Accurate calibration values cannot be achieved.
- Major boom structure components are replaced.
Items Accessible on Reset Calibrations | Boom Calibrations Page:
N119598—UN—02MAY16

![[N119598.png]]
**Figure N119598**

Reset
Reset— begin the reset procedure.
Procedure to Reset Calibrations:
NOTE: This process cannot be undone. Once calibrations have been reset, you will have to perform each calibration again.
N119598—UN—02MAY16
Reset
1.Select the Reset button.
2.The following calibrations are reset:
- Center Frame
- Tilt Sensor (if equipped)
- Tilt Valve (if equipped)
- Auto Boom Fold/Unfold (if equipped)
- Boom Level Position
