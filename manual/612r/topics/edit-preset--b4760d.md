# Edit Preset

Edit Preset allows you to adjust the wheel spacing to the width assigned to one of three buttons. The operator can configure the presets to accommodate different crop row spacings or other conditions.
Tread Presets are set at the factory but can be changed by the operator.
Edit Preset Procedure:
N118132—UN—10NOV16

![[N118132.png]]
**Figure N118132**

Tread Preset
1.Select the Tread Preset to edit.
N118128—UN—10NOV16

![[N118128.png]]
**Figure N118128**

Edit Preset
2.Select the Edit Preset input box to change the tread width preset.
3.Enter the desired tread width using the keypad.
n118434—UN—22JAN20

![[N118434.png]]
**Figure N118434**

Checkbox
4.Select the Checkbox next to the keypad if you want to use the same width for the other set of wheels. If you want to use a different width or keep the width of the other wheels unchanged, ensure that the Checkbox is deselected.
N118151—UN—16FEB16

![[N118151.png]]
**Figure N118151**

OK
5.Select the OK button when finished.
6.If necessary, adjust the tread width by following the Tread Adjust Procedure.
