# Advanced Settings

Advanced Settings allows you to access further adjustments and less common settings.
Items Accessible on Advanced Settings Page:
NOTE: Some of the following items are only displayed if machine is equipped with the associated options.
N156802—UN—02AUG21

![[N156802.png]]
**Figure N156802**

Total Boom Sections
Total Boom Sections— total number of boom sections set up on the machine. Select the input box to change the number of boom sections.
NOTE: This setting is not the number of sections you have enabled. The number of boom sections set up must be entered for the spray rate control unit to calculate boom width and the correct application rate.
Total Boom Width— displays the total width of the boom.
N118045C—UN—24APR26

![[N118045C.png]]
**Figure N118045C**

Section Setup
Section Setup— configure each boom section.
N156060C—UN—24APR26

![[N156060C.png]]
**Figure N156060C**

Installed Spray Tips
Installed Spray Tips— indicates the spray tip selected. Select one of the tip icons to view the Select Tip page.
N125618C—UN—24APR26

![[N125618C.png]]
**Figure N125618C**

Fence Rows
Fence Rows— indicates the selected spray tip installed on the fence row nozzles. Select the icon to view the Select Tip page.
If Equipped with INC Pro:
WZ1406741—UN—28MAY25

![[WZ1406741.png]]
**Figure WZ1406741**

Curve Compensation
Curve Compensation— select the the toggle button to enable or disable this feature.
WZ1408747—UN—09JUN25

![[WZ1408747.png]]
**Figure WZ1408747**

Limit Minimum Flow Percentage
Limit Minimum Flow Percentage— select the checkbox to enable or disable this feature.
NOTE: On machines equipped with dual product solution systems, Limit Minimum Flow Percentage is enabled or disabled separately for each solution system.
