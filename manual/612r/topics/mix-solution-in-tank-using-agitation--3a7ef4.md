# Mix Solution in Tank (Using Agitation)

NOTE: With the solution tank filled and solution pump primed, complete the following steps to mix chemicals thoroughly.
Open solution tank lid to verify sufficient mixing visually.
NX1435329—UN—10DEC25

![[NX1435329.png]]
**Figure NX1435329** — A: Solution Pump On/Off; B: Agitation On/Off

1. Push solution pump on-off (A) to engage solution pump.
2. Press agitation on/off (B) to begin agitation.
NOTE: Pump speed and agitation valve setting determine the amount of agitation.
Agitation valve setting must be set using the CommandCenter display.
NX1440413—UN—14JAN26

![[NX1440413.png]]
**Figure NX1440413** — A: Intensity Increase Button; B: Intensity Decrease Button; C: Auto Intensity On/Off Button; D: Power Agitation On/Off Button

3. Adjust the agitation intensity using intensity increase button (A) or intensity decrease button (B).
NOTE: Auto intensity and power agitation can also be toggled using the display in the cab.
Intenisty increase/decrease buttons will be ignored while auto intensity is active.
4. Enable auto intensity using auto intenstiy on/off button (C).
5. Enable power agitation using power agitation on/off button (D).
6. Mix solution thoroughly before operating in the field.
NOTE: To minimize foaming, operate agitation at a lower rate. Turn off agitation when tank volume drops below 378.5 L (100 gal) to prevent foaming and air in system.
7. To stop agitation, press the solution pump button to stop the pump and press the agitation on/off button to close the agitation valve.
