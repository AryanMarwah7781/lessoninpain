# Machine Calibration | Tread Adjust

This procedure calibrates the tread adjust feature. Tread adjust must be properly calibrated to determine tread width to avoid driving on crop.
Perform Calibration When:
- A tread sensor has been replaced.
- Treads are not traveling to the expected spacing.
