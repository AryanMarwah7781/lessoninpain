# Solution Tank Level Sensor Procedure

Procedure Requirements:
Engine State | Engine OFF, key in Run position
Operating State | Parked
Rinse Tank | Empty
Solution Pump | Off with plumbing open
Standard Solution Systems Only:
Solution Tank | Empty
Calibration Overview:
N120226—UN—23FEB16

![[N120226.png]]
**Figure N120226**

Begin Calibration
1. Select Begin Calibration to begin procedure.
2. Follow messages on-screen to complete procedure.
N118093—UN—16FEB16

![[N118093.png]]
**Figure N118093**

Save
3. Confirm calibration by selecting Save.
If Calibration Fails:
N118122—UN—02MAY16

![[N118122.png]]
**Figure N118122**

Retry
1. Select Retry button.
2. Verify that all requirements listed on-screen have been met.
3. If calibration fails twice, contact your John Deere dealer or other service provider.

If Current Voltage Value is red, then current reading is outside the calibrated range.
