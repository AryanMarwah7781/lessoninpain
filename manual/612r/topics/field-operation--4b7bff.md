# Field Operation

CAUTION: Do not turn on the machine until you are sure that nobody is in the danger zone.
N155116—UN—21APR21

![[N155116.png]]
**Figure N155116** — A: Raise/Lower Switch

1. Unfold the boom and press raise/lower switch (A) to position the boom at desired operating height.
2. Set up the display for your particular application. (See the CommandCenter Display Applications section for proper setup procedure.)
3. Verify that the tank is loaded with solution.
NOTE: If no solution flow is detected, the solution pump will automatically shut off after a brief time to prevent overheating and damage to seals.
N155117—UN—21APR21

![[N155117.png]]
**Figure N155117** — A: Solution Pump Switch

4. Push solution pump switch (A) to engage the solution pump.
5. View spray operation on the display.
N155118—UN—21APR21

![[N155118.png]]
**Figure N155118** — A: Rate Control Switch; B: Manual Rate Switch

6. Select rate control switch (A) programmed for desired application rate (1, 2, or 3) or the manual rate switch (B).
NOTE: Rate selected is highlighted on the display.
N166439—UN—08MAR24

![[N166439.png]]
**Figure N166439** — A: Multi-Function Lever

7. Push multi-function lever (A) slowly forward to start forward motion.
8. Verify that desired boom sections are enabled. (See
Boom Sections | Custom in the Boom and Nozzles Application section.)
NOTE: The status of each boom section is indicated on the display. (See Section Control Status in the Boom and Nozzles Application section.)
N167055—UN—04APR24

![[N167055.png]]
**Figure N167055** — A: Spray System On/Off Switch; B: Indicator; C: Indicator

NX1396838—UN—17MAR25

![[NX1396838.png]]
**Figure NX1396838** — A: Spray System On/Off Switch; B: Indicator; C: Indicator

9. Press spray system on/off switch (A) to start spraying operation.
NOTE: Indicators (B and C) are illuminated when the spray system on/off switch is activated on the multi-function lever.
NOTE: Spray system shutdown is not immediate. Solution flow will continue for a few seconds after pressing the spray system on/off switch. For best response time and coverage, turn off the spray system on/off switch while slowing for the row end.
N155121—UN—21APR21

![[N155121.png]]
**Figure N155121** — A: Spray System On/Off Switch

10. At the row end, press spray system on/off switch (A) to stop spraying. All other switches can remain in preset positions.
NOTE: Spray system start-up is not immediate. To overcome delayed response, press the spray system on/off switch while moving forward to start spraying just before solution is needed.
11. When aligned with the next row, press the spray system on/off switch to resume spraying.
