# Tow Mode

This procedure can be used to steer the machine when the engine is not running.
IMPORTANT: Refer to the Operator's Manual for the complete Tow Mode procedure.
Modify When:
- The machine must be moved and the engine is inoperable.
- The machine must be moved following a hydraulic pump failure.
- The machine must be moved following a driveshaft failure.
Items Accessible on Tow Mode Page:
N128462—UN—31MAY18

![[N128462.png]]
**Figure N128462**

Enable Backup Pump
Enable Backup Pump— engages the backup pump to provide steering and braking.
N128463—UN—31MAY18

![[N128463.png]]
**Figure N128463**

Disable Backup Pump
Disable Backup Pump— disables the backup pump.
N118396—UN—17FEB16

![[N118396.png]]
**Figure N118396**

Close
Close— return to previous page and disable the backup pump.
Procedure to Tow Machine:
1.Prepare the machine for towing. (See Operator’s Manual for instructions.)
N128462—UN—31MAY18
Enable Backup Pump
2.Select the Enable Backup Pump button to enable the backup pump.
NOTE: The backup steering pump activates when the button is selected and runs continuously until disabled or battery power is lost. The backup pump provides steering and service braking power when enabled.
N118396—UN—17FEB16
Close
3.Select Close to disable the backup pump and return to the previous page.
