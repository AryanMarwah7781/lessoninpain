# Spray System Main Page

WZ1408697—UN—09JUN25

![[WZ1408697.png]]
**Figure WZ1408697**

Spray System
NOTE: Underscored text identifies that additional information is available within this section or another section of this publication.
Main page shown is for example only. Your main page may differ depending on options or connected equipment.
Spray System application allows you to configure the solution system controls to ensure proper application of solution.
Modify When:
- Changing application rates.
- Higher levels of agitation are needed.
- Application rate requires a change to flow valve configuration.
NOTE: Some items below are only displayed if machine is equipped with the associated option.

N145175—UN—13JUN19

![[N145175.png]]
**Figure N145175**

Minimum Pressure
Minimum Pressure—minimum pressure maintained while spraying.
NOTE: This setting is typically 83—104 kPa (0.83—1.03 bar) (12—15 psi) and should be set below the spray pressure setting. If the setting is set near or equal to the spray pressure there will be fluctuations in rate/ pressure.

Pressure Recirculation
Pressure Recirculation—pressure maintained in the boom while system is actively recirculating fluid. Select the value to modify the pressure setting.
NOTE: Recirculation returns boom contents to the solution tank. Ensure that boom plumbing is rinsed to prevent contamination of solution tank. Direct Injection pumps will be disabled when recirculation is enabled.
