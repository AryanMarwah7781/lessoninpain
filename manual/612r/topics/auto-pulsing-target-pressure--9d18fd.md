# Auto Pulsing Target Pressure

Auto Pulsing Target Pressure is the pressure maintained by the solution system during application. Target spray pressures are only available when using automatic pulsing mode. Using target spray pressures maintains droplet size when changing speeds or application rates. Target pressure setting does not override the minimum spray pressure entered during machine setup.
Modify When:
- Larger droplets are desired. Decrease the pressure.
- Smaller droplets are desired. Increase the pressure.
- The spray tip size is changed.
Procedure to Modify:
NOTE: If equipped with dual product solution system, the target spray pressures for each solution system are adjusted separately. Select the desired target spray pressure for the solution system you want to adjust.
