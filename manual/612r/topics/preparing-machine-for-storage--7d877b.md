# Preparing Machine for Storage

IMPORTANT: Load Command components must be stored at temperature below 50°C (122°F).
1. Evacuate chemicals from Load Command system.
2. Rinse Load Command system with clean rinse water.
3. Fill rinse tank with 189 L (50 gal) with SprayMaster Winterizer Fluid N305634.
4. Repeat rinse procedure.
5. Lubricate Load Command pump and nurse arm.
