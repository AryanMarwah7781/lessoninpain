Side Load Station Keypad and Displays
The sprayer is equipped with a 20-button keypad (B) and two micro displays (C and D) at the side load station. These devices are used by the operator to interface with the solution system when filling the solution tanks and adding chemicals. Raise the cover (A) for access to the keypad and displays. Another micro display is located at the front fill station for use when filling through the front ports.

Keypad Buttons (system 2 buttons and common buttons)
The keypad button functions are as follows:
- Eductor On/Off (A)—turns the eductor on or off (default eductor volume must be set from the CommandCenter display in the cab).
- Solution Pump On/Off (B)—turns the solution pump on or off (solution pump runs at 50% speed until adjusted).
- Fill Station Light (C)—turns the load station light on or off.
- Eductor Rinse On/Off (D)—turns the eductor on or off. Rinse solution comes from a source selected by the operator. (Default eductor volume must be set from the CommandCenter display in the cab.)
- Agitation On/Off (E)—turns agitation on or off (agitation volume must be set from the CommandCenter display in the cab.)
- Visual Nozzle Check Button (F)—directs the solution flow to nozzle port A or B.
- Rinse Water Select (G)—pressing the button gives the operator access to the clean water for rinsing options.
- Push-On Fill (H)—pressing the button begins the filling process using an external nurse tank pump; pressing the button again stops the filling process.
- Spray System On/Off (I)—turns the enabled spray sections on-off. (spray sections must be enabled or disabled on the display.)
- Menu Page (J)—displays additional functions on the microdisplay.
- Pull-On Fill (K)—pressing the button begins the filling process using the onboard POWRSPRAY pump; pressing the button again stops the filling process.
- Rinse Cycle (L)—begins the rinse procedure; full system or boom rinse can be selected using the micro display.
Indicators (M) display the status (on or off) of the function controlled by that button. Indicator light turning on indicates that the function is on. Indicators can also display the setting that the function is using for operation.
