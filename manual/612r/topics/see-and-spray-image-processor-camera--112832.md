# See & Spray - Image Processor/Camera

See & Spray - Image Processor/Camera allows you to access video feeds, fault codes, fallback status, and view diagnostic readings.
Items Accessible on See & Spray - Image Processor/ Camera Page:
WZ1408464—UN—06JUN25

![[WZ1408464.png]]
**Figure WZ1408464**

Select Processor
Select Processor— use the left and right arrows to toggle between image processors, or select the center of this overlay to open a full list of available image processors.
NX1460833—UN—06MAY26

![[NX1460833.png]]
**Figure NX1460833**

Select a Processor Group
Select a Processor Group— displays all active and faulted image processors, cameras, and light sensors. Press directly onto the desired group number to access more information. The currently selected image processor is highlighted by a yellow square.
WZ1408469—UN—06JUN25

![[WZ1408469.png]]
**Figure WZ1408469**

Select a Camera
Select a Camera— use the left and right arrows to toggle between cameras or select the center of this overlay to open a list of available cameras for the image processor selected.
WZ1408482—UN—06JUN25

![[WZ1408482.png]]
**Figure WZ1408482**

Video
Video— displays the live video feed from the selected camera. Detected targets are highlighted in blue.
Press the video tile to open a full screen of the video feed.
NX1459206—UN—27APR26

![[NX1459206.png]]
**Figure NX1459206**

View
View— select to access additional information about the selected issue.
WZ1408443—UN—06JUN25

![[WZ1408443.png]]
**Figure WZ1408443**

Diagnostic Readings
Diagnostic Readings— select to access additional information about the currently selected image processor and the cameras connected to the selected image processor.
WZ1408443—UN—06JUN25
Diagnostic History
Diagnostic History— select to access fault history and fallback mode history.
WZ1408443—UN—06JUN25
Capture an Issue
Capture an Issue— select to record the See & Spray ethernet logs in the background. To export data for a specific image processor, view the diagnostic data within File Manager.
Once you press the button, a message confirming you want to record the ethernet logs will appear. Select the OK button to continue. Another message will notify you once the issue capture is complete.
