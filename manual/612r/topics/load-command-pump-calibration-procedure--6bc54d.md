# Load Command Pump Calibration Procedure

Procedure Requirements:
Engine State | Running at low idle
Wheel Speed | 0 km/h (0 mph)
Operating State | Parked, not applying product
Hydraulic Fluid Temperature | >65.6°C (>150°F)
Load Command Pump | Prime pump if it has been
serviced or replaced.
Solution System
- Contains enough solution to prevent pump cavitation. Minimum volume 567.8 L (150 gal)
- Solution pump OFF
Calibration Overview:
NOTE: Warm the hydraulic fluid temperature to the normal operating range before the calibration, and fill the solution tank with enough solution to keep the pump from running dry.
Load Command Calibration Data
Speed (rpm) | Current (mA)
A1 | 300-310 | 800-1400
B1 | 550-600 | 1400-2000
