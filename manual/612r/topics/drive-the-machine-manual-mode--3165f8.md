# Drive the Machine—Manual Mode

N142910—UN—10APR19

![[N142910.png]]
**Figure N142910**

Transmission Mode Selection
1. Select Manual from the Transmission Mode selection on the display.
NOTE: Ladder automatically retracts when the machine moves.
N137031—UN—27APR18

![[N137031.png]]
**Figure N137031**

High Idle Switch
2. Press the high idle switch to achieve maximum engine speed.
IMPORTANT: Machine damage can occur if the speed range adjustment switch is moved from a higher speed range to a lower speed range, causing the engine to exceed 3000 rpm. Target speed can be changed when the machine is moving or stopped.
Maximum transport speeds are not available when the tread width is not adjusted to the narrowest setting.
NOTE: When the machine is started, or has been shut off and restarted, the F1 range is automatically selected with a target speed of 16 km/h (10 mph).

N166439—UN—08MAR24

![[N166439.png]]
**Figure N166439** — A: Multi-Function Lever

4. Push multi-function lever (A) slowly forward to start forward motion. Continue pushing the lever forward to increase ground speed. Rotate the speed range adjustment switch to increase ground speed when the engine reaches maximum rpm.
NOTE: Machine attempts to match and hold the actual travel speed to the target speed, with the engine at wide open throttle and the multi-function lever fully forward in field and transport modes.
“Anti-stall” feature allows the machine to stay at a desired rpm so that solution pump pressure is not compromised. The system accomplishes this task by automatically slowing the vehicle speed if the set target speed is not attainable. There is no need to shift speed ranges or pull back on the multi-function lever to prevent an engine or hydro system stall. Additionally, this feature automatically keeps the engine running at peak power (power bulge) under heavy load conditions.
CAUTION: When transporting the machine downhill at transport speeds, the machine tries to hold the target speed until the engine starts to overspeed. At this time, the vehicle speed could increase beyond the target speed. Before starting down a hill, select a speed (less than 35 mph) that is appropriate for the load on the machine and the steepness and length of the slope.
5. To reverse direction of travel, move the multi-function lever to neutral, then press the brake pedal to bring the machine to a complete stop. Move the multi-function lever to the right and rear to back up the machine. The reverse speed available is between 8.1—16.1 km/h (5—10 mph).
