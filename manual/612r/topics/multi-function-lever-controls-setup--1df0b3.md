# Multi-Function Lever - Controls Setup

Multi-Function Lever Controls Setup is used to assign applications and functions to buttons on the multi-function lever.
NOTE: See Function Assignments for a list of functions that can be set to the configurable buttons.
Items Accessible on the Multi-Function Lever Controls Setup Page:

Programmable Button
Buttons C, D, and E—are used for Dual Position Functions that require you to select from multiple positions, such as to increase or decrease a value, or to make a left-hand or right-hand adjustment.
NOTE: If equipped with Independent Mode, dual position buttons can also be assigned single position functions.

Lock Indicator
Lock Indicator— illuminates to indicate that the control group lock button is locked.
NOTE: Lock indicator resets every key cycle.
