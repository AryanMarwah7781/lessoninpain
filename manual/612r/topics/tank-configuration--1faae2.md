# Tank Configuration

Select the method for applying product from each tank.
NOTE: Some of the following items are only displayed if machine is equipped with the associated option.
Ensure that pumps are turned off before changing tank configuration.
WZ1408492—UN—06JUN25

![[WZ1408492.png]]
**Figure WZ1408492**

Single - Independent Tank 2
Single - Independent Tank 2— apply product from Tank 2. Tank 1 is inactive, but agitation is available.
If the cross-over valve is used, spray mode A is supported. If the cross-over valve is not used, spray modes A, B, A+B, Combined A+B, and Automatic are supported.
WZ1408489—UN—06JUN25

![[WZ1408489.png]]
**Figure WZ1408489**

Single - Combined Tank Normal Flow
Single - Combined Tank Normal Flow— apply the same product from multiple tanks using a single solution pump.
Spray modes A, B, A+B, Combined A+B, and Automatic are supported.
WZ1408489—UN—06JUN25
Single - Combined Tank High Flow
Single - Combined Tank High Flow— apply the same product from multiple tanks using two solution pumps.
Spray modes A, B, A+B, Combined A+B, and Automatic are supported.
WZ1408490—UN—06JUN25

![[WZ1408490.png]]
**Figure WZ1408490**

Dual - Independent Tanks
Dual - Independent Tanks— apply different products from each tank.
Spray modes A for tank 2, B for tank 1, and A+B are supported.
