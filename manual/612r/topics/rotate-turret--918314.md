# Rotate Turret

Rotate Turret buttons adjust the turret position within the control unit. The control unit must know the position of turret to achieve the desired application rate and provide the correct system options to you.
Modify When:
The physical turret orientation has been changed.
Procedure to Modify:
N127731—UN—16DEC16

![[N127731.png]]
**Figure N127731**

Rotate Turret
1. Select the desired rotate turret button to align the spray tips shown on-screen to the actual positions on the boom.
NOTE: Changing the turret position on the screen does not change the actual turret position. You must manually adjust each turret to the correct position.
WZ1406971—UN—28MAY25

![[WZ1406971.png]]
**Figure WZ1406971**

Close
2. Select the Close button to save changes.
WZ1408764—UN—09JUN25

![[WZ1408764.png]]
**Figure WZ1408764**

OK
3. A message appears to ensure that the nozzle turrets have been physically rotated to match the orientation on the display screen. Select the OK button to confirm.
