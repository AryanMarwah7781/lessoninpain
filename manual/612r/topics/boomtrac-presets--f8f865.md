# BoomTrac Presets

BoomTrac Presets allows you to quickly switch between two different BoomTrac configurations to react to changing conditions.
The presets can be used to quickly change settings for different crop types or react to changing spraying conditions within a field. For example, one preset can be used for normal spraying conditions and the other preset for crossing waterways.
Procedure to Modify:
NX1458255—UN—20APR26

![[NX1458255.png]]
**Figure NX1458255**

BoomTrac Presets
1.Select the desired preset.
2.Adjust the BoomTrac settings such as height mode, target height, and sensor height as needed.
Changes will be automatically saved to the selected preset.
