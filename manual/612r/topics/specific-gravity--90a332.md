# Specific Gravity

Specific Gravity is a measure of the density of a substance in comparison to the density of water. The specific gravity of the product being used can effect the flow rate.
The Specific Gravity screen allows you to view the current product's specific gravity setpoint, change the specific gravity to the measured value, and turn ON/ OFF the auto update feature.
Items Accessible on Specific Gravity Page:
WZ1406741—UN—28MAY25

![[WZ1406741.png]]
**Figure WZ1406741**

Auto Update
Auto Update— turn this feature ON to allow the system to automatically update the specific gravity value to the measured value when there is a change.
When Auto Update is turned OFF, the specific gravity value will not change even when there is a new measured value.
When you want to update the specific gravity to the measured value but leave Auto Update turned OFF, press the Set to Measured button or enter the desired value using the Input Box.

Setpoint Outdated
Setpoint Outdated— indicates that the current setpoint does not match the measured specific gravity value. This is indicated by the setpoint value being highlighted in red.
Press the Set to Measured button or turn ON Auto Update to adjust the setpoint to the measured value.

Measured Specifc Gravity
Measured Specific Gravity— displays the specific gravity value as measured by the system. Pressure sensors inside the tank are used to measure and calculate the specific gravity.
