# Rinse System | Solution Tank Only

Solution Tank Only rinse allows you to rinse the solution tank without rinsing any other systems.
Perform Solution Tank Only Rinse When:
Spraying off rinse solution is not possible.
Solution Tank Only Rinse Procedure:
CAUTION: Spray system can contain hazardous material that can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use rinse system in an area where people, animals, vegetation, water supply, and so on, cannot be contaminated.
NOTE: Chemical buildup in aspirators can occur if not cleaned out thoroughly and regularly. To clean, close all nozzles except the aspirator nozzles during boom rinse.
Engine rpm reverts to the previous level when solution pump is turned off if throttle position has not been adjusted.
NOTE: Rinse system can be operated from the load station using the keypad. See your Operator’s Manual for more details.
Solution tank must be empty before rinsing.
1.Verify that solution pump is OFF.
