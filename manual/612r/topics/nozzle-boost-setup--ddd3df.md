# Nozzle Boost Setup

Boost Setup allows for an increased or decreased application rate from the selected nozzles.
Modify When:
- Increasing the rate in the wheel tracks.
- Increasing the rate for the outer nozzles.
- Desiring an increased rate from a selected nozzle.
- Decreasing the rate near sensitive crops or plants.
Procedure to Modify:
WZ1408755—UN—09JUN25

![[WZ1408755.png]]
**Figure WZ1408755**

Nozzle Boost Solution System
1.If equipped with dual product solution system, select the solution system you want to adjust the boost setup settings for.
NOTE: When only one solution system is active or when in combined tank mode, solution system 2 settings are disabled and cannot be accessed.
WZ1408754—UN—09JUN25

![[WZ1408754.png]]
**Figure WZ1408754**

Nozzle Body Input Box
2.Select the Nozzle Body input box.
3.Enter the desired nozzle body number.
WZ1408764—UN—09JUN25

![[WZ1408764.png]]
**Figure WZ1408764**

OK
4.Select the OK button to confirm.
WZ1408757—UN—09JUN25

![[WZ1408757.png]]
**Figure WZ1408757**

Rate Input Box
5.Select the Rate input box.
6.Select the desired nozzle boost rate from the drop-down menu.

OK
