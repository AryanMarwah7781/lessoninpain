Pressure Strainers
Strainers are used to help keep dirt and debris from entering and damaging the solution pump, nozzles, and other components. Strainer screens should be removed and cleaned to maintain solution flow.
For best results, John Deere recommends using an 80 mesh strainer if apporved by the chemical label. If the chemical label requires a different mesh strainer, follow the chemical label requirement.
See Clean Fill Strainer, Aspirators, Nozzle Bodies, and Tips—As Required and Clean Pressure Strainers— Daily in this section.
