# Advanced Settings

Advanced Settings allows you to access further adjustments and less common settings.
NOTE: Some items below are only displayed if machine is equipped with the associated option.
Items Accessible on Advanced Settings Page:
WZ1408747—UN—09JUN25

![[WZ1408747.png]]
**Figure WZ1408747**

Machine Entrance/Exit Lighting
Machine Entrance/Exit Lighting— select to illuminate cab roof convenience lights.
H125409C—UN—23JUN25

![[H125409C.png]]
**Figure H125409C**

Engine Off Delayed Lighting
Engine Off Delayed Lighting— allows you to set the time limit for the lights to shut off after exiting the machine.
If Equipped with See & Spray:
WZ1408593—UN—09JUN25

![[WZ1408593.png]]
**Figure WZ1408593**

Boom Lighting
Boom Lighting— select the desired boom lighting option.
- Select OFF to not use the boom lights.
- Select ON to have the boom lights on at all times.
- Select AUTO to turn the lights ON automatically when the environmental lighting is low, the engine is ON, the booms are unfolded, and See & Spray is enabled.
WZ1408747—UN—09JUN25
Activate With Worklight Preset 2
Activate With Worklight Preset 2— boom lighting will turn ON when Worklight Preset 2 is ON, the engine is ON, and the booms are unfolded.
If Not Equipped with See & Spray:

WZ1408747—UN—09JUN25

Activate With Worklight Preset 2— boom lighting will turn ON when Worklight Preset 2 is ON, the engine is ON, and the booms are unfolded.
