# CommandARM

The CommandARM is the armrest console on the right-hand side of the seat. It carries the
CommandCenter display, the multi-function lever, the machine and spraying controls, and the
reconfigurable buttons.

## What it is

CommandARM Console and Display describes the controls and features on the armrest attached to the
right-hand side of the seat
[[commandarm-console-and-display--f3fc44|CommandARM Console and Display]]. The same description
appears in the cab overview [[sprayer-overview--6fbbe6|Sprayer Overview]], where the
multi-function lever is described as located on the CommandARM
[[sprayer-overview--6fbbe6|Sprayer Overview]].

Groups on the CommandARM [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]]:

- **Spraying Controls** — controls for the solution system or dry spreader when installed
  [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]].
- **Engine and Ground Drive** — controls for engine speed, park brake, and ground drive
  [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]].
- **Console and Display** — select for adjustments to the console and display
  [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]].
- **HVAC** — select to adjust temperature, fan speed, and air flow mode inside of cab and view
  outside temperature [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]].
- **Radio** — select to access radio presets that you can configure
  [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]].
- **Phone** — describes the controls for Push-To-Talk (PTT) and end call
  [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]].
- **Lights** — select to access light presets that you can configure
  [[commandarm-console-and-display--f3fc44|CommandARM Console and Display]]; see [[lights]].

## Related settings

### Controls Setup

Controls Setup application is used to make new assignments or access custom presets that you
previously configured on the multi-function lever or the CommandARM
[[controls-setup-overview--256617|Controls Setup Overview]]. Controls Setup contains no default
assignments; the multi-function lever and CommandARM reset to a locked state upon a key cycle
[[controls-setup-overview--256617|Controls Setup Overview]]. The display must be booted in order
for you to disengage the control group locks for function assignment, and control group refers to
the reconfigurable buttons on both the multi-function lever and CommandARM
[[controls-setup-overview--256617|Controls Setup Overview]].

CommandARM Controls Setup is used to assign application and functions to the commandARM
[[commandarm-controls-setup--f87692|CommandARM - Controls Setup]]:

- **Button 1** is used for applications that require you to select a Single Position Function such
  as ON/OFF [[commandarm-controls-setup--f87692|CommandARM - Controls Setup]].
- **Button 2** is used for Dual Position Functions that require you to select from multiple
  positions, to increase or decrease a value, or to make a left-hand or right-hand adjustment
  [[commandarm-controls-setup--f87692|CommandARM - Controls Setup]].
- If equipped with Independent Mode, dual position buttons can also be assigned single position
  functions [[commandarm-controls-setup--f87692|CommandARM - Controls Setup]].
- Programmable buttons are rocker switches, and they are programmed one way — for example,
  left = down (close) and right = up (open)
  [[create-dual-position-assignments--8d0efc|Create Dual Position Assignments]].

### Steering mode buttons

Select four-wheel steer mode by pressing the button on the CommandARM or pressing the four-wheel
steer foot switch; press the CommandARM button or foot switch again to return to two-wheel steer
mode [[steering-mode--5ec80a|Steering Mode]]. Select crab steer mode by pressing the button on the
CommandARM; press the CommandARM button again to return to two-wheel steer mode
[[steering-mode--5ec80a|Steering Mode]]. See [[steering]].

## Related procedures

- **Create Single Position Assignments.** Press the Control Group Lock button on the CommandARM,
  select the desired single position assignment button, select to activate the Select Application
  display, select the application you want to assign to the reconfigurable button, select the
  function, then close the Controls Setup application
  [[create-single-position-assignments--e90e10|Create Single Position Assignments]]. The light is
  on when locked and off when unlocked; when unlocked, applications and functions may be modified
  [[create-single-position-assignments--e90e10|Create Single Position Assignments]].
- **Create Dual Position Assignments.** The same sequence, starting from a dual position assignment
  button [[create-dual-position-assignments--8d0efc|Create Dual Position Assignments]]. If an
  assignment is already present on the Control Setup display, the "Remove Assignment" option is
  placed at the top of the list; select it to close and clear the assignment
  [[create-dual-position-assignments--8d0efc|Create Dual Position Assignments]].
- **Adjust the armrest and display.** See [[display]] and
  [[console-and-display--92d57a|Console and Display]].
- Attaching a secondary display: these video inputs are in addition to the armrest CommandCenter
  Display [[dual-display--fe591a|Dual Display]].

## Related warnings

The CommandARM topics themselves carry no DANGER, WARNING or CAUTION text — the signal words on
these notes are NOTE only
[[controls-setup-overview--256617|Controls Setup Overview]],
[[commandarm-controls-setup--f87692|CommandARM - Controls Setup]]. Warnings that fire while you are
using CommandARM controls appear on the machine pages they belong to: boom folding on [[boom]],
lighting and road transport on [[lights]], and brake or steering fault indicators on [[display]].

## Related troubleshooting

- The on-screen lock indicator is illuminated whenever the displayed control group is locked with
  the control group lock button on the CommandARM, and applications or functions setup will not
  operate [[controls-setup-overview--256617|Controls Setup Overview]]. If a configured button does
  nothing, check that indicator first
  [[commandarm-controls-setup--f87692|CommandARM - Controls Setup]].
- Assignments do not survive a key cycle: the multi-function lever and CommandARM reset to a locked
  state upon a key cycle [[controls-setup-overview--256617|Controls Setup Overview]].
- For the list of functions that can be set to the configurable buttons, see Function Assignments
  [[commandarm-controls-setup--f87692|CommandARM - Controls Setup]]; for a list of available
  application or function assignments, see Application Assignments or Function Assignments
  [[create-single-position-assignments--e90e10|Create Single Position Assignments]].
