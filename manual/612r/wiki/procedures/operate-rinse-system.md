# Operate Rinse System

**Applies to:** the base machine — Single Solution Command System (section 60), all models, no
option [[operate-rinse-system--738e0d|Operate Rinse System]]. Machines with the **Dual Product**
solution system rinse two solution systems and use a different procedure, given only in the
conditional section at the end of this page.

The following procedure is recommended daily or anytime chemicals are switched
[[operate-rinse-system--738e0d|Operate Rinse System]]. The Rinse System application also lists
applying product to different crops, changing product mixes, repairing or servicing machine,
preparing machine for storage, and changing between tanks as times to rinse
[[rinse-system--45e6cf|Rinse System]]. This full-system rinse ends with a boom rinse:
[[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter]].

**The product label governs** disposal and handling of the rinsate: always follow all label
directions for effective, safe, and legal use of agricultural chemicals, and properly dispose of
unused chemicals, flushing solution, and empty chemical containers
[[service-and-operate-chemical-sprayers-safely--6b47f1|Service and Operate Chemical Sprayers Safely]]
(generic Deere-wide module).

## Warnings

> [!warning] CAUTION
> CAUTION: Spray system can contain hazardous material, which can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use the rinse system in an area where people, animals, vegetation, and water supply, and so on, cannot be contaminated. [[operate-rinse-system--738e0d|Operate Rinse System]]

> [!warning] CAUTION
> CAUTION: Quik-Fill valve (A) can contain hazardous materials that could cause injury or be poisonous. Before removing Quik-Fill cap (B), verify that Quik-Fill valve is closed. [[drain-solution-tank--463f0b|Drain Solution Tank]]

> [!warning] NOTE
> NOTE: Engine speed can increase when a rinse cycle is initiated. [[operate-rinse-system--738e0d|Operate Rinse System]]

> [!warning] NOTE
> NOTE: Starting the solution pump can increase the engine speed. [[operate-rinse-system--738e0d|Operate Rinse System]]

## Prerequisites

1. Wear protective clothing, eyewear, and gloves, and move to an area where people, animals,
   vegetation, and water supply cannot be contaminated
   [[operate-rinse-system--738e0d|Operate Rinse System]].
2. System rinse must be set up using the display before the rinse procedure can be operated from the
   Fill Station (Rinse System Application section)
   [[operate-rinse-system--738e0d|Operate Rinse System]], [[rinse-system--45e6cf|Rinse System]].
3. Drain the solution tank [[operate-rinse-system--738e0d|Operate Rinse System]]. Do not drain
   solution onto the ground; drain into a container
   [[drain-solution-tank--463f0b|Drain Solution Tank]]:
   verify that the Quik-Fill valve is closed, open the lock levers and remove the cap, connect a
   nurse tank hose or place a suitable container under the Quik-Fill, press the menu button on the
   keypad, press the drain tank button on the micro display, and press cancel to close the drain
   valve when the desired fluid level is reached; then remove the hose, close the Quik-Fill valve
   and replace the cap [[drain-solution-tank--463f0b|Drain Solution Tank]].
4. Operate boom air purge (if equipped) to remove solution before performing the rinse procedure
   [[operate-rinse-system--738e0d|Operate Rinse System]].

## Steps (from the Fill Station)

5. Set spray pressure at 620—690 kPa (6.2—6.9 bar) (90—100 psi) to assist in chemical removal when
   spraying rinse water [[operate-rinse-system--738e0d|Operate Rinse System]] — **see the pressure
   conflict below.**

![[NX1435331.png]]

**Figure NX1435331** — A: Rinse Button [[operate-rinse-system--738e0d|Operate Rinse System]]

6. Press rinse button (A) [[operate-rinse-system--738e0d|Operate Rinse System]].

![[NX1440558.png]]

**Figure NX1440558** — A: System Rinse Button [[operate-rinse-system--738e0d|Operate Rinse System]]

7. Press system rinse button (A) [[operate-rinse-system--738e0d|Operate Rinse System]].

   > [!warning] NOTE
   > NOTE: When rinsing the eductor, the operator must manually open eductor rinse and sump valves when the display shows that portion of the rinse cycle. [[operate-rinse-system--738e0d|Operate Rinse System]]

8. The rinse procedure begins automatically and rinses the eductor, agitation, Load Command (if
   equipped), recirculation (if equipped), boom and solution tank
   [[operate-rinse-system--738e0d|Operate Rinse System]].

![[NX1440559.png]]

**Figure NX1440559** — A: Skip Button; B: Cancel Button [[operate-rinse-system--738e0d|Operate Rinse System]]

9. Press skip button (A) to skip to the next step if desired
   [[operate-rinse-system--738e0d|Operate Rinse System]].
10. Press the rinse button or cancel button (B) to stop automatic rinse. The rinse procedure
    automatically stops when complete [[operate-rinse-system--738e0d|Operate Rinse System]].

![[NX1440536.png]]

**Figure NX1440536** — A: Solution Pump On-Off Button [[operate-rinse-system--738e0d|Operate Rinse System]]

11. Press solution pump on/off button (A) on the keypad
    [[operate-rinse-system--738e0d|Operate Rinse System]].

![[NX1440567.png]]

**Figure NX1440567** — A: Pump Speed Increase Button [[operate-rinse-system--738e0d|Operate Rinse System]]

12. Increase pump speed, if desired, using pump speed increase button (A) on the micro display to
    achieve higher spray pressure [[operate-rinse-system--738e0d|Operate Rinse System]].

![[NX1440568.png]]

**Figure NX1440568** — A: Spray System On/Off Button [[operate-rinse-system--738e0d|Operate Rinse System]]

13. Press spray system on/off button (A) to spray out rinsate through the boom
    [[operate-rinse-system--738e0d|Operate Rinse System]].
14. Turn off the spray system and solution pump when the tank runs empty
    [[operate-rinse-system--738e0d|Operate Rinse System]].
15. Perform a boom rinse — [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter]]
    [[operate-rinse-system--738e0d|Operate Rinse System]].

Rinse procedures can also be activated from the cab using the display, but the operator must still
open eductor valves manually to rinse the hopper
[[operate-rinse-system--738e0d|Operate Rinse System]]. In the Rinse System application the rinse
types are Boom Only, Solution System, Solution Tank Only and Rinse Tank Transfer, and the target rate
can be adjusted as desired to avoid crop damage when rinsing in field
[[rinse-system--45e6cf|Rinse System]].

> [!conflict] Spray pressure for rinsing
> The machine-specific rinse procedure says to set spray pressure at 620—690 kPa (6.2—6.9 bar)
> (90—100 psi) when spraying rinse water [[operate-rinse-system--738e0d|Operate Rinse System]]. The
> generic Deere-wide chemical-safety module (`generic: true`) says not to operate solution delivery
> system at pressures exceeding 345kPa (3.5 bar) (50 psi)
> [[service-and-operate-chemical-sprayers-safely--6b47f1|Service and Operate Chemical Sprayers Safely]].
> The rinse value is well above the generic limit. This page does not choose; confirm the maximum
> for your machine with your John Deere dealer.

## If your machine has Dual Product (conditional — not the base procedure)

Dual Product machines have two separate systems to rinse, Solution System 1 and Solution System 2,
which can be rinsed independently, combined, or combined with equalizer
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]]. The same
CAUTION and the same 620—690 kPa (6.2—6.9 bar) (90—100 psi) rinse pressure are printed there
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].

![[NX1408051.png]]

**Figure NX1408051** — A: Solution System Button; B: Checkbox; C: OK Button
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]]

D1. Unfold the boom, drain the solution tank, and operate boom air purge (if equipped)
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].
D2. Set spray pressure at 620—690 kPa (6.2—6.9 bar) (90—100 psi)
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].
D3. On the cab display select the Solution System button, choose the system to be rinsed, select
the checkbox to reclaim product after the rinse cycle if wanted, and select OK
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].
D4. Select Rinse Cycles to choose the number of rinse cycles and Cycle Fluid Usage (Low, Normal, or
High), then select Start
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].
D5. Watch the status and progress indicators; Skip is only available once per circuit and can only
skip in order, and Abort ends the cycle early
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].
D6. When the rinse stops, start the solution pump and press the spray system On/Off switch to spray
rinsate through the boom
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].

The "1 + 2" and "1 + 2 with Equalizer" variants follow the same sequence
[[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].

## What the manual does not specify here

- How much rinse water to use for the base machine; the Dual Product display offers Low, Normal and
  High fluid usage, but no volume is printed
  [[operate-rinse-system-using-cab-display--f80420|Operate Rinse System Using Cab Display]].
- Where rinsate may be sprayed — the manual says only to use the rinse system where people, animals,
  vegetation and water supply cannot be contaminated
  [[operate-rinse-system--738e0d|Operate Rinse System]]. Beyond that, follow all label directions
  [[service-and-operate-chemical-sprayers-safely--6b47f1|Service and Operate Chemical Sprayers Safely]].
