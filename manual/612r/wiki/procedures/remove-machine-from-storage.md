# Remove Machine from Storage

Returning the sprayer to service after storage, from sealing tape to calibration. Applies to all
models, base machine [[remove-machine-from-storage--234a44|Remove Machine from Storage]]. Step 6
applies only to Final Tier 4 and Stage V engines, as the manual marks it
[[remove-machine-from-storage--234a44|Remove Machine from Storage]]. A separate Load Command section
follows the main steps for machines that have it.

## Warnings

> [!warning] IMPORTANT
> IMPORTANT: When first starting the machine after removing from storage, run the machine at no more than low idle for 4 minutes. Turn on the air conditioning system during this time to prevent compressor seal failure.
> [[remove-machine-from-storage--234a44|Remove Machine from Storage]]

> [!warning] NOTE
> NOTE: When removing the sprayer from storage, it is normal to find gear oil leaking out of the planetary drive hub inside the rim, or a puddle of oil on the rims, after the machine has sat for a period of time. The gear reduction hubs have a mechanical seal between the spindle and hub. It is normal for oil to leak out of these seals when a machine has been in storage.
> [[remove-machine-from-storage--234a44|Remove Machine from Storage]]

> [!warning] Generic Deere-wide safety — Work In Ventilated Area
> Engine exhaust fumes can cause sickness or death. If it is necessary to run an engine in an enclosed area, remove the exhaust fumes from the area with an exhaust pipe extension.
> [[work-in-ventilated-area--277b10|Work In Ventilated Area]]

## Steps

1. Remove sealing tape and plastic bags from openings
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
2. Check the engine oil level. If low, check for leaks. Add oil as required
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
3. Check the coolant level. If low, check for leaks. Add coolant as required
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
4. Clean the negative (-) battery terminals and cables and reconnect
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
5. Fill the fuel tank with proper grade diesel fuel
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
6. Final Tier 4 and Stage V engines only — if the diesel exhaust fluid (DEF) tank has not been
   drained, test urea concentration; if concentration is not within specifications, drain and replace
   with new or known good DEF; if the DEF tank has been drained, fill tank
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]]. The correct DEF concentration
   is 31.8—33.2% urea [[testing-diesel-exhaust-fluid-def--4c0b70|Testing Diesel Exhaust Fluid (DEF)]].
7. Drain SprayMaster Winterizer Fluid from the solution system and flush the system
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
8. Start engine and warm to operating temperature. Check for leaks
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]]. (See the IMPORTANT above:
   no more than low idle for 4 minutes on first start, with the air conditioning on.)
9. Clean the engine compartment and machine thoroughly, inside and outside
   [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
10. Check the oil level in hydrostatic/hydraulic reservoir. If low, check for leaks. Add oil as
    required [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
11. Check tire inflation [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
12. Lift each corner of the machine and remove stands
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]]. Instructions for lifting the
    machine are in Install Optional Tires—400R, 408R, 410R, and 412R or Install Optional Tires—600R,
    612R, and 616R [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
13. Ensure that all hardware is tight
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
14. Lubricate all grease fittings
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
15. Check the oil level in the planetary hubs. If low, check for leaks. Add oil as required
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
16. Remove plugs from the nozzle body turrets if necessary
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
17. Add clean water in the solution tank and operate the system to check for leaks before installing
    nozzle tips and screens [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
18. Inspect the nozzle tips, making sure that they are all the same size. Install tips and screens
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
19. For machines not equipped with pressure recirculation, perform a boom air bleed
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]] — see
    [[recommendations-for-eliminating-air-from-solution-system]].
20. For machines equipped with pressure recirculation, operate the pressure recirculation system
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]] — see
    [[recommendations-for-eliminating-air-from-solution-system]].

    > [!warning] IMPORTANT
    > IMPORTANT: If performing this process after removing machine from storage, it must be performed after freezing is not an issue or done with winterizing fluid.
    > [[recommendations-for-eliminating-air-from-solution-system--c98980|Recommendations for Eliminating Air from Solution System]]

21. Operate the spraying system and observe spray patterns. Adjust or replace tips as necessary
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
22. Review the Operator's Manual for operating adjustments and safety information
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
23. Calibrate the sprayer [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
24. Check the fire extinguisher gauge (if equipped) for the proper charge
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].
25. Check the air conditioning refrigerant charge. Have the system charged if necessary
    [[remove-machine-from-storage--234a44|Remove Machine from Storage]].

## If your machine has Load Command

The Load Command section has its own short removal-from-storage list
[[removing-machine-from-storage--fe30f2|Removing Machine from Storage]]:

1. Lubricate Load Command pump and nurse arm
   [[removing-machine-from-storage--fe30f2|Removing Machine from Storage]].
2. Prime pump, if necessary [[removing-machine-from-storage--fe30f2|Removing Machine from Storage]].
3. Rinse Load Command system [[removing-machine-from-storage--fe30f2|Removing Machine from Storage]].
4. Evacuate Load Command system and sprayer booms
   [[removing-machine-from-storage--fe30f2|Removing Machine from Storage]].
5. Begin normal operation [[removing-machine-from-storage--fe30f2|Removing Machine from Storage]].

> [!inference] Where the Load Command steps fit
> Neither topic says whether the Load Command list runs before, after or inside the main list. Its
> last step, "Begin normal operation", suggests it is done once the main machine is back in service.
> Confirm with your dealer if the order matters for your machine.
