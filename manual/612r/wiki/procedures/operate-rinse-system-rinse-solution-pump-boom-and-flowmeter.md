# Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)

**Interval:** rinse pump, flowmeter(s), and boom with clean water daily or anytime chemicals are
switched [[rinse-solution-pump-boom-and-flowmeter-s-daily--124862|Rinse Solution Pump, Boom, and Flowmeter(s) —Daily]].
**Applies to:** the base machine — Single Solution Command System (section 60), all models, no
option [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
Two Dual Product-only steps from the cab version are given in a conditional box below.

This is the boom-only rinse: it rinses the pump, boom, and flowmeter
[[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
Boom Only allows you to remove spray solution from the solution pump, flowmeter, and boom plumbing
when the solution tank still contains spray solution; perform it before servicing the solution pump,
flowmeter, or boom plumbing, and as necessary to clean nozzle bodies and prevent tip plugging
[[rinse-system-boom-only--03863f|Rinse System | Boom Only]]. It is also the last step of the full
[[operate-rinse-system]].

**The product label governs** the handling of rinsate: always follow all label directions for
effective, safe, and legal use of agricultural chemicals
[[service-and-operate-chemical-sprayers-safely--6b47f1|Service and Operate Chemical Sprayers Safely]]
(generic Deere-wide module).

## Warnings

> [!warning] CAUTION
> CAUTION: Spray system can contain hazardous material, which can cause serious injury or death to you or others. Wear protective clothing, eyewear, and gloves. Use the rinse system in an area where people, animals, vegetation, and water supply, and so on, cannot be contaminated. [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]]

> [!warning] NOTE
> NOTE: During a boom rinse cycle, the pump bleed and air bleed lines add some fresh water to the solution tank. This could result in the product being diluted and/or extra product in the tank. [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]]

> [!warning] NOTE
> NOTE: Engine speed can increase when a rinse cycle is initiated. [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]]

## Prerequisites

1. Wear protective clothing, eyewear, and gloves, and work in an area where people, animals,
   vegetation, and water supply cannot be contaminated
   [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
2. Spray rinse water at 620—690 kPa (6.2—6.9 bar) (90—100 psi) to assist in chemical removal
   [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]]
   — **see the pressure conflict below.**
3. Verify that the desired boom sections are enabled (Boom Sections tab of the Nozzle System
   application) [[rinse-system-boom-only--03863f|Rinse System | Boom Only]].

   the fold procedures and their CAUTION are on [[boom]].

6. Press cancel button (A) to stop the rinse procedure
   [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].

   > [!warning] NOTE
   > NOTE: Chemical buildup in the aspirators can occur if not cleaned out thoroughly and regularly. [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]]

7. After the boom has been rinsed, close all nozzle bodies not on an aspirator
   [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
8. Set the aspirator to "Open" position
   [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
9. Perform a second boom rinse procedure: flush one boom section at a time for 5 to 10 seconds until
   all sections are flushed
   [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].

   > [!warning] NOTE
   > NOTE: Rinsing all sections at once may not produce enough system pressure to flush the boom plumbing properly. Active boom sections must be controlled from the cab using section control switches. [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]]

10. Press cancel button (A) to stop rinse procedure
    [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
    Engine speed reverts to the previous level when the rinse procedure is turned off if the
    throttle position has not been adjusted
    [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
11. Return the nozzle bodies to previous positions
    [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].

## From the cab instead (Rinse System | Boom Only)

Boom rinse procedures can be operated from the cab using the display
[[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
In the Rinse System application: select Start (pump priming begins), press the Solution Pump switch,
then press the Spray System Master switch on the multi-function lever and boom rinsing begins; a
completion message appears and can be viewed in the Status Center
[[rinse-system-boom-only--03863f|Rinse System | Boom Only]]. Then close all nozzle bodies that are
not on an aspirator, set aspirator nozzles to open positions, and select Start for a second boom
rinse, rinsing only one boom section at a time for 5—10 seconds until all sections are flushed;
return nozzle bodies to previous positions
[[rinse-system-boom-only--03863f|Rinse System | Boom Only]]. Active boom sections can be controlled
using the Boom Sections tab of the Nozzle System application or the Boom Section Control Scroll
Wheels on the CommandARM [[rinse-system-boom-only--03863f|Rinse System | Boom Only]].

> [!note] Only if your machine has Dual Product
> Before selecting Start in the cab version: select the boom you want to rinse using the Select Boom
> input box (only available when the solution tanks are being used independently), and turn ON the
> solution system 1 pump using the Toggle Button if the boom being rinsed uses solution tank 1
> [[rinse-system-boom-only--03863f|Rinse System | Boom Only]].

> [!conflict] Spray pressure for rinsing
> This procedure says to spray rinse water at 620—690 kPa (6.2—6.9 bar) (90—100 psi)
> [[operate-rinse-system-rinse-solution-pump-boom-and-flowmeter--e70f48|Operate Rinse System (Rinse Solution Pump, Boom, and Flowmeter Only)]].
> The generic Deere-wide chemical-safety module (`generic: true`) says not to operate solution
> delivery system at pressures exceeding 345kPa (3.5 bar) (50 psi)
> [[service-and-operate-chemical-sprayers-safely--6b47f1|Service and Operate Chemical Sprayers Safely]].
> This page does not choose; confirm the maximum for your machine with your John Deere dealer.
