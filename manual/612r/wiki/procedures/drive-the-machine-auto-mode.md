# Drive the Machine—Auto Mode

Getting the machine moving in Auto transmission mode, setting a target speed, and reversing. This is
a true step-by-step procedure in the manual, for all models
[[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]. The maximum speed ranges differ
by model group and by whether a wet system or dry spreader box is fitted (table below).

## Warnings

> [!warning] CAUTION
> CAUTION: When transporting the machine downhill at transport speeds, the machine tries to hold the target speed until the engine starts to overspeed. At this time, the vehicle speed could increase beyond the target speed. Before starting down a hill, select a speed (less than 56.3 km/h [35 mph]) that is appropriate for the load on the machine and the steepness and length of the slope.
> [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

> [!warning] IMPORTANT
> IMPORTANT: Machine damage can occur if the speed range adjustment switch is moved from a higher speed range to a lower speed range, causing the engine to exceed 3000 rpm. The target speed can be changed when the machine is moving or stopped.
> Maximum transport speeds are only available if the tread width is adjusted to narrowest setting.
> [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

> [!warning] CAUTION
> CAUTION: To avoid serious injury or death to you or others, always use the seat belt properly. [[reduce-travel-speed--b6b710|Reduce Travel Speed]]

> [!warning] NOTE
> NOTE: Display saves the Auto mode setting when the key is turned off, but the machine will always start in Manual mode until the high idle switch is pressed and Auto mode is selected.
> [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

## Steps

1. Select Auto from the Transmission Mode selection on the display
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

   ![[N142909.png]]

   **Figure N142909** — Transmission Mode Selection
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

2. Press the high idle switch to achieve maximum engine speed
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

   ![[N137031.png]]

   **Figure N137031** — High Idle Switch [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

3. Press the park brake switch to release the park brakes
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]. The ladder automatically
   retracts when the machine moves [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

   ![[N137032.png]]

   **Figure N137032** — Park Brake Switch [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

4. Push forward on the multi-function lever (A). Auto mode automatically raises the engine rpm and
   shifts the transmission as needed
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

   ![[N166439.png]]

   **Figure N166439** — A: Multi-Function Lever
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

   > [!warning] NOTE
   > NOTE: When the machine is started, or has been shut off and restarted, the low range is automatically selected by the chassis control unit (CCU).
   > [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

5. Select target speed by rotating the speed range adjustment switch (A) to increase the speed until
   the desired target speed is reached
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]. Selected target speed and the
   vehicle speed indicator are displayed on the corner post display
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

   ![[N166440.png]]

   **Figure N166440** — A: Speed Range Adjustment Switch
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

   ![[NX1396836.png]]

   **Figure NX1396836** — A: Target Speed; B: Vehicle Speed Indicator
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

6. Continue pushing the multi-function lever forward to increase ground speed. Rotate the speed range
   adjustment switch to increase ground speed when the engine reaches maximum rpm
   [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].
7. To reverse direction of travel, move the multi-function lever to neutral, then press the brake
   pedal to bring the machine to a complete stop. Move the multi-function lever to the right and rear
   to back up the machine. The reverse speed available is proportional to the distance the lever is
   moved [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

## How Auto mode behaves

> [!warning] NOTE
> NOTE: Machine attempts to match and hold the actual travel speed to the target speed, with the engine at wide open throttle and the multi-function lever fully forward in field and transport modes. Cruise control will be active at all times.
> [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]

The "Anti-stall" feature allows the machine to stay at a desired rpm so that solution pump pressure
is not compromised, by automatically slowing the vehicle speed if the set target speed is not
attainable; there is no need to shift speed ranges or pull back on the multi-function lever to
prevent an engine or hydro system stall
[[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]. Auto mode provides enough engine
rpm for rate control, even at a reduced engine rpm with antistall still active
[[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]].

For slowing and stopping (multi-function lever, brake pedal, secondary brake), see
[[components/brake]] and [[reduce-travel-speed--b6b710|Reduce Travel Speed]].

## What the manual does not specify here

- A target speed for spraying is not given in this topic; the table gives ranges only
  [[drive-the-machine-auto-mode--c2def8|Drive the Machine—Auto Mode]]. Spraying speed is set by the
  application rate, the installed tips and the product label.
- The topic does not describe Manual mode driving.
